## 处理原则

- 先盘点入口 → 交互草图给用户确认 → 实现 → 多角色评审。
- 每个浮层都要能收起；手机窄屏统一折叠与手势。
- 通知统一一层：优先级、不遮挡正在编辑的表单、每版本关一次的规则一致。
