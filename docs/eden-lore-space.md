# 伊甸庄园 · 设定空间清单（Blender v2 用）

来源：角色卡《庄园布局》《女仆团》及人物条目（只读，卡片不入库）、`docs/eden-estate.md`、`map/data/maps.json`（`here.mjs` 词表）。
**内容规则**：只写中性名称与功能；卡中性质不宜的房间一律给通用名并加 `*`（如「附属室 A*」），只保留几何与标签，不写功能与陈设。

统计：卡中空间 **41** 项（主楼 F1 9、F2 7、F3 4、B1 5、B2 4、系统 2、室外 10，其中 4 项为 * 通用名），仓库既有补充 **14** 项，人物 **11** 组；`here.mjs` 当前能解析 **54/55**。

卡的总体数据：独占悬浮岛；「占地约 12,000 m²（含室外庭园）」；地上三层 + 地下两层；新古典白石；主人动线与仆从动线分离。
> 注：卡的 12,000 m² 远小于岛面（约 670 × 500 m），v2 按「主楼群 + 庭园核心约 1.2 ha」理解，其余为林地、别墅与园林（推断）。
