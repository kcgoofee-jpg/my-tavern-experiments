- **手机**：控制列太高、顶栏够不着、点空白误收、柄与 home 条冲突、88dvh 太高 → §10.1、10.2、10.4（控制列只常驻 ⋯ + − ⌂，顶栏只留标题 + ✕，轻点阈值，全开 ≤ 80%，柄 ≥ 48px）。
- **桌面**：快捷键与酒馆输入冲突、Esc 过载、映射入口太深、提示在编辑时被延后、设置与右栏打架 → §10.6–10.9。
- **无障碍**：只能拖动的操作（2.5.7）、点空白无键盘等价、焦点去向、对比度、提示时长与角色 → §10.3、10.4、10.9–10.11；三维拖动自动收起默认关（§10.5）。
