# UI v2 · 统一交互规范（草案，待用户确认）

配套：`inventory.md`（盘点与 U1–U12 根因）、`mockups.html`（低保真草图）、`shots/*.png`、`review.md`。
平台优先级：macOS 酒馆（WebKit）+ 桌面 > 手机 375 宽可用 > iPhone 专门适配（最低）。
令牌：沿用 `map/ui/tokens.css` v1，不新增色值；新增的只有布局令牌（§7）。

---

## 1. 原则

1. **每种东西只有一个家**：一个顶栏、一个底部抽屉、一列浮动控件、一个通知层。
2. **每个浮层都能收起**，收起方式一致：抽屉柄 / 下滑 / Esc / 点地图空白。
3. **地图或模型永远至少露出 50%** 的可视面积（手机抽屉半开 ≤ 45dvh）。
4. **同一时刻底部只有一个东西**：抽屉。卡片、事态、人物、部件、图例、导览都作为抽屉的内容，不再各自贴底。
5. 平面图和三维页用同一套外壳（`chrome`），三维页只是把「层切换」换成「视图切换」。

## 2. 布局分区

```
┌──────────── 顶栏 T（44px）──────────────┐
│ ‹上一级  标题 / 面包屑   [未上图][状态] ⚙ │
├──────────────────────────────────────────┤
│                                    ┌──┐  │
│           地图 / 模型              │C │  │  C = 浮动控制列（拇指侧）
│                                    │  │  │
│                                    └──┘  │
├──────── 底部抽屉 S（柄 + 标签页）────────┤
│ ═══  事态 3 · 人物 5 · 地点             │
└──────────────────────────────────────────┘
```

### 2.1 顶栏 T
- 嵌入酒馆时：**宿主标题栏 H3 与查看器顶栏 V1 合并为一条**。宿主栏只留：拖动区、当前地点胶囊、✕；其余（线路、未上图）通过 postMessage 交给查看器顶栏显示。单独打开时查看器顶栏自己带 ✕。
- 内容（左 → 右）：`‹` 上一级 · 面包屑（手机只显示当前一级）· 未上图 chip（有时）· 状态点（加载 / 慢 / 失败，点开看详情）· 图层 · ⚙ 设置。
- 语言、主题、清晰度档、版本号移入设置（§5），顶栏不再放。
- 三维页：标题写在顶栏（取代 E1 大标题；徽章与格言放进「关于这里」抽屉页）。

### 2.2 底部抽屉 S（唯一）
- 三档：**收起**（柄 + 一行摘要，56px）/ **半开**（40dvh，手机；桌面 360px）/ **全开**（88dvh，顶栏下方）。
- 柄：宽 36×4 的可见横条 + 整条 44px 高的命中区；带文字按钮「收起 / 展开」给读屏与鼠标（`aria-expanded`）。
- 手势：柄上下拖动吸附到最近一档；列表滚到顶后继续下拉 = 降一档；点地图空白 = 回到收起。Esc = 降一档。
- 标签页：平面图「事态 · 人物 · 地点」；三维页「部件 · 流向 · 说明」。点地标 / 热点 → 切到「地点 / 说明」并半开。
- 桌面（≥ 900px）：抽屉改为**右侧栏**，宽 360px，同样三态（收起 = 48px 竖条；半开 = 360；全开 = 480 + 列表两栏）。收起态始终可见，不会「开了关不掉」。
- 任何时候抽屉都不盖住浮动控制列：控制列 `bottom` 跟随抽屉高度（手机），桌面在右栏左侧。

### 2.3 浮动控制列 C
- 手机：拇指一侧（沿用「惯用手」设置），竖排：层 / 视图切换（折叠成一个按钮，点开展开竖排）、缩放 + −、复位 ⌂、标注开关 🏷。
- 桌面：右下（右栏左侧），同顺序；层切换在桌面可常展开。
- 抽屉全开时控制列隐藏；半开时跟随上移。

### 2.4 悬浮按钮（宿主）
- 位置、拖动不变。状态只保留：进度环、失败虚线、红点（当前地点）。「新事态」气泡改走通知层（§3），不再挂在按钮上。

### 2.5 各层默认视野（U2）
- 每层在 `registry` 里给 `view.phone`（核心区矩形）；手机首次进入 fit 核心区，允许缩远看到周边。

### 2.6 地图叠加层级（U8）
- 标签 > 人物头像 > 当前地点 > 事件点 > 航线 / 行程 > 安保小签 > 底图。航线在标签框范围内断开（绘制时挖空），不再穿字。

## 3. 通知层（唯一）

一个队列、一处渲染（宿主页 `em-notice`；查看器内的通知 postMessage 给宿主统一显示；单独打开时查看器自己渲染同一组件）。

| 级别 | 例子 | 位置 | 行为 |
|---|---|---|---|
| **P0 阻断** | 强制更新；地图加载失败（线路都连不上） | 面板内居中卡片，遮罩地图 | 不能关；主按钮 + 次按钮固定位置（右主左次） |
| **P1 需要处理** | 存储满；有新版本；自检有 ⚠；加载很慢（U3） | 顶栏下方横幅（一条） | 可关；**同一版本 / 同一组警告关一次就不再出现**；多条时折叠为「还有 N 条」 |
| **P2 信息** | 新事态；别名已生效（可撤销）；已填入聊天 | 底部抽屉上方的小 toast（控制列不遮） | 4s 自动消失；带「撤销」时 8s；同时最多 1 条，其余排队 |
| **P3 状态** | 加载进度、瓦片慢 | 顶栏状态点 | 不打断 |

规则：
- 同时最多：1 个 P0 + 1 条 P1 横幅 + 1 条 P2 toast。P0 出现时 P1/P2 暂停排队。
- **不遮挡正在编辑的表单**：设置 / 对话框打开且焦点在输入框时，P1/P2 延后到关闭后。
- 开场自检（H9）改为：一切正常 → 只在状态点闪一次 ✓，不弹卡；有 ⚠ → P1 横幅「自检发现 N 项需要注意」→ 点开进入设置「更新与版本 · 自检」。
- 「未上图」不是通知：是顶栏 chip（持久状态），点开选择器。
- 读屏：P0 `role=alertdialog`；P1 `role=status`；P2 `aria-live=polite`。

## 4. 三维查看器外壳（庄园 + 道具共用，U7 / U11 / U12）

一个 `map/ui/chrome3d.js`（名字待定），两页都引用：
- **顶栏**：标题 + 视图切换分段（外观 / 内透 / 剖切；道具页按清单给出的模式）。剖切时分段下方出现楼层 / 高度二级条（庄园 B2…F3 按钮；道具页滑条）。
- **控制列 C**：+ − ⟲、标注开关（同时控制房间标签和热点编号）、导览（有时）。
- **底部抽屉 S**：「部件」「流向 / 图例」「说明」三页。
  - 默认**收起**（摘要行：「部件 12 · 流向 4」）。首次打开也不展开（U12 主因）。
  - 点热点 → 抽屉半开到「说明」，模型自动平移让热点位于抽屉上方可见区中心。
  - 拖动 / 旋转模型超过 300ms → 抽屉自动降到收起（可在设置「高级」关闭）。
  - 流向开关与流向图例合并：打开「流向」页即显示流向线，离开即隐藏；页内可「固定显示」。
- 导览：作为抽屉的一页（上一站 / 下一站在抽屉摘要行），不再单独浮条。
- 加载：沿用通知层 P0/P3 组件。

## 5. 设置信息架构（U10）

设置 = 手机全屏页 / 桌面右侧 480px 面板；首屏是分组列表，点进子页，左上 `‹` 返回。搜索框在首屏顶（桌面）。

| 页 | 内容 |
|---|---|
| **显示** | 主题、语言、清晰度档、惯用手、关闭花屏特效、减少动态（跟随系统 / 开 / 关）、画质（三维像素比上限） |
| **人物** | 人物栏显示数值、人物卡显示更多资料、人物来源（只读计数） |
| **数据与映射** | 变量映射、自定义别名 / 忽略、填入聊天的模板、数据来源（`EdenMap.sources()` 只读）、存储占用与清理 |
| **更新与版本** | 当前版本、检查更新、自动检查、自动更新、锁定版本、自检结果与「重新运行」、更新日志链接 |
| **高级** | 打开地图时自动跳到当前地点、线路选择、三维抽屉自动收起、调试（fps） |
| （页脚） | 关于 · 原作角色卡作者与原作发布帖链接（必须保留） |

模块（varmap / custom / compose / selfcheck）改为向指定页注册 `registerSection(page, el)`，不再 `insertBefore(#selfCheck)`。

## 7. 手势、动效、无障碍

- 手势：地图拖动 / 捏合不变；抽屉柄竖拖；抽屉内容横向不绑定手势（避免与图集左右滑冲突）。
- 动效：抽屉吸附 `--dur-2` + `--ease-out`；`prefers-reduced-motion` 与设置「减少动态」→ 瞬切，不飞行只跳转。
- 命中区 ≥ `--hit`（44px），文字 ≥ 11px（令牌已有下限）。
- 焦点：抽屉展开焦点移到标签页；收起焦点回到柄。对话框焦点陷阱 + 返回原入口。
- 新增布局令牌：`--bar-h: 44px; --sheet-peek: 56px; --sheet-half: 40dvh; --sheet-full: 88dvh; --rail-w: 360px; --col-w: 48px`。
- 图集 `.rg` 改用 `--gold` 等令牌（去掉自带 `#c9a45c`）。

## 10. 第 1 轮评审后的修订（覆盖前文同名条款）

1. **手机顶栏**只留 标题 + 状态点 + ✕（命中 44×44）；上一级、图层、设置、层切换、标注收进控制列的「⋯」。控制列手机常驻只有 ⋯ + − ⌂；半开时最高到屏幕中线，超过则改为横排贴抽屉上沿。
2. **抽屉档位**：全开手机上限 80dvh；`dvh` 在酒馆 iframe 内不可靠 → 以 iframe 容器高度（`%` / JS 测量）为准。柄命中区 ≥ 48px，底部加 `safe-area-inset-bottom`；柄上的拖动不透传给地图。
3. **拖动之外的等价操作（WCAG 2.5.7）**：文字按钮循环 收起 → 半开 → 全开；列表下拉降档、拖柄都只是加速方式。
4. **点地图空白收起**：只认移动 < 8px 且 < 250ms 的轻点；点到地标 / 热点按地标处理。键盘等价 = Esc。
5. **三维「拖动模型自动收起」默认关**（设置「高级」可开）。
6. **Esc 只作用于最上面一层**：对话框 > 设置 > 抽屉；嵌入时 `stopPropagation`，不传给酒馆。
7. **快捷键**只在查看器 iframe 有焦点、且焦点不在输入框 / contenteditable 时生效；`?` 打开快捷键表；单字母快捷键可在「高级」关闭（WCAG 2.1.4）。增加 `M` 直达「数据与映射 · 变量映射」。
8. **桌面设置与右栏同列**：设置打开时替换右栏内容（‹ 返回回到抽屉），不再叠第二个右侧面板；右栏宽度可拖到 720px，宽度与开合状态按聊天记在本机。
9. **通知时长**：P2 默认 6s；带「撤销」≥ 10s；悬停 / 聚焦时暂停。P1 横幅用 `role=region` + 标题，不用 `status`。P0 打开时焦点落在主按钮。**用户自己操作产生的 P2**（如别名已生效）不延后，改为在所在设置页内联显示并带撤销。
10. **焦点与读屏**：抽屉标签用 `tablist / tab / tabpanel`（←→ 切换）；点地标切页时焦点留在地图，变化经 `#sr` 播报；被隐藏的控制列用 `inert`。
11. **对比度**：实现前逐一检查 3 主题 × 4 层的文字 4.5:1、非文字 3:1；桌面收起竖条用正文色横排「事 3 / 人 5」；减少动态或高对比时去掉 `--glow-text`。
12. 横屏手机（高 < 480）：按桌面右栏布局处理，栏宽 min(360px, 45vw)。
13. （第 2 轮补）读屏 / 无空白可点时，收起的路径是文字按钮；抽屉柄对抽屉底色 ≥ 3:1；地标与热点可用 Tab 进入（组内方向键漫游），焦点样式用 `--focus` 描边；§10.7 的开关同时关闭 `M`。
14. （第 2 轮补）焦点在宿主页时快捷键不生效，宿主把 Esc 用 postMessage 转给查看器；快捷键用 `event.key` 并在 `isComposing` 时忽略；右栏宽度上限 min(720px, 50vw)；离开设置回到之前的抽屉标签与滚动位置。手机抽屉摘要行左侧加层名胶囊（「中层 ▾」），一次点击即可切层 / 回上一级。
