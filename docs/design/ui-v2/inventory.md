## 五、重复与冲突汇总

- **提示样式 7 种**：H6 底部 toast、H7/H8 顶部更新、H9 自检卡、H10 酒馆 toast、H11 气泡、V10 状态条、V13 `#cuToast`。无统一队列；自检（30003）会盖住强制更新（30002）。
- **加载界面 4 种**：H4、V9、E7、P6，各自的重试 / 换线路按钮位置不同。
- **视图切换 2 套**：E2（左竖 / 底横）与 P1（顶部分段）。
- **缩放 2 套、标注开关 2 套**：V5 / E3；V2「地名」/ E3「标」；道具页没有。
- **卡片 3 套**：V8、E4、P5。
- **顶栏 2 层**：嵌入时 H3（宿主）+ V1（查看器）；庄园再加 E1。
- **底边争用（手机）**：V6 停靠栏、V7 事态栏、V8 卡、V11 页脚、E2 楼层条、E5 导览、P3 部件、P5 说明卡、H6 toast、H9 自检、H1 悬浮按钮（最后两个在宿主层）。
