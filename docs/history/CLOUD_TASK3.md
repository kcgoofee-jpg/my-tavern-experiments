## 1. 每层参考城市（用户已确认）
在现有 OSM 管线（`blender/tc_osm.py`、`tc_city.py`）上，按城区拼接不同的真实城市肌理。天城是虚构城市：可以旋转、裁剪、镜像，不保留任何真实地名；统一署名 © OpenStreetMap contributors。

| 层 / 城区 | 参考 | 要点 |
|---|---|---|
| 中层 · 核心区与高区（执法局总局、议会、辉光大教堂、圣铁摇篮） | 纽约曼哈顿中城 | 规整街区、装饰艺术风格高楼、「老钱」气质；夜里是楼内透出的暖光，霓虹克制 |
| 中层 · 商业区 | 东京新宿 / 涩谷，保留现有九龙旺角一带 | 霓虹、全息广告、窄街高密度 |
| 中层 · 外围居住区 | 纽约布鲁克林 | 低矮联排住宅、旧仓库、宽街，和核心区拉开对比 |
| 下层 · 地基区 | 深圳城中村 + 德国鲁尔区工业带，局部参考九龙城寨的密度 | 贫民窟屋顶极密；厂房、储罐、货运铁路 |

- 做法：每个参考区域单独下载处理成 `blender/data/osm/<区域>.json`；在 3 km × 1.875 km 平面上划城区多边形，各城区取对应数据；城区交界处做 50–100 m 的过渡带（道路接续、建筑密度渐变），避免拼缝。
- 跨层对位：中层 C 区检查点与下层 7 号井在同一平面位置，保持不变；上层岛屿投影数据继续从 `tc_upper.json` 取。
- 上层庄园：给岛屿风格加 `estate_style`（english / chateau / suzhou / lingnan / neoclassical），写进 `tc_upper.json` 的 islands，方便以后在地图上显示。
- 先各出 2000px 草稿放到 `docs/drafts/`，与上一版对比，每层最多迭代 3 轮。

## 2. 各地图默认缩放（新待办）
设定里只有天城分上中下三层；但圣都（「城市中轴的高台浮空堡垒群与超级摩天楼」）、原域（「悬浮圣山」）也有浮空结构，以后可能做「浮空 + 地面」两层。所以缩放不能写死。
- 在 `map/data/maps.json` 每张地图加 `view`：`{ "focus": "<标记 id>", "width_m": <初始可见宽度，米>, "min_width_m": <最大放大时的可见宽度>, "extent_m": [宽, 高] }`。世界图按公里级、天城各层按几百米级给合理默认值（例如世界初始约 1/3 大陆宽，天城各层初始约 800 m 宽、能放大到约 60 m 看清伊甸主楼）。
- `map/viewer.html` 的 `focusStart` 改为按 `view` 计算（米 → 归一化宽度），手机竖屏按可见高度另算；没有 `view` 的地图沿用现在的逻辑。
- 最大放大倍数也按 `min_width_m` 限制，不再全局统一 `maxZoomPixelRatio`。
- `tools/check_maps.py` 检查 `view` 字段。
