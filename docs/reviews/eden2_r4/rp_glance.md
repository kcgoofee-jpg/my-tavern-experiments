# RP 扫一眼 · eden2 r4

分数 7/10（过门槛）

玩具感：大幅消失。旧图是均匀绿地+圆球树+粉色色块，像沙盘玩具；新图有扫描树冠、草地纹理、灰色屋顶和泳池，第一眼是"私人庄园航拍"。残留点：大草坪偏平、偏黄绿；散落的灰色小方亭像 UI 图钉。

一眼能找到：
- 主宅：是，正中宫殿+半圆柱廊，375px 下也最醒目。
- 登岛口：是，底部圆台+水渠长轴线，指向清楚。
- 湖：是，北部深色湖面，375px 下偏黑但可辨。
- 别墅：大致可以，东西两侧白屋+泳池，但在 375px 下缩成白点，和亭子/服务楼分不开。

Top 3 修改：
1. P1（省流/手机）：椭圆环路上 8 个灰色小方亭太规整、像图标，建议缩小或融入树荫，或者删掉一半。
2. P1（手机）：湖面和森林太暗，375px 下糊成一片，建议提亮湖面反光、给林缘加一点明暗过渡。
3. P1（省流）：别墅在手机上辨识度不够，建议加大泳池蓝色块/屋顶对比，并统一朝向，让人看出"一圈别墅"。

否决再开一轮：否。第 1、2 条手机上一眼可见，值得小改一轮。

## r4 第二轮
分数 7.5/10（过门槛）
玩具感：375px 下已无，像航拍缩略图。
进步：湖面和林子提亮，手机上不再糊；小亭减半且换彩色屋顶，不再像图钉；主宅、中轴、登岛口、湖依旧一眼可见；机库/网球场/菜园有颜色区分。
剩余前三：
1) P1（手机）：别墅仍缩成白点，和服务楼、机库分不太开，可加大泳池蓝块。
2) P2（省流）：草地浅色斑块有点像污渍，手机上不明显。
3) P2（省流）：东侧空心白圆环像 UI 标记，可能和事件标记混淆。
否决再开一轮：是——剩下的问题手机上几乎看不到，玩家不会在意。

## r4 第三轮
分数 7.5/10（过门槛）
玩具感：375px 下无，像航拍缩略图。
进步：主楼、中轴、南入口、湖、西侧彩色梯田在手机上一眼可分；别墅少而大，不再是白点；夜景灯光一眼能认出主楼和道路。
剩余前三：
1) P1（手机）：南侧和东侧的白色圆盘（观景台）像事件/定位标记，易混淆，建议压暗或加纹理。
2) P2（省流）：夜景东侧森林全黑，若有事件标记在那里会看不清，加几盏路灯即可。
3) P2（清晰）：特写小屋、健身馆材质偏卡通，玩家平时看不到。
否决再开一轮：是——剩余问题除第 1 条外手机上基本不可见，第 1 条可顺手改。
