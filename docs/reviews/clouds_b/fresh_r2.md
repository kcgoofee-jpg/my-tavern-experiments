# 现编审阅 · clouds_b r2

**身份**：低视力/色弱辅助功能测试员，常在户外强光、手机亮度 50% 下测游戏地图。
**为什么选他**：r1 新人设看的是精灵叠加；本轮底面近白、岛靠明度差取胜，没人从「低对比感知 + 强光屏幕」角度检查岛与标记是否仍可分辨。
**只看**：①灰度下岛/底明度差；②色弱下标记可辨；③强光下亮底眩光。
