# 现编审阅 · clouds_b r1

**身份**：做过 CoC/部落类手游 UI 的前端合成工程师，常在手机上叠加半透明精灵到静态底图上检查「叠加后会不会穿帮」。
**为什么选他**：本轮把底图换成「不动的纯白云铺满」，而查看器会在上面实时叠漂移云精灵；固定人设只看静态图，没人看「白底 + 白云精灵 + 白唇」三者叠加的风险，以及「不许有岛影」约束下岛如何落地。
**只看**：①底面与漂移精灵的对比余量；②白唇与底面/精灵的层次；③无岛影下的空间深度；④亮底在手机上的眩光/刺眼。

**分数：5/10**

| # | 级别 | 位置 | 现象 | 修法 |
|---|---|---|---|---|
| 1 | P0 | 全图底面 vs 漂移精灵 | 底面已接近白（≈#EEF0F4）且几乎无起伏，白色云精灵叠上去会几乎看不见（无对比余量），或只能靠加灰边才显形→又回到「卡通云」 | 底面整体压到约 #DCE2EA–#E6EAF0 并带冷蓝灰体积暗部，给精灵留 ≥10% 亮度差；精灵保持最亮（#FFFFFF 顶光） |
| 2 | P1 | 岛边白唇 | 唇与底面同色，精灵飘过时唇/精灵/底三层无法区分，唇等于不存在 | 唇亮度介于精灵与底面之间，并用团状外轮廓；精灵层在岛上方经过时 alpha ≤0.5 以免盖住岛 |
| 3 | P1 | 所有岛 | 禁岛影后岛在亮底上悬浮感弱、像贴片（尤其左下城堡岛） | 只在岛自身侧壁做暗崖边/AO（岛内部，不投到云上）；不违反无岛影规则 |
| 4 | P2 | 手机夜间使用 | 大面积近白底在暗色聊天界面旁很刺眼 | 查看器提供暗色模式下底面整体 -15% 亮度的滤镜 |
| 5 | P2 | 事件光圈 (1565,960) | 浅蓝光晕在白底上对比不足，精灵飘过时可能被遮 | 标记层置于精灵层之上，外加深色描边 |

一句话：静态图可读，但白底没给漂移精灵留对比余量，叠加后要么看不见云要么回到卡通描边——先压暗底面再过门。
