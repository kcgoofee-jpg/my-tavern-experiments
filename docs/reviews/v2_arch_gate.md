## 第 1 轮问题与修复
- **架构**
  - `settings.page`、`notice-act.key` 在 schema 里改为可缺，否则设置首页深链会被丢弃。
  - 模块加载失败时告警一次。
  - boot 消息盖上 `v`。
  - 加测试：宿主 / 查看器的 PROTO 与模块一致。
  - 注明 schema 只做部分形状检查。
  - 另外修了一个 P0：**`outfit` 实际发的是对象**。按原来的 schema，协议模块加载后，所有着装消息都会被丢弃。这是跑全套浏览器测试时 mvu093 报出来的。
- **性能**：预热改为「按层记账」，后来进了同组还会补 L10；途中切图就停；dzi 解析成功才记；省流时不记；定时器去重。文档写明省下的流量有一部分会挪到第一次打开那张图时，并补测了切图代价。
- **UI / UX**
  - 「未上图」标签加省略号，不再压住标题。
  - 压在控制列下面的图钉让开。
  - 上手提示要点掉才算看过（最多出 3 次），桌面和手机分开措辞。
  - 未上图空状态复用节点、加播报。
  - 清理的等待秒数至少 1 秒。
  - 刷新载入失败时有兜底。
- **产品**：上手提示提到三维；未上图空状态说明「放一次，这个聊天之后都会记住」；设置「高级」里可以「再看一次」上手提示。
- 全套浏览器测试另外抓到一个问题：嵌入时通知里带着函数（onClose），`postMessage` 报 DataCloneError（e7_host）。已修。
