# C3 庄园门控 · 本机实测（2026-09-27）

环境：
- 服务：本机 `python3 -m http.server` 服务 `map/`，未压缩。
- 浏览器：Playwright 驱动 **headless Google Chrome**（ANGLE Metal，Apple M5）。
- 条件：没有网络节流，也没有 CPU 节流。
- 帧率是 headless 下的数字，不代表真机。
- 手机按 375 × 812、DPR 2、isMobile + hasTouch 模拟。
- 脚本在 scratchpad 的 `c3/gate.mjs`，没有入库。

## 近景（`#card .cu`「细节 ›」依次切换）

- **主浴室 316**：3 个视点（毛巾与台面 ×2、马桶间）。
- **访客盥洗室 103**：4 个视点（毛巾与台面 ×2、马桶间 ×2，含高位水箱）。
- **客房 A 219**：3 个视点（黄铜毛巾架与搭挂毛巾、洗手台、马桶间）。
- **床（主卧 315）**：页面没有床的近景视点。这张是本机把相机直接拉到画面高 3.4 m 拍的。
- **真实素材**：`map/estate/assets/` 不存在，没有用任何 CC0 真实素材。马桶、毛巾、床品全是程序几何加 canvas 纹理（任务 7 第 3a 条原本要求走 CC0）。

## 查看器嵌入（`viewer.html`，从世界图 → 上层 → 伊甸地标进入）

- **桌面**：
  - 楼层条 9 个按钮的中心点都落在庄园 iframe 上。
  - 导览条没有被遮挡。
  - 嵌入后整页传输 3.2–3.5 MB（含世界图与上层瓦片）。
- **手机，修之前**：
  - **R02 复现**：「外观」「全部」的中心点落在查看器的「下层」按钮上。
  - **R11 复现**：导览条左端落在层按钮上。
  - 换当前地点（`eden-map:here` 书房）以后，导览条仍留着。
- **手机，本机修之后**：
  - 改法：`viewer.html` 在窄屏且进入庄园时，层按钮改成底部一行，iframe 让出 46 px。
  - 结果：9 个楼层按钮、导览条 3 个采样点都落在庄园上；父页面 scrollY 为 0。
  - 「换地点后导览条仍留着」要庄园页在收到 `estate:room` 时关掉导览，归云端。
- **手机，修之后仍有的问题**：导览条（bottom 60 px）盖住庄园自己的 + / − / 复位按钮的下半部分，归云端。
