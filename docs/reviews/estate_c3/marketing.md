# C3 庄园终审 · 顶奢地产营销视角

**评分：6.5 / 10**（v2 云端审阅给 8.5；本轮按「顶奢 + 传承 + 马桶毛巾有质感」三条用户原话独立打分，未沿用）

## 做得好的
- **外观构图对**：中轴大道 → 花坛 → 门廊 → 圆顶，五段式立面一眼读成庄园；家徽 + 「始建约一百九十年 · HORTUS SUPRA NUBES」标题是最强的传承钩子。
- **马桶读得清**：主浴室和盥洗室的马桶都有桃花心木座盖、莨苕叶纹基座、黄铜冲水杆/纸架；盥洗室高位水箱 + 黄铜拉链 + 瓷拉手，是全片最有「老宅」味道的一张。
- **卡片文案一流**：「桌面皮子换过四次，墨水渍一直留着」「每一代新家主移肖像」这类句子正是顶奢经纪会写进 brochure 的东西。
- **主卧床**：床头家徽、四柱纱幔、床尾凳、枝形烛台，氛围到位。
- **v2 第 1 条已部分落实**：主浴室马桶间已排到最后（3/3）。

## 问题
### P0
1. **毛巾没有达到「清楚有质感」**（用户原话，是交付门槛）。
   - 客房 A 毛巾架上的两条毛巾半透明、发白，几乎和奶油色墙面融为一体，看起来像塑料薄膜。
   - 洗手台上的叠放小方巾像两块白色蛋糕盒，顶面一个蓝点。设定里的「12 条、三折、金线绣家徽」读不出来，看不出层数和边缘。
   - 设定中的蜂窝纹擦手巾、藤编篮都没有近景。
   - 修法（`map/estate/*`，云端）：
     - 毛巾改成不透明（opacity 1，关 transparent），基色压到 #efe9df，和墙面拉开明度。
     - 叠放毛巾做出逐层圆角的折边（每层一条暗缝阴影），侧面用毛圈法线/粗糙度纹理。
     - 家徽绣标放大到正面可读，换成金线色，删掉蓝点。
     - 毛巾架的毛巾要有垂坠下摆。
     - 近景 1/3 的机位再拉近约 40%，让毛巾占到画面 1/3。
2. **镇宅之宝缺席**：主浴室的传承细节写的是「三代整块 Statuario 浴缸」，可 3 个近景里没有浴缸。卖点写在卡片上，画面里却看不到，这是营销上最大的漏洞。
   - 修法（云端）：主浴室近景加一个「浴缸」视点，排第 1 位；毛巾台面第 2，浴袍第 3，马桶间第 4。

### P1
3. **大理石纹像卡通裂纹**：纹路是等宽的棕色长曲线，稀疏又均匀，看起来像瓷砖贴纸，是「新样板间感」的主要来源。
   - 修法（云端，canvas 纹理）：纹路改成粗细渐变的灰金主脉加细网次脉，透明度 0.3–0.6；底色加低频云雾噪声；台面加一层清漆高光（roughness 0.15）。
4. **整体太新、太干净**：外观草坪是均匀的高饱和黄绿色，近景没有任何使用痕迹，像开发商的新盘。
   - 修法（云端）：
     - 草坪饱和度降约 15%，偏橄榄色。
     - 按 v2 第 4、5 条补上中轴修剪条纹和门廊柱影；v2 第 2 条窗光同样没见到，一并补上。
     - 黄铜统一改成做旧色 #b8914a（现在是亮柠檬金，偏廉价），高光保留，把饱和度压下来。
5. **大厅黑白棋盘地面加红柱**，第一眼像酒店或赌场大堂。
   - 修法（云端）：v2 做的「灰褐与奶油斜铺」在这张图里没看到，请确认它是否在门控构建里生效；红柱改成仿云石或奶油色，也可以只留门口两根。
6. **嵌入态开场卖点弱**：手机嵌入后导览的第 1 站是「停靠平台引导环 · 门把手」，又占满画面上半部。
   - 修法：导览第 1 站换成门廊/家徽山花或长箱钟（云端，改 tour 顺序）。
   - 导览卡在手机上压住 + / − 按钮，这一条归云端；measurements 已记录。
### P2
7. **营销截图**：除 m375 外，都带着 `T0 · fps · calls` 统计浮层（v2 第 7 条原样重现），主浴室那张还显示 3 fps。对外素材请去掉 `?stats=1`（截图脚本，本地）。
8. **浴袍**：板状，袖子是方块，缺少厚度和垂感。可以加腰带垂尾，领口折边加厚。
9. **床品**：金色床旗像一块平板塑料。可以加织物纹理和两端下垂的折边。
10. **盥洗室近景 3/4**：机位把高位水箱的顶部切掉了，而铭牌正是这间的传承细节。相机需要下移，并把铭牌拍进画面（云端）。
11. **viewer.html（本地）**：手机修复后，底部层按钮一行和庄园楼层条上下叠成两行按钮带，视觉上很拥挤。进入庄园后可以把查看器那一行改成单个「返回上层」胶囊。

## 明确回答
- **(a) 马桶、毛巾近景是否清楚、有质感？** 马桶是：两处都清楚，也有老宅细节。毛巾否：叠放那组像盒子，毛巾架上的半透明发白，读不出毛圈质感和金线家徽，没有达到用户原话的要求。
- **(b) 是顶奢加传承，还是新样板间？** 宏观构图和文案是顶奢传承；材质层（卡通大理石纹、亮柠檬金、均匀亮绿草坪、零使用痕迹）把观感拉回「新建展厅」。现在讲故事的是文字，不是画面。
