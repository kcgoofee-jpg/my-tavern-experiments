# C3 门控 · 建筑师独立评审（新古典 / 帕拉第奥向）

**评分：6.5 / 10**（云端 v2 自评 9 分偏高。体量和柱式骨架已经站住，但立面材质、屋顶用途和两处毛巾近景拖了"传承感"和"质感"的后腿）

依据：`docs/drafts/estate_gate_*.jpg` 共 11 张，另有 `c3/out/desk_ext.png`、`desk_F5.png` 的局部放大，以及 `measurements.md` 和 `eden-estate.md` §柱式/标高。

## 做得好的
- **轴线与总图**：中轴大道、喷泉、对称花坛、门廊、主楼穹顶、北湖在同一条轴上。两翼经连廊接到图书馆塔楼和音乐厅亭，是标准的帕拉第奥五段式，从外观一眼能读出来。
- **柱式**：科林斯巨柱式贯通 F1–F3，D 1.35、柱高 13.5 m（10D），中跨放宽。连廊用爱奥尼。柱式等级（主楼高、连廊低）是对的。
- **屋顶**：两翼铅皮平顶已补上烟囱，位置落在承重墙线上，结构上可信。
- **室内格局**：大厅是棋盘大理石地面加斑岩色柱，肖像廊是绛红锦墙加肖像加长地毯，主卧有家徽床头和四柱帐。"礼仪层 → 私人层"的层级在平面上读得出来。
- **马桶**：访客盥洗室是高位桃花心木水箱、黄铜落水管、拉链瓷坠，外加凹槽柱式底座和桃花心木座圈。这是全场最有"传承"味的一件器物。
- **洗手台**：十字柄加鹅颈龙头、桃花心木框板柜、Statuario 台面，比例正确。
- **缩放**：以光标为中心缩放，漂移 0 px；支持双指捏合、双击拉近、+/−/复位。用户原先抱怨的缩放难用已经解决。

## 问题

### P0
1. **外立面是"新刷的白模"，看不出两百年的石头**（`building.js` 外墙/窗材质）。
   - 现状：全楼同一种纯白，没有石材色差，F1 粗面石基座几乎看不见；窗洞是橙褐色的实心块，读成百叶或砖，不像玻璃。整栋楼远看像售楼处的展示模型，这是"新展厅感"的主要来源。
   - 修法一（墙）：墙体改成暖灰的波特兰石色（约 #E6DFD0）。F1 加深一档，并把分缝刻深。檐口和窗套用浅一档的颜色。整体加一层很淡的竖向雨痕或风化 AO（canvas 噪声即可）。
   - 修法二（窗）：窗改成深色玻璃（#2B3238，带一点反射），配 6+6 白色窗棂。
2. **中央屋顶平台做成了度假酒店的屋顶露台**（`building.js` F5 / `furniture.js` 眺望层）。
   - 现状：玻璃盒子、一圈蓝色环形座椅、成排躺椅，直接破坏"传承"。帕拉第奥宅邸的屋顶只有栏杆、烟囱、穹顶和灯笼亭。
   - 修法：删掉玻璃盒和躺椅。眺望亭改成穹顶顶部的石质灯笼亭（lantern），或者一座铅皮小观景亭（belvedere），配铸铁座椅 2–4 张即可。
3. **客房 A 毛巾架上的搭挂毛巾像半透明的纸或纱**（`furniture.js` `towelHang` / `panelG`）。
   - 现状：厚度 t 0.012 太薄，在亮光下发白、发透，看不出绒圈。这是用户点名的物件，不能过门。
   - 修法：t 提到 0.02–0.025。材质改为不透明，roughness 0.95，并加 sheen。贴上与叠放毛巾同一张绒圈法线/凹凸纹理。下缘滚边加粗，颜色压暗 5%，让边缘出现阴影。

### P1
4. **叠放毛巾像两块方糖**（`towelStack`）。现状是折层分得不开，侧面缺少圆鼓的折边层次。修法：折边圆角半径拉到厚度的 0.5，每层之间留 3–4 mm 暗缝，上下两层错开 5–8 mm；家徽圆片从蓝点改成浮雕金线小盾徽。
5. **洗手盆左侧有一圈虚线弧**（主浴室近景 1，`furniture.js` 台盆）。看起来是溢水孔或盆沿的碎几何在穿插，读成瑕疵，需要清掉或改成实心盆沿。
6. **层高一律 4.5 m，没有主层（piano nobile）**（`eden-estate.md` 标高 / `building.js` 窗型）。帕拉第奥宅邸应当 F1 基座略矮、F2 主层最高且窗最大、F3 方窗更小。现在三层窗几乎等高，立面没有主次。
   - 不改楼面标高也可以做：F2 窗加高 0.6 m，配三角/弧形窗楣和栏杆；F3 窗压到 F2 的约 2/3。
7. **主浴室马桶的低位水箱是一个白方盒，悬在墙上**（`furniture.js`）。修法：水箱加线脚盖板和黄铜铭牌；落水管和盆接处加法兰。它的"质感"比访客那只弱一档。
8. **所有质感都靠程序生成的 canvas**（`measurements.md` 指出 `map/estate/assets/` 不存在）。任务 7 第 3a 条要求用 CC0 实拍素材，这条没落实。修法：至少给毛巾（绒圈）、大理石、桃花心木三种材质换上 CC0 的 1K 贴图（ambientCG / Poly Haven），预算足够（现在总共 1.26 MB）。
9. **手机端导览条盖住 + / − / 复位按钮的下半部分**（`map/viewer.html`，或 `index.html` 的控件定位）。修法：导览条出现时，控件上移 64 px；收到 `estate:room` 时关掉导览条。
10. **近景性能**：主浴室近景截图显示 3 fps，那一帧有 550k 三角形（可能是截图时刚切换视点）。需要确认 `FINE` 层的 LOD 在近景时只加载当前房间。

### P2
11. **门廊山花**：斜檐仍然没有齿饰，从外观远景看是一块光板（上一轮第 3 条未做）。
12. **大厅斑岩柱是独立圆柱，上面没有额枋**。它们既然承重（规格书写的是承托鼓座），就应该连上一段额枋，否则读成摆件。
13. **穹顶与门廊比例**：从正面看，鼓座加穹顶被 31 m 宽的门廊压住，显得小。可以把鼓座再加高 1 m，或加一圈柱廊（peristyle）。
14. **景观树是低多边形的切面团块**，与"写实"基调不一致（`site.js`）。至少近主楼的两排改成更圆润的树冠，配两种绿色。

## 明确回答
- **(a) 马桶、毛巾是否清楚、有质感？** 马桶是（访客那只高位水箱很好，主浴那只及格）。毛巾只算一半：叠放的读得出但像方块，毛巾架上的搭挂毛巾发透、像纸，不达标。
- **(b) 是顶奢传承，还是新展厅？** 室内靠家徽、肖像、高位水箱和卡片文案，传承感基本立住了。外观是纯白无风化，屋顶又是酒店露台，整体仍偏"新建的展示模型"。修掉 P0-1 和 P0-2 之后才算过线。

内容合规：没有看到不当道具，私人房间陈设中性。
