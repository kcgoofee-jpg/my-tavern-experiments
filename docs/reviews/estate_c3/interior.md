# C3 室内终审 · 伊甸庄园（室内设计师视角）

**评分：6.0 / 10**（云端 v2 给 8.0。我不同意：v2 修掉的是「看得到」，用户要的是「有质感」和「传承感」，这两条都还没到顶奢水准）

依据：`docs/drafts/estate_gate_cu_*.jpg`、`desk_rooms/floors`、`m375`，scratchpad `c3/out/desk_cu_*.png`，`measurements.md`，`map/estate/furniture.js`（`toilet` / `towelStack` / `panelG` / `towelHang` / `robe` / `bed`），`lib.js`（材质）。

## 做得好的
- **马桶的类型学是对的**。维多利亚莨苕基座、桃花心木座圈和盖板（盖板掀起一个小角度）、大理石盖低水箱、瓷球杠杆、落地铜纸巾架都在。访客盥洗室是高位桃花心木水箱，配铜冲水管、铜链和瓷拉手，并有铸铜铭牌。家族宅邸就该选这种器型，不像酒店。
- **五金统一**：全宅是抛光黄铜（`brass` 粗糙度 0.2），十字把手、鹅颈龙头、铜钩、梯形毛巾架整套一致。
- **织物有家族标识**：叠放毛巾前沿有金色刺绣带，外加 3 cm 珐琅家徽圆片。浴袍胸前有金徽。这是老宅「定制布草」的正确语言。
- **动线分区清楚**：主卧、主浴、更衣在 3F 私人层成套；1F 访客盥洗室有前室，外加两间独立马桶间；4F 为服务层。主仆分离合格。
- **楼层总览成立**：黑白棋盘大厅配仿斑岩柱，主卧有凡尔赛拼花和大地毯，肖像廊是红色丝绒墙配肖像。
- **材质表可用**：Statuario / Calacatta / Nero 大理石，桃花心木清漆（clearcoat 0.3）。卡片上的「传承细节」文案很好，比如浴缸石料来自已经封矿的旧采石场。

## (a) 马桶、毛巾近景是否清楚、有质感？
**马桶清楚，质感一般；毛巾认得出，但没有质感。**
- **马桶**
  - 形体和五金都读得出。
  - 瓷面发白、发平，只在碗沿有一点高光，看不出釉面的深度和环境反射，像白色塑料（`porcelain` 有 clearcoat 1，但环境贴图太弱）。
  - 基座上的 12 个浮雕叶片像一圈白色豆荚，读不出莨苕叶。
  - 主浴马桶间的前景被两块白色截墙挡住。访客马桶间的高位水箱被画面顶边切掉一半，这个问题 v2 已经提过，仍未修。
- **叠放毛巾**（`cu_vanity_towels`、`客房 A_2`）
  - 读起来仍是「白色方盒」。每折之间没有阴影缝，侧面没有圆润的鼓起，绒圈法线（`TEX.towelN`，64² 贴图，米数 0.035）在 1440 宽的近景里只剩细碎噪点。
  - 家徽圆片是一个蓝色小点，看不出是刺绣。
  - 垂边在主浴里几乎看不到。
- **搭挂毛巾**（`cu_towel_rail`）
  - 已经不再是透明的幽灵片（`towel` 改成了 DoubleSide）。
  - 但整体过曝、灰白、没有体积，像两张纸挂在杆上。软褶幅度 0.012 m 太小，看不出垂坠。
- **浴袍**（`cu_robes`）
  - 轮廓成立，但它是挤出的厚片加方盒袖子，像纸样。华夫格纹理基本不可见。
- **床**（`cu_bed`）
  - 枕头的层次还行。
  - 被面是直角方块，四边不下垂。床尾的金色搭巾是一块纯黄平板，没有丝或缎的反光。

## (b) 顶奢传承，还是新样板间？
**更像刚竣工的样板间。** 「传承」目前主要靠卡片文字，而不是材料本身。
- **所有表面都是同一种「新」**：
  - 桃花心木的色值、纹理均匀，没有日晒褪色。
  - 黄铜全部是镜面金，没有包浆，把手处也没有摸亮的对比。
  - 大理石没有磨损和蜡光的区别。
- **大理石纹理**
  - 纹路像褐色树根或裂缝，而且墙、台面、地面用的是同一张图。v2 第 5 条提过，没有修。
  - 顶级 Statuario 应该是灰调的细长主纹，不该是这样的褐色网纹。
- **镜子是平灰色圆盘**，没有反射，也没有年代感（比如镀银老化、镜框鎏金磨出底色）。
- **器物没有时代混搭**：没有旧地毯的磨白、古董钟、银器这类「代代添置」的层次。

## 问题与修法

### P0（直接对应用户要求）
1. **毛巾没有「质感」**（`furniture.js` 中的 `towelStack`、`panelG`，`lib.js` 中的 `towelN`）
   - 按 `CLOUD_TASK7.md` §3a，接入一套 CC0 毛巾或织物 PBR（Poly Haven 的 terry / fabric 类，512² 的 normal 加 roughness 加 AO），近景 fine 批次专用。
   - 如果坚持程序化：
     - `towelN` 升到 256²，绒圈半径加大，米数改成 0.02。
     - 加一张 AO/颜色贴图：折层之间压暗 25%。
     - `foldG` 两端也要圆角。
     - 每折之间插一条 0.003 m 深色缝。
   - 搭挂毛巾：`panelG` 的褶幅从 0.012 加到 0.025–0.03，底边滚边加粗；材质 sheen 降到 0.4，避免发灰过曝。
2. **瓷面和织物缺少近景光照**（`main.js` 中的 closeups）
   - 近景模式下临时加一盏暖色小 spot（或 RectAreaLight）打侧光，用来把绒圈法线和瓷釉高光拉出来。
   - 马桶近景的环境贴图强度（envMapIntensity）调到 1.2 以上，并给 `porcelain` 加 `sheen: 0` 和 `ior 1.5`，形成釉层反射。

### P1
3. **近景构图**
   - 访客盥洗室的马桶间视点要把高位水箱整体框进画面，画面上沿多留 0.6 m。
   - 主浴马桶间的前景截墙，在 close 模式下降低高度或隐藏。
4. **台盆边缘的黑色虚线（z-fight）仍在**（`basins`）
   - 在盆沿加一圈 `porcelain` 环盖住，或把挖孔缩小 5 mm。v2 第 4 条提过，未修。
5. **大理石纹理**（`lib.js` 中的 `marbleCanvas` 与 statuario/calacatta 两张图）
   - 主纹改成灰色，线宽 ×0.5，透明度 ≤ 0.35。
   - 墙和台面分开用两张图，墙面米数从 1.6 提高到 2.4。
6. **做旧层**
   - 黄铜：新增一个 `brassAged` 材质（粗糙度 0.35，色偏 #A88A45），用于把手、龙头以外的五金。
   - 桃花心木：加一层低频明暗 mask。
   - 镜子：`mirror` 加边缘暗化的 vignette 贴图。
   - 地毯：主走道方向磨淡 10%。
7. **床品**（`bed`）
   - 被面四边下垂 0.25 m，边缘做圆角。
   - 床尾搭巾改成 `silk`/缎材质，粗糙度 0.3 加 sheen，颜色压到旧金色 #B89A5A。
   - 主卧要补一个床的近景视点：目前页面上没有，C3 的床图是手动拍的。

### P2
8. **细节**
   - 马桶基座浮雕改成真正的叶形截面（lathe 或 extrude 叶片），或者去掉，改为素面加线脚。
   - 家徽圆片直径从 3 cm 放大到 4.5 cm，近景才读得出。
   - 访客台面上的绿色皂碟造型含混，建议换成银质或瓷质皂碟。
9. **浴袍**（`robe`）
   - 华夫格改用独立的格纹法线贴图。
   - 袖子从方盒改成锥形 lathe 或 extrude。
   - 衣摆加一点摆动的曲面。

## 结论
**不过门。** 器型选择和空间规划有顶奢的骨架，但近景质感还停在「白模加色块」这一层。用户点名要「毛巾清楚有质感」，这一条没有达到。修完 P0 两条（最好用 CC0 织物 PBR 加近景补光）并补上做旧层以后，可以到 7.5–8。
