# 以太气候调节塔 评审（2026-09-28）

卡：天城的气候由以太气候调节塔人工维持（四季分明，没有极端天气；庄园窗外是「被以太气候塔调过的」天气）；事件示例有「塔体保养·第三环停机」。卡没写位置，地图放在上层（仓库推断）。三维与上层底图一致：深色石塔身直径约 40 m、从中层伸到约 950 m，塔顶环台、金冠环、悬浮以太晶冠、云面青色光晕。模型是塔顶约 260 m 与晶冠。
