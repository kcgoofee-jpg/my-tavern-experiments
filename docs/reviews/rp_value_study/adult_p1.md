# 人设 A1 · 成年重度成人向 RP 玩家（28 岁，每天长时间游玩，场景频繁切换，沉浸优先，桌面为主）

> 说明：本文只讨论功能、流程、隐私、沉浸与性能；成人向内容一律中性称为「成人向场景 / 私密场景」。卡内所有角色均为成年人。

## 1. 我什么时候、为什么打开地图；看什么
- **场景切换的那一刻**：模型把场景从「家庭餐室」切到西翼主人私区，我要确认地图跟上了。看的是标题栏那行「当前地点：…」（`push()` 调 `getHere()` 读 MVU `stat_data.世界.当前地点`，`{{user}}` 由 `userName()` 替换）。一晚上切十几次，每次只瞄 2–3 秒。
- **私密场景里想确认「这间房在哪、隔壁是谁的」**：庄园房间级视图（`docs/eden-estate.md` F3 私人层 301–309）对沉浸帮助最大——知道门禁门、侍从间、仆役楼梯在哪，写出来的动线才合理。
- **角标亮了**：`recompute()` 从最近 `SCAN = 40` 楼重算事态，有新事就出角标。在私密场景中途我多半不点，等场景结束再看。
- **很少看底图本身**。面板关掉走 `sleepViewer()`，3 分钟内重开秒开——这对「频繁开关」是刚需。

## 3. 什么会让我停用
- **流式输出时卡顿**：`MESSAGE_UPDATED` 高频触发 `recomputeSoon()`，长回复里如果掉帧，我直接关脚本。
- **跟随停在上一个房间**：我用自己的房间叫法，认不出就「不动地图」（回落规则），久了我会不信任它。
- **切聊天串状态**：从一个存档切到另一个，地图还停在上个存档的房间或事件。
- **回注扰戏**：`injectPrompts` depth 4 的态势摘要在私密场景中被模型反复提起城市事态，破坏节奏。
- **面板挡输入栏 / 打开慢**：一晚上开关几十次，每次多 1 秒都会累积成放弃。

## 5. 架构上该怎么支撑我
- **全部本机**：别名、笔记、场景状态、人员位置都存 `localStorage`，键名按 `chatId` 分（照 `edenMapSeen:<chatId>` 的做法，如 `edenMapNotes:<chatId>`、`edenMapWho:<chatId>`），不联网、不进 CDN、不进仓库。
- **不审核**：沿用 `docs/content-compat.md`——地点和事件原样解析，地图只管位置与显示，不读、不判断场景内容。
- **扩展接口优先于内置功能**（E6）：`EdenMap.on('here')` 已能驱动场景历史；补一个 `EdenMap.setWho(角色, 房间)` 和 `EdenMap.note(房间, 文本)`，由本机脚本或手动面板写入，地图只负责画标记。
- **注入可控**：`inject()` 加一个本机开关（关闭 / 仅场景切换时 / 始终），默认不变；笔记永不注入。
- **性能**：`recompute()` 在流式期间节流到生成结束（已有 `GENERATION_AFTER_COMMANDS` 同步点），切聊天时清空上一聊天的地点与事件再重算。

## 6. 一句话结论
对我来说地图的价值在「室内、跟得准、切得快」：先把当前地点跟随 + 自定义叫法 + 房间级视图做稳，再按聊天隔离地加上「谁在哪」和私人房间笔记，渲染和 3D 可以排后。
