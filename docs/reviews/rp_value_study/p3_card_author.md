# 人设 3 · 制卡作者：这套地图对我的卡值多少

> 我是写卡的人，不是做渲染的。我想把地图接进自己的卡，但不装 Blender、不学管线，而且我自己还会不停地更新卡。以下判断基于仓库的实际实现。

## 1. 玩家什么时候打开地图？我最看重它带来什么
- **打开时机**：(a) 剧情里换了地点（`eden-map.js` 读 MVU `世界.当前地点`，悬浮按钮右上角亮红点）——玩家想知道「我现在在哪、旁边有什么」；(b) 悬浮按钮上出现事态数红标（`em-badge`），玩家好奇「城里出什么事了」；(c) 想找下一个去处、要找人的时候。大部分时间玩家都在读文字，地图每次只开十几秒。
- **我最看重的**：**世界观可信、剧情有连续性**。事件标签落点（`data-tcmap`）加上态势回注（`injectPrompts` 深度 4、≤80 字），让模型记得「7 号井昨晚起火」。这相当于替我的世界书做了一份活的状态账本，也是玩家会截图、会回来反馈的部分。底图只要「好看、像这个世界」就够了，多一层写实，玩家不会多聊一轮。

## 3. 什么会让我放弃接入
1. **底图非 Blender 不可**。`render-performance.md` 里四张 8K 要 1 小时 40 分钟，这还是 M 系列 Mac 的数据；再往前还有 A1–A7、B2 多轮四审阅。作者复制不了这一套。
2. **核心代码里写死了本卡设定**。`events.mjs` 的 `layerGuess` 用正则硬编码「伊甸 / 7 号井 / 血肉磨坊」，64 种类型和发布机构全是天城的名字。我换一个世界观，就得 fork 源码。
3. **我改卡以后地图坏掉，而且没人告诉我**。我改了地名，`alias` 对不上，地图就静默「不动」，没有任何报错。
4. **一出 bug，玩家骂的是我**。E4b 仍有 P1：R01 屏幕正中有点不开的死区，R02 手机庄园按钮误触会离开庄园。
5. **文档互相矛盾**：`map-events.md` 还写着「性相关词整条丢弃」，`content-compat.md` 却说已经取消过滤。我不知道该信哪一份。

## 5. 直接意见
- **渲染还要做多少轮**：天城这张收尾就停——B2 用完第 3 轮就按最高分版本发。把渲染轮次换成 TT 稳定性和接入工具。
- **通用化时底图该多写实**：「一张像样的图 + 准确的点位」就够了。Blender 写实只做可选的示范档，默认档必须是作者不用 Blender、一个下午就能出图的轻量方案。

**一句话**：我的玩家为剧情连续性打开地图，不是为了看像素；接入、维护和稳定这三关里只要有一关过不去，渲染再好我也不会接。
