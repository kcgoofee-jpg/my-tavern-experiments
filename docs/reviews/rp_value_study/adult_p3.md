# 人设 A3 · 重视隐私的成年成人向 RP 玩家（30 岁，隐私敏感；桌面 SillyTavern 为主，偶尔在通勤 / 共享空间用手机 TT）

> 说明：本文只讨论功能、流程、隐私、沉浸感与性能。卡内成人向 / 私密场景一律中性指代，不涉及具体内容。所有角色均为成年人。

## 1. 我什么时候、为什么打开地图；看什么
- **进入私密场景前**：剧情从 F1 礼仪层转到 F3 私人层（`docs/eden-estate.md` 的 312 主人起居室、315 主卧、317 寝、320 私人房间 A 等，房间本身都是中性建筑描述）。我点开地图确认「在哪一间、隔壁是谁的房间、门禁在哪」，保证空间逻辑不穿帮。看的是标题栏 `em-here`（`eden-map.js` 的 `getHere()` 读 `stat_data.世界.当前地点`）和庄园房间高亮。
- **场景之间的过渡**：私密场景结束后回到公共区域，我用地图找「下一个去处」，顺带看角标——`recompute()` 从最近 `SCAN = 40` 楼算出的事态，决定外面有没有需要回应的事件。
- **续档**：隔天回来，先看地图恢复「谁在庄园哪里」。现在地图只知道我在哪，不知道其他角色在哪。
- 一次打开 5–20 秒。我更在意**打开时屏幕上出现什么字**，而不是底图多精细。

## 3. 什么会让我停用
- **任何可见的审核 / 过滤**：地点或标签因为词汇被改写、丢弃、打码。`docs/content-compat.md` 已去掉关键词过滤、认不出归「其他」，这条必须长期保持。
- **尴尬的界面文字**：标题栏直接显示「当前地点：主卧」、角标数字跳动、首次提示气泡 `tipOnce()`「天城有新事态…」在别人能看到屏幕时弹出。手机上悬浮按钮也是一个可见信号。
- **数据离开本机**：查看器从 jsDelivr / jsdmirror 取静态资源可以接受；但如果当前地点、别名、覆盖层内容进入任何 URL、日志或远程请求，我会立刻卸载。
- **跨聊天泄漏**：`edenMapCustom` 是全局 localStorage，一个聊天里起的房间别名会出现在另一个聊天（或别人借用同一浏览器时）。
- **回注打断节奏**：`inject()` 在 depth 4 注入事态；私密场景中模型突然插入城里的事件会出戏。
- 流式输出时卡顿、面板打开慢于 3 秒。

## 4. 缺什么
| 缺项 | 分 |
|---|---|
| 低调模式：中性标题（只显示「地图」）、隐藏当前地点行、角标只显示圆点或关闭、关闭提示气泡 | 10 |
| 一键隐藏（快捷键 / 双击按钮，面板与按钮同时收起） | 9 |
| 谁在哪（角色 → 房间，读 MVU 或本机手填） | 8 |
| 每个房间的场景状态（门开 / 关、灯光、「请勿打扰」这类中性状态） | 7 |
| 本机私人房间笔记（按聊天隔离，不进回注） | 7 |
| 回注暂停开关（「本场景不注入事态」） | 7 |
| 所有本机状态按聊天隔离（别名、显示名、覆盖层、笔记） | 8 |
| 一键清除本机数据 | 6 |

## 5. 架构上该怎么支撑我
- **原则**：仓库与 CDN 只放中性地图、建筑与接口；用户个性化只在本机，不审核、不上报。E6（`docs/GOAL_v0.9.1.md` 的 `window.EdenMap`）是正确方向。
- **存储**：`edenMapCustom` 改为按聊天分键，例如 `edenMap:chat:<chatId>:{alias,names,notes,scene,who}`，沿用 `chatKey()` 取 `chatId` 的做法；全局只留外观设置（语言、主题、线路、按钮位置）。提供 `EdenMap.clearLocal({ chat })`。
- **接口建议**：
  - `EdenMap.setPrivacy({ neutralTitle, hideHere, badge: 'count'|'dot'|'off', tips: false })`，存本机；外挂脚本读取后控制 `em-title` / `em-here` / `em-badge` / `tipOnce()`。
  - `EdenMap.hideAll()` 与可配置快捷键。
  - `EdenMap.setRoomState(room, { door, light, note })`、`EdenMap.setWho(name, room)`：只画在本机覆盖层；`on('here')` 已有，可联动。
  - `EdenMap.setInject(false)` 或按场景暂停 `injectPrompts`；笔记与房间状态**默认不进回注**，用户显式勾选才进。
- **绝不能进 CDN / 仓库 / 网络请求**：当前地点原文、房间别名与显示名、覆盖层内容、笔记、角色位置、聊天 ID。资源 URL 只能带版本号，不带任何状态参数；示例扩展保持空壳。
- **测试**：加一条自动检查——打开面板、切换地点后，网络请求列表里不出现地点字符串或 localStorage 值。

## 6. 一句话结论
房间级跟随已经很有用，但让我每天放心打开的是「低调模式 + 一键隐藏 + 按聊天隔离的本机数据」；E6 先把这三件做成默认可用，再谈覆盖层与 3D。
