# P5 · 低端机 / 弱网用户：地图在聊天 RP 里值多少

> 人设：三四年前的千元安卓机或旧 iPad，内存 2–3 GB，国内网络，jsDelivr 时通时断，流量按月算。视角是第一人称，依据仓库实现与实测体积（2026-09-27，分支 `cloud/tc-mid-low`）。

## 先看我要付多少流量（实测）
- 程序：`viewer.html` 104 KB，`eden-map.js` 36 KB，OpenSeadragon 340 KB，`events.js` 40 KB。
- 瓦片（中层 `tc_mid_files`，每块 512 px）：L11（2000 px，省流档上限）共 12 块，508 KB；L12（标准）1.46 MB；L13（8K 清晰）4.08 MB。整套金字塔 6.1 MB，世界图 2.3 MB。
- 我的机器内存 ≤ 4 GB，`lean()` 会判为省流模式：自动档封顶到「标准」，后台不预热别的图，点开之前只花约 50 KB（E4 N02）。**一次会话看一两层，实际花 0.5–2 MB。这可以接受，也是这个项目最让我放心的地方。**
- 庄园 3D：three.js 加页面脚本约 1.4 MB，外加主线程构建。ui-audit R12 实测 Slow 3G 下 59–67 秒才能用，N10 实测构建时卡死 17–45 秒。这对我来说就是个坑。

## 1. 我什么时候开地图，看什么
- 剧情里出现一个我不熟的地名，或者角色说「去下层」，我想知道这地方在哪、离我多远。
- 悬浮按钮上的角标变了，说明有新通报。我点开看是哪儿出了事，跟我有没有关系。
- 换场景、隔了几天回来接着聊时，我用它看一眼「我现在在哪」。

真正看的就是**红点在哪、我在哪、地名叫什么、这事是什么**，每次 5–15 秒就关。我从来不会放大去看楼顶上的空调外机。

## 2. 各项的价值和我注意力的占比
| 项 | 对我的价值 | 注意力占比 |
|---|---|---|
| 全图渲染的真实感和美观 | 4 | 5% |
| 放大后的渲染细节（8K 局部） | 1 | 1% |
| 加载速度 / 秒开 | 10 | 20% |
| 当前地点自动跟随（`here.mjs` 六级回落） | 9 | 15% |
| 聊天事件标记与事件流 | 8 | 15% |
| 地图 → 聊天操作（规划中） | 6 | 5% |
| 态势回注给模型（`injectPrompts`，depth 4） | 7 | 4%（我看不见，但它让剧情前后对得上） |
| 庄园房间级视图 | 5 | 4% |
| 3D 庄园 | 2 | 1% |
| 双语 / 主题 | 2 | 1% |
| 自定义（房间名、本地覆盖层） | 4 | 2% |
| 在 TT 里稳定、没 bug | 10 | 15% |
| 手机操作体验 | 9 | 12% |

合计 100%。其中「快、稳、手机顺手」三项占 47%，「我在哪、出了什么事」两项占 30%，渲染画面两项加起来只占 6%。

## 3. 什么会让我不再用
1. **聊天页被拖卡**。流式输出时输入框卡顿，或者页面因为内存被系统杀掉重载，我会直接把脚本关掉。这一条比地图难看严重十倍。
2. **白屏或一直转圈**。jsDelivr 抽风时，现在有「重试 / 换线路」（jsdmirror），20 秒没进度会提示，这个做得对。但如果我要手动选一次线路才能用，我只会试一次。
3. **误进 3D 庄园**。自动跟随把我带进庄园，然后卡几十秒、连「×」都点不动。现在失败 0.6 秒会退回平面图，也会记住，但「慢」还不算「失败」，最好别自动进 3D。
4. **偷偷花流量**。按清晰档拉 8K 瓦片（单层 4 MB 以上），或者后台预热。现在已经封顶到标准，千万别改回去。
5. 按钮挡住聊天输入框，或者按钮拖不动。

## 4. 缺什么我会在意
| 需求 | 分数 |
|---|---|
| 纯文字 / 低清降级模式（只有地名列表、事件列表和一张 1200 px 小图，比如已经有的 `world_1k.jpg` 120 KB） | 9 |
| 离线缓存（Service Worker 或 Cache Storage，下次打开不再走 CDN） | 9 |
| 任务图钉 / 我自己钉的点 | 7 |
| 地点间移动 / 路线（从 A 到 B 要过几道检查点） | 7 |
| NPC 位置（主要角色现在在哪） | 7 |
| 地点笔记（我自己记一句话） | 6 |
| 历史时间线（按剧情时间回看事件） | 6 |
| 时间 / 昼夜 | 3（不要为这个再渲一套图） |
| 战争迷雾 / 探索 | 3（好玩，但只要是遮罩层就行，不要新渲染） |

## 5. 对「渲染还要做几轮」的意见
8K 对我意味着：多出 2.6 MB 的清晰档瓦片（我的机器根本不会去加载）、更长的渲染排期，以及更晚才发版。A3–A7 五轮、B2 三轮在修 7 号井格栅、交界车流、城中村楼缝，这些我用省流档 2000 px 基本看不到，和我没什么关系。

**一句话结论：渲染到「一眼能认出是哪一层、哪片城区」就够了。剩下的轮次换成秒开、离线缓存、低清 / 纯文字模式和不拖卡聊天页，对我来说价值高一个数量级。**
