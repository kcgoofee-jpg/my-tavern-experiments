# 人设 P1 · 重度 RP 玩家（桌面 TT / SillyTavern，每天几小时，多个长存档）

## 1. 我什么时候打开地图、看什么
- **换场景前后**：模型写「你来到 7 号井」，我点悬浮按钮确认「我在哪、周围有什么」。真正看的是标题栏那行「当前地点」（`eden-map.js` 的 `getHere()` 读 MVU `世界.当前地点`）和高亮点，再加周围两三个地标名，好决定下一句往哪走。
- **角标亮了**：`recompute()` 算出新事态、按钮出角标，我会点开看「出了什么事、离我多远」，然后回聊天写反应。看的是事件卡的标题、等级、状态，不是底图。
- **隔天续档**：长存档断了一天，打开地图找回空间感。这时最缺的是「上次到这为止发生过什么」。
- 底图本身我看第一次会惊叹一下（v7 中层夜景确实好看），之后基本当背景。一次打开 10–30 秒，看完就关。

## 3. 什么会让我不再用
- 流式输出时卡顿、按钮挡输入栏、开关后内存涨——长会话里每一次都会被放大。
- **地点跟错或不动**：跟随是核心信任；错两次我就不看了。
- **事件凭空消失**：`eden-map.js` 里 `SCAN = 40`（`docs/map-events.md` 还写着 200 楼 / 80 楼，文档与代码不一致）。我一个剧情轻松几百楼，40 楼前的封锁、通缉就从地图上没了，而剧情里它们还在生效。这比渲染粗糙严重得多。
- 回注提示词让模型反复提同一件事、出戏。

## 5. 一句话结论
渲染已经够当背景了，别再为 8K 细节开新轮次；把时间花在「长会话里地点和事件始终对、历史可回看、地图 → 聊天一键操作」上——那才是我每天都会碰到的东西。
