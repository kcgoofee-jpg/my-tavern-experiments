# 架构师汇总 · 成人向 RP 人设（A1 重度沉浸 / A2 多角色求新 / A3 隐私敏感）

> 只讨论功能、隐私、存储与接口。成人向 / 私密场景一律中性指代；卡内角色均为成年人。对照：`p1_heavy_rp.md`（非成人向重度 RP）。

## 1. 结论先行
- 这一群体的地图是**室内地图**：当前地点跟随（9.0）与庄园房间级视图（9.0）并列第一，「谁在哪」（8.7）是最大缺口；事件流（5.7）明显低于 P1（9）。
- 三人都把**按聊天隔离的本机数据**列为硬要求；A3 把低调模式列为「能否打开」的前提（10）。现状：`edenMapCustom` 尚未落地（只在 `here.mjs` 注释里），正好直接按聊天分键，不背迁移包袱。
- E6 只加小而本机的四件：按聊天分键、低调模式 + 一键隐藏、回注开关、清除本机数据。「谁在哪」、房间笔记、地图 → 聊天放下个版本。
- 3D 与渲染对这一群体边际价值低（4.3 / 5.0），不为它追加投入。

## 3. 共识与分歧
**共识**
1. 跟随准 + 房间级 + 自定义叫法 = 核心信任链；认不出时「不动地图」被 A1 视为隐性失败，需要让用户知道「没认出」（只在本机提示，不上报）。
2. 所有个性化只在本机、按聊天隔离；**不审核、不改写**任何地点名 / 别名 / 角色名（`docs/content-compat.md` 长期保持）。
3. 回注（`inject()` depth 4）在私密场景中会打断节奏，三人都要一个开关；笔记 / 房间状态默认永不注入。
4. 地图 → 聊天只能填输入框、不自动发送（与路线图一致）。

**分歧**
- 隐私权重：A3 10 vs A2 6。解法：低调模式做成可选设置，默认值不变，不影响其他人设。
- 事件流：A1 嫌 `SCAN = 40` 太短（与 P1 一致），A3 希望私密场景期间静默。解法：本版只给回注开关；窗口长度与「仍生效」常驻放下个版本统一处理。
- 3D：A2 愿意偶尔看，A1/A3 嫌慢。维持现状。

## 4. E6（v0.9.1）范围调整
前提：npm 截止约 2026-09-29，E5 后才动 viewer。只做本机、小改、可回退的项。

| 项 | 标记 | 说明 |
|---|---|---|
| `edenMapCustom` 按聊天分键 | **E6 必做** | 外挂脚本持有 chatId，viewer 不读 chatId |
| 低调模式（中性标题 / 隐藏地点行 / 角标 圆点·关 / 关提示） | **E6 必做** | 只改 `em-title`、`em-here`、`em-badge`、`tipOnce()` |
| 一键隐藏 | **E6 必做** | 面板 + 悬浮按钮同时收起 |
| 回注开关 | **E6 必做** | 默认 `on`（行为不变） |
| `clearLocal` | E6 可选 | 本聊天 / 全部 |
| 网络断言测试 | **E6 必做** | 见护栏 |
| `renameRoom` 显示名 | E6 可选 | 已在 content-compat 预留，本版可只做 alias |
| `registerOverlay` | 推后 | 无代码入口前价值低（均值 5.7） |
| `setWho` / 房间笔记 / 房间状态 | 推后 | 下个版本 |

**接口（外挂脚本侧，viewer 经消息转发）**
```js
EdenMap.setRoomAlias(word, room, { scope: 'chat' | 'global' = 'chat' })
EdenMap.removeRoomAlias(word, { scope })
EdenMap.getRooms()                        // 标准房间目录（只读，来自 maps.json）
EdenMap.setPrivacy({ neutralTitle: bool, hideHere: bool, badge: 'count'|'dot'|'off', tips: bool })
EdenMap.getPrivacy()
EdenMap.hideAll(on = true)                // 快捷键默认 Alt+Shift+M，可在 ⚙ 改
EdenMap.setInject('on' | 'off')           // 'scene'（仅场景切换时）推后
EdenMap.clearLocal({ chat: true } | { all: true })
EdenMap.on('here' | 'events' | 'map', fn) // 已规划，保持
```
viewer 只接收 `eden-map:custom { rooms, names }`（当前聊天已合并的表），由外挂脚本在 `CHAT_CHANGED` 时重发。

**localStorage 键布局**
| 键 | 作用域 | 内容 |
|---|---|---|
| `edenMap:chat:<chatId>:custom` | 聊天 | `{ v:1, rooms:{自定义名:标准房间}, names:{标准房间:显示名} }` |
| `edenMap:chat:<chatId>:seen` | 聊天 | 替代现 `edenMapSeen:<chatId>`（读旧键一次后迁移） |
| `edenMap:custom` | 全局 | 可选的全局别名（`scope:'global'`），与聊天表合并时聊天优先 |
| `edenMap:privacy` | 全局 | `setPrivacy` 的值 |
| `edenMap:inject` | 全局 | `'on'|'off'` |
| 现有 `edenMapLang/Theme/Line/LineManual/FabPos/EvTip` | 全局 | 外观设置，不动 |

迁移：若存在旧 `edenMapCustom`（理论上只有开发机有），首次启动搬到 `edenMap:custom`（全局）并删旧键；不自动分发到任何聊天。chatId 为空时不写聊天键，只读全局表。

**护栏**
- URL 只带版本号与线路；不带地点、别名、chatId 或任何 localStorage 值。
- 不新增任何网络请求；不引入统计、日志上报、远程配置。
- 不审核、不过滤、不改写；认不出按 `here.mjs` 回落。
- 低调模式下，折叠 / 隐藏态不得在 DOM `title`、`aria-label` 里残留地点原文。
- 测试（`tools/browser/`）：设置一个唯一标记串作为当前地点与别名 → 打开面板、切图、切聊天、触发重算 → 断言所有请求 URL / 请求体都不含该串；另断言 `hideHere` 时 `.em-here` 为空、`badge:'off'` 时角标隐藏、`setInject('off')` 后 `uninjectPrompts` 被调用且不再注入。

## 5. 下个版本优先级（按顺序）
1. **地图 → 聊天（只填输入框）**：地点卡「去这里」、事件卡「追问这件事」，模板本机可改。用户已定，无需再批。
2. **谁在哪 / 角色位置板**：对 MVU 各角色位置字段复用 `here.mjs` 解析；字段路径走卡作者配置（本卡先写死一份配置文件，不做通用抽取）。本卡内实现无需批准；做成通用配置格式属于**通用化，等用户 approve**。
3. **按聊天的房间场景状态**（中性：门 / 灯 / 请勿打扰 / 在场角色）与**私人房间笔记**：键 `edenMap:chat:<id>:{scene,notes,who}`，默认永不注入，显式勾选才进回注。
4. **房间清单视图**（楼层 / 分区文字列表，比点图快）+ **去过标记**（按聊天）。
5. **最近地点历史**（基于 `on('here')`，最近 10 条，可点回楼层）。
6. **时段标签**（读 MVU 时间，标题栏一个标签；无字段时不显示）。
7. 事件窗口：`SCAN` 与文档对齐、「仍生效」事件常驻；回注增加 `'scene'` 档。
8. `registerOverlay` 的无代码入口（模板 / 开关），再考虑别名批量导入导出。
- 任何「给其他卡用」的抽象（配置 schema、skill 生成）一律归**通用化**，等用户批准后再开始。

## 6. 风险 / 不做
- **不做**内容过滤、关键词表、分级提示；不读、不判断场景内容。
- **不做**云同步、账号、远程备份；导入导出只到本机文件。
- **不加**遥测、错误上报、使用统计（包括匿名）。
- **不**为这一群体追加 3D / 渲染投入（均值 4.3 / 5.0）；庄园 Blender 重建按既有计划走。
- 风险：`CHAT_CHANGED` 与 MVU 更新竞态导致新聊天短暂显示上一聊天的别名 → 切聊天时先清空再加载，测试覆盖。
- 风险：低调模式与 E5 样式同文件冲突 → E5 合并后再改，改动限于四个元素的显示逻辑。
- 风险：回注默认值被误改 → 默认 `on` 写进测试。
