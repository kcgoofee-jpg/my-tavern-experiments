# P2 · 手机轻度玩家（通勤 / 睡前，竖屏单手，在意流量与耗电）

## 1. 我什么时候打开地图、看什么
- **悬浮按钮上冒出红角标**（`eden-map.js` 的 `em-badge`，新事态数）或第一次弹出「天城有新事态」提示时。我点开是想知道**出了什么事、离我近不近**，扫一眼事态横条和针的位置就关。
- **剧情换场景、我搞不清「现在在哪一层 / 哪个房间」时**。标题栏那行「当前地点：…」（`em-here`）加上打开就落到那个位置（`here.mjs` 六级回落），这对我比任何画面都有用；很多时候我**只看标题栏那一行**，地图本身都没细看。
- 真正看的：红点在哪、针的名字、底部抽屉里的一两句设定原文。我几乎不会双指放大看屋顶，也不会切清晰档。一次打开大概 10–20 秒。

## 3. 什么会让我不再用它
- **偷跑流量、发热**：我在 iPhone 上。`lean()`（`eden-map.js:199`、`viewer.html:388`）靠 `navigator.connection` / `deviceMemory` 判断省流，**Safari / iOS WebView 都没有这两个 API**，所以我永远不进省流：每次进聊天都开幽灵面板拉首屏瓦片，自动档上限还是「清晰」（`autoMax` 返回 `hd`，dpr 3、8000px 金字塔）。我没点地图也在花流量，这是最容易让我卸掉的一条。
- 点开转圈超过 3 秒、或者关掉 3 分钟后（`SLEEP_MS`）再开又从头加载。
- 按钮挡住酒馆输入框或发送键；面板里误触（R02 楼层条被层按钮盖住，点了直接离开庄园；R01 屏幕正中死区）。
- 流式输出时聊天卡顿。
