# v0.9.2 开局关键地点 · 评审第 1 轮

## A) 设定考据者 · 8/10
- P1 maps.json eden：`openings:[1..5]`，但开局二到四的起点是书房，终点在别处。卡片只写「开局一–五」，看不出二到四是从书房出发、去别的地方。修：卡片行写成「开局二（起点，目的地：星渊大学）」这样的格式，目的地标记那边也注明「目的地」。
- P2 ruined_churches：层和位置都是推断，src 里已写明，tag inf 也标了。OK。只提醒一点：「天城边缘」放在下层的右下角有依据，可以接受。
- P2 old_apartment 的 src 写了「从下层上来租下的第一间屋子」，这是剧情细节，超出了中性地名的范围。修：删掉这半句，只留「当前地点 = 中层-钢铁霓虹区-旧公寓楼」。
- 名称都中性，没有成人词或开局标题，OK。首相府本身是 inf，挂开局三没问题。
结论：层级和落点都忠于卡片，推断项都标了 inf。只剩起点和目的地的语义没区分开。

## B) RP 玩家 · 7/10
- P1 上层手机图：标签「开局一–五」里的 en dash 贴着汉字，看上去像「开局一一五」，容易误读。修：区间改用「至」或「~」（开局一至五），或者直接逐个列出「一·二·三·四·五」。
- P1 中层：辉光大教堂（开局八）在默认视野里看不到，width 已放到 2000，手机上还是只看得到执法局和旧公寓。开局八进图后没有醒目的落点。修：当前地点命中时自动居中（确认 here 逻辑会 pan 过去），或者默认 focus 在带 openings 的点之间取中。
- P2 旧公寓的金色针和 here 的红色脉冲同时出现时优先级怎样，没看到截图验证。修：补一张「当前地点 = 旧公寓楼」的截图。
- 金边加后缀的强调在 375px 下清楚可读，declutter 把 op 排到 rank 1，不会被挤掉，好。
结论：落点都正确，强调有用，只是区间写法在手机上会读错。

## C) 现编 persona · 7.5/10
人物：林晓，26 岁，第一次玩这张卡的轻度玩家，用 iPhone SE 在地铁上玩，看不懂「开局N」对应的是哪段开场白。
选她的原因：这次改动只做了编号、不带标题（这是硬规则），编号能不能让新人自己对上号，是最大的风险。
检查点：
1. 我选了第六个开场白，地图会不会直接带我到中层旧公寓？测试 is(...) 覆盖到了。通过。
2. 标签上的「开局六」能不能看懂？能，但「开局一–五」读成了「一一五」。不通过（同 B-P1）。
3. 点开卡片能不能知道这是「开场白 6 的起点」还是「目的地」？不能区分。不通过（同 A-P1）。
4. 英文界面：Opening 1–5 的区间正则替换写法可用，但 EN 截图没审。待补。
结论：编号本身够用，区间符号和起点/目的地的区分影响新人理解。
