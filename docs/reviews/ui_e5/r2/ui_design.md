## 1. 环境

- 浏览器：Playwright Chromium（desktop 1440×900，DPR 1）+ WebKit iPhone 13 配置（375×812，DPR 3）。
- 组合：中 / EN × 深 / 浅，两种视口共 8 组；每组依次截 世界 → 上层 → 中层（注入 4 条事态，自动开卡）→ 关卡 → 事态列表 → 下层地点卡 → 设置 → 图层菜单（桌面）。
- 网络 / CPU：不节流，本地 5178 服务，档位「省流」。
- 后台：其他审阅与 Blender 渲染并发；每次浏览器运行都经 `lockrun.sh` 拿锁（单实例），单次运行 40–41 s。
- 脚本：`scratchpad/e5/rev2/work/design/d.mjs`；截图与探针数据：`scratchpad/e5/rev2/work/design/shots/`（`desktop_*` / `iphone_*` 共 60 张，`probe_*.json`）。
- 探针：每个状态记录 #build / #foot / #zoom / #glitchNote / #layers / #evbar / #card 的矩形；在固定 UI 上各取 28 个点做 `elementFromPoint`，看有没有被地图元素盖住；统计可见文字 < 11 px 的数量；搜旧色（#d9a441、#e0182d、Bootstrap 蓝）。
