# E5 第 2 轮 · 无障碍审阅（读屏 + 键盘 + 低视力）

人设：用读屏（VoiceOver / NVDA）和纯键盘的用户，外加把页面放大到 200% 的低视力用户。只看现在的绝对水平，独立打分。

## 1. 环境

- 被测代码：分支 `cloud/tc-mid-low`。审阅期间 HEAD 从 3f9ba38 前进到 08068a0，但 `map/viewer.html`、`map/events.js`、`map/ui/` 在 `3f9ba38..HEAD` 之间没有改动，所以测的就是 E5 第 2 轮的代码。
- 服务：本地 `tools/cors_server.py`，端口 5178，不压缩。
- 工具：
  - Playwright（npx 缓存），Chromium 和 WebKit。
  - axe-core 4.13.0：用 `page.addScriptTag` 注入，跑全部规则。
  - 自写探针：
    - 最小字号：扫可见文字节点。
    - 对比度：把各层祖先背景按 alpha 叠到纯黑、纯白、中灰三种地图底色上，取最差值。
    - 实际热区：从元素中心往四个方向用 `elementFromPoint` 探，伪元素扩展的热区也算进去。
    - Tab 走查：记录焦点环、是否在视口内、是否被别的元素盖住。
    - 读屏树：`locator.ariaSnapshot()`。
    - 播报：用 MutationObserver 记录 `#sr` 的文字。
- 视口：
  - 桌面 Chromium：1440×900、1280×800。
  - 200% 放大：720×450，相当于 1440 宽的屏幕放大 200%。
  - 宽度扫描：641–1024。
  - 重排：320×568。
  - 手机：Chromium 375×812，触屏，DPR 3。
  - iPhone：WebKit，iPhone 13 配置。
- 节流：无网络节流，也无 CPU 节流。
- 后台：测试时没有 Blender 在渲（`pgrep "Blender -b"` 为空）。浏览器全程用 `lockrun.sh` 串行，同一时间只开一个。
- 脚本与截图：scratchpad 的 `e5/rev2/work/a11y/`。
  - 脚本：`a_axe.mjs`、`b_touch.mjs`、`c_kbd.mjs`、`d_misc.mjs`、`e_more.mjs`、`f_detail.mjs`。
  - 结果：`*.json`。
  - 截图：`shots/*.png`。

### 本轮通过的其他项

- **开关**：图层弹层和设置弹层里的开关全部是 `<input type=checkbox role=switch>`，读屏树为 `switch "地名" [checked]`。按空格可以切换，地名随之隐藏；焦点留在开关上，并且有焦点环。
- **对话框**：
  - 地点卡是 `role=dialog`，用 `aria-labelledby=cardTitle` 命名，是非模态的，所以不需要 `aria-modal`。用键盘打开时，焦点进标题（`tabindex=-1`）；Tab 依次到卡内的 4 个「进入…」链接。
  - Esc 按层级依次关闭：设置 → 图层 → 列表 → 卡片。每次关闭后焦点都回到触发它的元素 ✅。
- **页面地标**：
  - `header`（banner）
  - `nav#crumbs "位置"`
  - `#stage role=main "天城地图"`
  - `nav#layers "楼层"`
  - 两个 `aria-live=polite`（`#tierState`、`#sr`）
- **重排**：320×568 下没有越界的控件；「⋯」抽屉 `overflow-y:auto`，可以滚动（scrollHeight 561 > clientHeight 397）。

## 4. 一句话结论

E5 把自动检查项全部做干净了：axe 0 违规，没有小于 11 px 的字，焦点环、switch、列表语义、播报合并都到位，R07–R10 修好。但有两条新 P1：窄宽度 EN 下工具栏和缩放组被推出屏幕、不能滚动；两个弹层打开后焦点不进去。两条都影响低视力用户和键盘 / 读屏用户，所以本轮 **7.5 / 10，门控不过**。把 F-01、F-02 修掉，再补上 F-03、F-04 这两处一行级的修复，就可以到 8.5。
