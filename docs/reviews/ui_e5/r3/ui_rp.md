## 6. 一句话结论

RP-1 修得干净：面板开着时，新事件只更新列表、角标和播报，不再把地图拉走、关掉卡片；同楼换地点也不再被事件盖掉。「边聊边看」的主场景不再被打断，本人设过 8 分门槛（8.3）。剩下的只有 P2 / P3：刚载入就打开时少飞一次，离开庄园偏慢，还有冻结的庄园问题。
