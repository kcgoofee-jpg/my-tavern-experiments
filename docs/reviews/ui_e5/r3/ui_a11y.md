# E5 第 3 轮 · 无障碍审阅（读屏 + 键盘 + 低视力）

人设：用读屏（VoiceOver / NVDA）和纯键盘的用户，外加把页面放大到 200% 的低视力用户。只看现在的绝对水平，独立打分。第 3 轮（最后一轮）。

### 新检查项结论

- **弹层 Tab 循环**：✅ 正确。弹层是非模态 dialog，可以用 Esc 退出，所以不算键盘陷阱（WCAG 2.1.2）。
- **手机「⋯」遮罩（`setMask`）**：✅ 视觉和指针行为正确。
  - 遮罩 375×812，z-index 12，rgba(0,0,0,.35)。
  - 在地图上点一下遮罩：抽屉关闭，没有开卡片，缩放没有变化，说明不穿透。
  - 卡片打开时层切换器 `visibility: hidden`，也不能 Tab 到。
  - 不足见 F-15：遮罩下面不是 inert，点遮罩关闭后焦点没有回到按钮。
- **瓦片全部失败的重试**：功能 ✅。
  - 不再显示「已加载」，遮罩保留，给出「重试」按钮。
  - 恢复线路后按「重试」，能回到 `tc_low` 并显示「✓ 已加载」。
  - 播报 ❌，见 F-13。

## 4. 一句话结论

上一轮的两条 P1 都修到位了：窄宽度下工具栏 0 个控件出屏；弹层打开时焦点进去、Tab 循环、Esc 回到按钮。F-03、F-04、F-05 和图例高度也清掉了。**本轮 8.0 / 10，过门控**，无 P0 / P1。剩下最值得修的三条都是一两行的改动：瓦片失败时失败提示连播 16 遍（F-13）；触屏深色中层层按钮对比度 4.09（F-12，本轮去毛玻璃带出来的）；工具栏收纳只在 resize 时判断、而且量宽偏小，窄宽度下当前地名被压没，收纳后的菜单在 450 高的视口里放不下（F-14）。
