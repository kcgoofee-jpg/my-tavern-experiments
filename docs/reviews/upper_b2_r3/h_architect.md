## 3. 冲突裁定

1. **伊甸东侧椭圆「准星」**
   - 分歧：只有现编指出。rp_glance 读成「圆形花园」，其余审阅者只查了卐形。
   - 裁定：**采纳现编，并升为发版阻塞**（不记作 P0，因为不是仇恨符号，但必须随本版修掉）。
   - 理由：本人复核，确认是「环 + 贯穿十字 + 中心点 + 四象限点」的分划图形，就在伊甸正中、手机一眼可见。本项目题材下，这和上轮定下的「敏感观感是发版硬条件」同一类。
   - 编排者的改法（外砾石环 + 内花环 + 4 条到环为止的短轴路）**认可**，并补两条：
     - 中心不要留「圆点 + 细环」，改成实心花床或喷泉池，直径 ≥ 内花环的 40 %；
     - 去掉四象限的 4 个小圆斑，或者改放到轴路上，不要落在 45° 方向。
   - 同批的西侧方园（宽砾石四分路 + 角部花床）、玫瑰园（去 8 辐改同心玫瑰环，同时消掉法轮联想）**认可**。
2. **岭南塘「泳池感」**
   - 分歧：设定、可读性、园林史记 P1；写实、rp_glance、现编记 P2。
   - 裁定：P1，但不阻断，因为「不像营房」的 P0 已经 6/6 通过。编排者的改法（浑绿水 + 深色石驳岸）**认可**，覆盖 isle8、isle12、isle32，同批验收。
   - 三进等宽、镬耳剪影加强：记遗留。
3. **SW 围墙要塞岛「军营 / 炮位」**
   - 分歧：只有现编提。设定审阅核对过身份与点位，认为这些都是中性建筑外观。
   - 裁定：**不阻断，记遗留 P1**。
   - 理由：这是有意的军事身份（将军府 / 城堡类），岛在 2000 px 上只有约 30 px，也不在手机默认视野内。
   - 如果本批顺手，只做一件：把「灰板 + 3 黑点」（`role_general_residence` 的装甲车图标组，或同类图标组）换成花坛或喷泉，其它不动。不做也不阻塞。
4. **压边云「棉花垫 / 贴纸 / 悬空」**
   - 分歧：云海和拼缝记 P1 / P2；rp_glance 认为「自然」；可读性没提。
   - 裁定：**不算标准档明显瑕疵，记遗留**。一眼可读以 rp_glance 为准；「悬在云缝上空」只在标准档细看才成立。
   - 本批**不改**：云改动牵动全图，最后一轮不引入未经审阅的全局变化。
5. **云沟槽对比太强、有描边线**
   - 分歧：可读性、写实、拼缝都提了；云海判定没有变平。
   - 裁定：记遗留，放到 v0.9.2 精修，和上面一条合并。
   - 理由：可读性已到 7.0 线，而且是全局改动。
6. **气候塔像 UI 标记**
   - 可读性、写实、rp_glance 都提了。
   - 裁定：不重渲，记遗留。塔本身就是 9 个 marker 之一，查看器上的常驻标签已能消歧，在 C2 截图里顺带确认。
7. **苏州同模板、小法式像「楼 + 泳池」、方块丛林格网、九曲桥通用符号、伊甸图章式园林**：都是参考项，记遗留。
8. **不采纳**
   - 写实提出的「云加 volume / 絮状噪声」：属于换风格，不做。第 1 轮已裁定 toon 三阶云是被接受的风格。
   - 可读性、园林史指出 lineup 并排图没对准目标岛：只是审阅材料的问题，记 tools 遗留，不影响本轮判定（多位审阅者用 `cu_*`、`crops` 交叉核对过）。

- 小法式 isle16 / 17 / 31：加宽中轴；镜池改成细长水渠（长宽比 ≥ 4）。
- 方块丛林：块中心也用泊松分布，整块抽稀。九曲桥改为可选件，出现概率 ≤ 40 %。
- 伊甸：加园路或轴线串起各园；外圈栏杆压暗；附属楼改坡屋顶。
- 气候塔：光晕和点环减弱。
- 草坪斑块提到 ±20–25 %，树冠做 2–3 种轮廓。
- tools：`lineup.py` 按岛心居中裁切，并给目标岛加框。

## 5. 轮次与重渲裁定

- 按放宽后的规则，每个资产每版本最多 2 轮。本轮已是第 3 轮（旧规则下的最后一轮），**不再开第 4 轮**。rp_glance 也行使了否决权（再开一轮提升 < 0.5 分）。**本轮就是发版版本。**
- **要不要重渲：要，但只是确认检查，不是新一轮审阅。** 4 项廉价修改都会改变伊甸和岭南的像素，没有经过渲染的代码不能直接发。做法：
  1. 先渲 2000 px 全图草稿，加伊甸 8K 局部和岭南 isle8 / 12 / 32 的 400 m 格（沿用本轮的相机与采样）。
  2. 由编排者对照下面的清单自查，外加 rp_glance **只看** `phone_375` 和伊甸局部（一眼判定，不打分）：
     - (a) 椭圆和西方园不读成准星 / 靶心；
     - (b) 全岛没有只有旋转对称的图形，也没有放射辐条；
     - (c) 岭南塘不再是泳池蓝，也没有浅色池沿；
     - (d) 回归检查：修改区域外，和 r3 的差分约等于 0；岛影差分测试照旧（p99 ≤ 1）。
  3. 通过后直接进入 B3 的 8K 正式渲染和切片。
  4. 如果 (a)–(c) 任何一项不过，只修那一处再检查，不开审阅团。
- 分数按本轮定档，不重新打分。确认检查只判有 / 无。

## 6. 与 GOAL 原文的差异

- 按用户 2026-09-27 同意的「渲染门控放宽」判定。严格项只有：设定 ≥ 7、一眼可读、标记可读、TT 性能、标准档无明显瑕疵。写实、园林史、拼缝降为参考（GOAL 阶段 2 原文要求四人 ≥ 7，已被放宽条款取代）。识别门槛：苏州 / 岭南 400 m，英式 / 法式 800 m（用户决定）。
- 阶段 3 原文第 2 条「岛影一致」按用户指示作废，改为「无岛影 + 白云遮挡」。航线、亮云环不计。
- 临时加严，沿用上轮：三条敏感观感 P0 是发版硬条件，不受「选最佳版本」兜底。本轮再加一条同类项：伊甸椭圆准星必须在发版渲染里修掉（本人裁定，理由见 §3-1）。
- 标记可读和 TT 性能两项严格条件，改由 C2 / C3 在发版前补证据，不在本包里判定。
