# art/rp_glance（RP 玩家扫一眼）· upper B2 第 3 轮

## 1. 分数：7.5 / 10（「一眼可用」）

看了 `full/norm.png`（= `upper_v6_r3.jpg`）、`phone_375.png`、`phone_1125.png`，之后才看局部（`upper_v6_eden_8k_half`、`lu_*`、`cu/isle12`、`crops/upper_se`）。
- **哪一层**：满屏白云海加上浮岛，375 px 手机上不到一秒就知道是「天上那层」，不会和中层、下层弄混。
- **伊甸**：默认视野下居中，面积最大，也是唯一一块大片亮绿。府邸、中轴林荫道和停靠平台在 375 px 上都能看出来，是全图第一眼落点。
- **瑕疵**：第一眼没看到刺眼的东西。岛影已经没了，云缝的蓝灰暗部是云自身的明暗，不脏也不黑。岛缘白云压边自然。伊甸东侧椭圆草坪现在是同心环加直十字，缩小后读成「圆形花园」，不再有旋转臂的联想。
- **扣分**：普通岛在省流 / 手机档只有 10–25 px 的绿点，要放大才能分出是哪片城区（按门控，苏 / 岭 400 m、英 / 法 800 m 放大后认得出，算过）。另外，这批材料里**没有带标记的截图**，「我在哪 / 出了什么事」的标记可读性没法验证（见问题 2）。

## 2. 问题（最多 5 条）

1. **P1 · 省流 / 手机可见 · `full/norm.png` 约 (1565, 955)、`phone_1125.png` 约 (1025, 950)、`crops/upper_se.png` 左上**
   气候塔是发亮的黄绿圆盘，外面还有一圈点环。缩小后很像 UI 按钮或事件标记（光晕 + 圆环 + 高亮），玩家可能会误以为「这里出事了」，或者想去点它。
   建议：压低发光强度和点环亮度，让它更像建筑，避免和事件标记用同一套视觉语言（亮色 + 光环）。本轮不必为此重渲，可以记 backlog，或者在查看器里给它加一个常驻地名标签来消歧。

2. **P1 · 无法判定 · 标记可读性**
   手机截图和全图都是纯底图，没有「我在这」和事件标记。门控严格项「标记可读、对比度 ≥ 4.5」本轮拿不到证据。
   建议：编排者补一张带 here 标记 + 2–3 个事件标记的 375 px 查看器截图（不需要重渲），重点看标记放在白云上的对比度，因为白底会吃掉浅色标记。

3. **P2 · 标准档可见 · `lu/isle12.png`、`cu/isle12.png`（岭南大祠堂岛）**
   400 m 下是「一排灰色长坡屋 + 半圆形规整蓝池（有直边）」，单看这座岛还带一点「院落 + 泳池」的味道。周围有树和曲池园林包着，已经不会读成营房 / 圈舍了。其余岭南岛 400 m 下读作「树林里的小园子 + 池」，没有营房感。
   建议（backlog）：半月塘直边改成麻石驳岸或加一圈暗色，降低「泳池蓝」的饱和度。

4. **P2 · 省流 / 手机可见 · 全图**
   普通岛大小接近，都是「绿团 + 小白云边」，扫一眼时除了伊甸和西南那座浅色大岛，其他岛之间没有区分度。对 RP 玩家来说，只要标记在，靠地名卡就能知道位置，所以不影响使用。
   建议：不改。

5. **P2 · 清晰档 · 8K 局部**
   伊甸东侧同心环、刺绣花坛等都是镜像对称，8K 半幅上没找到旋转卐形。清晰档的其他细节（树冠点阵残留、栏杆断口）玩家不会注意到，不记。

**P0：无。** 三条必清 P0 从 RP 玩家视角看都已清零：没有岛影、岭南不再像营房、伊甸没有旋转卐形。

## 3. 是否否决再开一轮：**是（否决）**
剩下的问题要么只在标准 / 清晰档可见，要么是查看器层面的事（气候塔消歧、标记截图），重渲底图帮不上。玩家扫两三秒只看伊甸和自己的标记，再开一轮渲染不会让「一眼可用」明显提高（< 0.5 分）。标记截图请在发版前用查看器补一张核对，不算新一轮。
