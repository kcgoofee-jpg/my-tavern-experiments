# 写实航拍审阅 · upper B2 第 3 轮

说明：本层是白天云海，没有夜景，所以钠灯、车灯这几项不适用。我改看曝光、材质、阴影统一、尺度，以及有没有矢量或 UI 感。
看过的图：`full/norm.png`、`crops/upper_eden.png`、`crops/upper_se.png`、`upper_v6_lu_lingnan.jpg`、`upper_v6_cu_lingnan.jpg`、`upper_v6_diff_ghost.jpg`。

## 1. 分数：6.0 / 10
写实只作参考，不阻断门控。

| 分项 | 分数 | 说明 |
|---|---|---|
| 曝光 / 色彩映射 | 7 | 云顶没有死白，暗部有层次，没有过曝 |
| 光影统一 | 7 | 去掉岛影后，云和岛的明暗方向一致；差分图里岛外没有暗晕 |
| 材质写实 | 4.5 | 云像翻糖、黏土，树是低多边形棒棒糖，草坪是单色平涂 |

| 矢量 / UI 感 | 5.5 | 栏杆虚线、气候塔光环圆点、云缝深色描边线都有这种感觉 |

**三条 P0 的核查结果：**
- 岛影：已清零。`diff_ghost` 里岛外只剩云体几何边缘的极淡残差，没有投影形状。
- 旋转卐形：8K 伊甸里没找到。东侧椭圆现在是同心环加直十字，玫瑰园是 8 辐，都有镜像对称。
- 岭南：400 m 下不再读成营房。isle12 半月塘的直边加蓝水，仍有一点泳池感，但属于 P2。

## 2. 问题（共 4 条，没有 P0）

1. **P1 · 标准 4000 起可见 · 所有云面**
   - 位置：`norm.png` 全图，`upper_se.png` 的云缝处（如 nx .1–.5，ny .3–.6）。
   - 现象：
     - 云是光滑的等值面，读起来像黏土或翻糖。
     - 团缝底部有一条连续的深灰细线，看上去就是描边，矢量感明显。
   - 建议：
     - 在 `tc_clouds._cloud_mat_emit` 里加中高频噪声，扰动烘焙明暗和 alpha 边缘，让云边碎一点、带絮状。
     - 把 only_local AO 的距离调小、强度降一些，消掉那条连续暗线。
     - 或者在云顶叠一层 volume / 半透明 puff 卡片。

2. **P1 · 标准 4000 可见 · 伊甸岛缘**
   - 位置：`upper_eden.png` 整圈岛缘。
   - 现象：白色栏杆在俯视下是一段段等宽白虚线，像 UI 描边。
   - 建议：
     - 栏杆底色再压暗，改成石灰或灰绿。
     - 或改为矮石墙加树篱，让它随地形起伏、宽度变化。

3. **P2 · 标准 4000 可见 · 气候塔**
   - 位置：`norm.png` 约 (0.78, 0.77)；`upper_se.png` 约 (0.31, 0.26)。
   - 现象：
     - 亮绿自发光团外面套一圈规则白点环，再加一圈冷色光晕。
     - 整体像地图 UI 图标，不像实物。
   - 建议：
     - 白点环改成随机间隔的小灯，亮度降一半。
     - 把 Glare / Fog Glow 的尺寸调小。

4. **P2 · 清晰 8000 可见 · 草坪和树**
   - 位置：伊甸大草坪，以及普通岛上的树冠。
   - 现象：
     - 草坪低频斑块 ±14 % 在标准档基本看不出来，仍然像单色平涂。
     - 树是同一种圆团模型，缩放一样，没有树种差异。
   - 建议：
     - `top_mat` 的斑块幅度提到 ±20–25 %，再叠一层割草条纹或踩踏小径的明度。
     - 树冠做 2–3 种轮廓（锥形、伞形），色相抖动约 ±8 %。

5. **P2 · 清晰 8000 可见 · isle12（岭南大祠堂）**
   - 位置：`cu_lingnan` 右上方的半月塘。
   - 现象：几何正半圆，直边是浅色硬边，池水是纯蓝，有一点泳池感。
   - 建议：池水改成暗绿褐，岸线加麻石驳岸，边缘不要那么规整。

## 3. 结论
三条 P0 都已清零；曝光和光影统一合格，没有过曝，也没有残影。写实度主要被云和植被的「黏土 / 低多边形」材质拖住，只有 6.0，但按新规则这一项只作参考，不阻断发布。
