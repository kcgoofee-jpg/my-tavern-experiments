## 2. 问题

**P0（必须去除，归云端）：岛影仍在。** 不扣云层分。
- 位置：
  - `upper_ne.png`：小岛右下 (880,580)、isle16 右下 (1400,650)、右上角暗团 (1600,50)；
  - `upper_north.png`：苏州岛右下 (1200,330)、isle17 右侧 (1700,380)、左下岛 (260,930)；
  - `upper_west.png`：湖岛右侧 (1200,700)；
  - `upper_se.png`：(1220,720)、右岛下方 (1800,520)。
- 这些都是投在云上的暗团。
- 改法：在 `tiancheng_upper.py` / `tc_clouds.py` 加 `ISLAND_SHADOWS=False`，默认关。关掉时把岛体、`under_*`（`tc_estates.py:515` 已是 False）、树、楼的 `visible_shadow` 全部置 False，或者云材质不接收阴影（用 light linking / shadow catcher 排除）。只保留云对岛底的遮挡。

**P1-1 平涂草地和屋顶，全岛「绒布 + 灰块」。** `upper_eden.png` 全岛，landmarks 全部。
- 现象：
  - 大片草坪没有明度起伏、割草痕和树下暗部；
  - 屋顶是单一的灰，看不到瓦面；
  - 果园方阵 (eden 550–1450, 960–1250) 像贴图瓦片。
- 改法：
  - `tc_estates.top_mat`：加 Scale ≈0.8 的大斑块（±12% 明度），再加 `ShaderNodeAmbientOcclusion`（距离约 .03），乘到 Base Color；
  - `flush()` 里的 `tc.vcol_mat('up_roofs_v', .7)`：换成 vcol × 噪声（Scale 400，±8%）× 沿屋脊方向的条纹 bump，`ROOFC` 每栋加 ±6% 随机明度；
  - 果园：每棵树加 ±0.3 冠径的位置抖动，缺 5–10% 的株。

**P1-2 云海仍像黏土壳。** 所有 crop 的大面积云。
- 现象：
  - 边缘是一圈均匀的灰蓝「内倒角」，像等宽描边；
  - 表面没有絮状细节；
  - 云缝底是纯平的 `(.7,.75,.85)` 色板。
- 改法（`tc_clouds.py` 与 `tiancheng_upper.py:118` 的 bump）：
  - bump Strength 提到约 .35，加 Scale 12 的第二层细噪声；
  - 云边做 displacement 或 alpha 絮边（边缘 5–15 m 半透明的碎絮）；
  - 亮面偏暖白 `(.86,.85,.82)`；
  - 云缝底加一层低处的第二层云，或 volume 薄雾，不要平板。

**P1-3 伊甸外圈白石栏杆是连续的白色描边。** `upper_eden.png` 整圈轮廓（`tc_estates.py:1404–1405`）。
- 改法：
  - `marble` 降到约 `(.70,.69,.65)`；
  - `wall_line` 每 40–60 m 断开一段；
  - 外侧加 3–5 m 的石或砾石步道和露岩岸缘，让「线」变成有宽度的「边」。

**P1-4 岭南岛读成「灰色水泥方台 + 蓝色泳池」，像现代度假村或 UI 图块。** lineup_lingnan 6 岛，se crop 右岛 (1650,420)。
- 现象：
  - 整块浅灰硬铺地加直角方塘，6 岛同一个模板；
  - 屋顶是单一的深灰小块；
  - 读不出青砖、镬耳墙、天井的黑白节奏。
- 改法（`est_lingnan`）：
  - 铺地改为暗一些的麻石色 `(.48,.46,.42)`，加噪声，面积缩到院落内；
  - 屋顶密排、天井用 `dark`；
  - 方塘边缘加石驳岸和水榭，打破正方形；
  - 按 layout 换塘的位置和形状。

**P2 伊甸局部仍有图形化元素。**
- 玫瑰园是放射饼图 (1280,900)，东侧的圆形草坪 (1390,710) 里有「卐」字形曲路：航拍里像 UI 符号，而且形状敏感，建议改成四向十字或同心环。
- 南端停靠平台 (1000,1300) 是纯白圆盘，像 UI 按钮：降低明度，加铺装分缝。
- 改法：在 `build_eden` 对应段落调整。

## 3. 结论

尺度问题已经解决，地标岛也有园林了。但材质仍是平涂，云仍是黏土壳，伊甸还有描边式栏杆，岭南是灰色方台模板。整体仍是「精致模型桌」，还不像航拍，5.5 分，不过门控。岛影还在，记为 P0 必须去除。
