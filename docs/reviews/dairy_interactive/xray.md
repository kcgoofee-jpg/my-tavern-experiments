# 内透方式比较（挤奶厅 → 伊甸主楼）

三种都在 `map/props/viewer3d.html` 里，界面「外观 / 内透 / 剖切」+ 剖切高度滑条；热点在三种方式下都能点（拾取时跳过掀开的屋顶、内透时的外墙、剖切面以上的交点）。

| 方式 | 做法 | 观感 | 成本（本机见 perf.md，全顶 60 fps） |
|---|---|---|---|
| (a) 屋顶掀开 | 外观模式下相机目标进建筑、距离 < 16 m 时 `roof` 上移 3 m 并抖动淡出（350 ms），飞向室内热点时自动触发 | 最自然，单层建筑足够；多层建筑只看到顶层 | 零（少画一个网格） |
| (b) 墙体 X 光 | `walls_ext` 在朝相机一侧（相对建筑中心的水平半空间，1.5 m 软边）用 4×4 Bayer 抖动降到 20 %；外墙保留 35° 边线 | 室内一目了然、不用排序；近看有网点感（DPR 2 下不明显） | 每像素一次点积 + discard |
| (c) 剖切 | 全局水平裁剪面；背面（`!gl_FrontFacing`）涂实色封口，墙体切口不空心 | 平面图式，读房间布局最清楚；单面网格（薄板）背面也会被涂色 | 一个裁剪面 + 双面绘制 |

## 建议（伊甸主楼）
- **默认外观 + (a) 自动掀顶**；**「内透」给 (b)**；**多层用 (c) 按层剖切**，滑条吸附到每层的 `y1`（楼板上方 1.2 m 左右），同时把该层以上的 `floor_N`、`interior_N` 整个隐藏而不只是裁剪（省 draw call、避免楼上家具的切口）。
- 每层数据：`floor_N`（楼板 + 楼梯）、`interior_N`（隔墙、家具）、`props_<热点id>`、`walls_ext_N`（外墙按层拆，(b) 只淡化当前层以上与朝相机一侧）、`roof`。清单 `groups.floors[] = {id, name{zh,en}, y0, y1}`。
- 墙体必须是有厚度的闭合体（封口依赖背面），单面装饰板放进 `interior_N`。
- 房间热点：`hotspots[].id` 用 maps.json 的标准房间名（拼音或英文 id + name.zh 对上 rooms），这样 estate:room 可以直接映射成 fly。
