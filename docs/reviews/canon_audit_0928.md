# 卡原名对账（庄园房间以外）· 2026-09-28

**起因**：庄园房间里发现仓库自己起了中性占位名（「受限房间 A/B/C」「附属室 A–D」）顶替卡的原名，模型写原名时对不上、id 也乱。庄园房间由另一路修（稳定 id + 运行时从用户本地卡绑定原名）。本篇查**其余全部**运行时数据有没有同类问题。

**写法**：本文中性表述。卡里成人向的原名一律写作「[卡原名，本地绑定]」，只给条目 id / 位置，不引用原文。

分类：(a) 卡原名在运行时数据里被自造 / 中性占位名顶替 → 匹配失败；(b) 缺卡原名别名；(c) 变量键名 / 枚举不对；(d) 自造的东西当成卡设定（应标仓库推断）；(e) 只在文档里的中性措辞，无害。
