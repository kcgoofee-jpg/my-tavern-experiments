## 分数：6.5 / 10

云层本身已经过关：厚、干净、三阶明暗统一，新旧差距巨大。

- 高岛（z > 6）的影子。尤其是落进云缝的，又变成了离岛很远的圆形暗斑，旧版「来历不明的暗斑」以较轻的形式回来了。

## 其它检查

- **伊甸亮云环**：
  - 在 v3（伊甸还小的时候），伊甸周围有一圈清楚的「花环」云，是全图第一眼。
  - 在 r4 里这圈已经读不出来。代码里 n = 16、R = 0.75–1.0 都是写死的，不随伊甸尺寸变化。伊甸放大到 rx 3.35 之后，环的周长约 30 单位，16 团间距约 2 单位，被 metaball 融进了周围的大云块。
  - 同时，`_puffs` 在 1.1 < q < 2.4 这一带把背景云的浓度都抬到 ≥ 0.55，环内外一样厚，环没有了对比。
  - `_tint` 只提亮 8%，而受光色 0.80 本来就接近白，看不出差别。
  - 环按椭圆排列，不跟伊甸的新轮廓。
- **黑洞**：有几个小云缝被四周的云壁挡住，成了近乎纯黑的点（RGB 约 30–40），比任何影子都深。位置（2000 px）：(1110,788) 伊甸码头正下方、(850,580) 伊甸左侧、(1525,858)、(1497,915)。看起来像「破洞」。
- **云穿岛 / 云压到岛上**：没有发现。低岛（silver_crown、isle3、isle8、isle11、isle25、isle26）的压顶逻辑有效。不过它按椭圆 rx × 1.25 判断，没有用新轮廓：长条岛的轮廓最多到 1.43 rx，目前靠云团半径的余量才没出事。
- **云团重复**：顶部鼓包大小接近，局部像一串同样的圆顶，比如 (900,820)、(1100,300) 附近。整体可以接受。
- **岛下岩体露边**：伊甸东北缘、english_1 和 chateau_1 的西北缘露出一条深褐色岩边，正好在影子的**反方向**，容易被读成「又一道影子」。原因在 `tc_estates.py` 岩体 `levels` 第 1 层：缩放 0.93 × 抖动 (1 ± 0.13)，超出了岸线。这是岛体的问题，不是云的问题，但会影响门控 2 的观感。
- **8K 局部草稿**：裁得太紧，高岛的影子被裁掉了，没法用来审影子。

## 问题清单

### P0（不改则门控 2 不过）

1. **高岛的影子成了脱离的圆团，落进云缝后成了深色暗斑**（isle4 / 5 / 13 / 15 / 32、isle28）。
   - `tc_clouds.py` 第 17 行：`CLOUD_ZENITH` 14 → **8**，偏移减少约 44%（高差 6.5 时从 1.6 单位降到 0.9 单位）。
   - `CLOUD_SUN_ANGLE` 5.0 → **2.5**，虚化宽度减半，小岛的影子能保留岬角、内湾的形状。
   - `docs/clouds.md` 里「偏移 ≈ 高差 × 0.25」「虚化 ≈ 高差 × 0.087」同步改成 0.14 / 0.044。
   - 底云单独用一盏灯，让**岛的影子不落进云缝**：在 `build_cloud_sea` 里新建 `cloud_sun_base`，方向、强度与 `cloud_sun` 相同，`light_linking.receiver_collection` 只放 `base`，`blocker_collection` 只放 `cl`（云团）。`cloud_sun` 的 receiver 去掉 `base`。这样云团照样在云缝里投蓝灰影带，保住厚度感；岛只在云顶上投影，不会再有远处的暗斑。
2. **伊甸亮云环没有按新尺寸放大，读不出来**（任务的明确要求）。改 `tc_clouds.py` `_puffs` 第 70–79 行：
   - 环沿伊甸真实轮廓排：`r = eden['isle'].r(a) * q`（islands 里已经带 `isle`），q 取 1.25–1.5。
   - 团数随周长变化：`n = int(2π · mean(rx,ry) · 1.4 / (1.25 · R))`，约 28–32 团。R 保持 0.75–1.0（团的大小不随岛放大，否则环会变成几坨大云）。每团外挂 3 → 4 个小团。
   - 环顶 `top` 从 0.75 调到 **0.95**，高出周围的云，能向外投一圈影，读出「云台」。
   - 背景加浓带从 `1.1 < q < 2.4` 改成 `1.6 < q < 2.6`，峰值 `d ≥ .45 + .3w`。在环外侧留出对比，不要环内外一样厚。
   - `_tint` 峰值从 1.08 改到 **1.12**，峰值位置 `q - 1.65` 改成 `q - 1.4`，与新的环位置对齐。

### P1

3. **云缝里的黑洞**（4 处，RGB 约 30–40）。
   - `_puffs`：云缝只由低频浓度决定，把 `if d < .3: continue` 改成 `if dens(x, y) < .3 and d < .3: continue`。只有 `lump` 造成的小洞会被填上，大块云缝保留。
   - 另外给底云材质加一个亮度下限：在 `build_cloud_sea` 里，`bm_` 的 Principled BSDF 设 `Emission Color` = 底色、`Emission Strength` = 0.2，让最深处不低于 RGB 约 80。
4. **低岛防穿模用的是椭圆，不是新轮廓**（目前没出事，但换种子就可能出事）。第 81–86 行：命中判断改用 `i['isle'].sfrac(local_x, local_y) < 1.15 + r / F`（或者对每个岛先采样 `r(th)` 做成极坐标表），替代 `rx*1.25`。
5. **伊甸周围的云缝**：伊甸左侧 (850,580) 和码头下方 (1110,788) 各有一个云缝。主角岛周围应该是连续的亮云台。P0-2 改完后，环内侧 q < 1.2 再强制 `d ≥ .5`（在 `_puffs` 的 eden 分支里加一行）。

### P2

6. **左上一大片连续云缝略有「湖」感**：`STYLES['toon']` 的 `dens` 频率从 `_fbm(3, 2, …)` 改到 `_fbm(4, 3, …)`，把大云缝打碎一些。或者把底云噪声 `noise_mat('cloud_base', …, 1.2, …)` 的 bump 从 0 改成 0.3，给底云一点起伏。
7. **顶部鼓包大小太一致**：`caps` 的半径 `R * uniform(.35, .5)` 改成 `uniform(.25, .6)`，个数上限加 1。
8. **岛下岩体在影子反方向露边**（不在本文件范围）：`tc_estates.py` `build_body` 的 `levels[1]` 从 `(.12, .93)` 改成 `(.12, .86)`，或者把 k = 1 的 `jit` 上限夹到 1.0，保证第 1 层不超出岸线。
9. **8K 局部草稿**：`--crop` 往右下多留约 1.8 单位（2000 px 下约 120 px），把影子带进画面；另外加一张高岛（isle5 或 isle13）的 8K 局部专门看影子。
