# 上层浮岛 B2 门控：拼缝与重复感审阅（审阅者 D）

- 对象：第 4 轮 `docs/drafts/upper_v4_r4.jpg`、`upper_v4_lineup_english.jpg`、`upper_v4_lineup_chateau.jpg`、`upper_v4_8k_*.jpg`、`upper_v4_landmarks.jpg`，对照第 3 轮 `upper_v4_r3*.jpg` 与旧版 `old_vs_new.jpg`。
- 方法：只写图里亲眼看到的；小岛用 PIL 从原图裁出放大 2–4 倍后逐对并排看（isle7 / isle18、isle11 / isle13、isle10 / isle23、isle31 / isle26）。`docs/upper-estates.md` 的自评只用来对照。
- 用户原话：「每个岛都长一个样，这很致命」。

## 分数：5.5 / 10

**进步明显的地方**
- 和旧版比，正椭圆 + 同一圈描边的「药片阵」已经没有了。
- 轮廓是真的各不相同：海岬、内湾、五角星、枫叶、花生形都有。
- 英式岛之间差异度尚可。

**没过的地方**
- **法式 6 座是同一个模板换了轮廓**：U 形楼、方形花坛、中轴一条水渠通向岛缘，6 / 6 相同。
- **台地地形变成了新的「统一圆圈」**：8 座岛上有同一个正圆挡土墙。
- **岛缘仍然是一整圈等宽的带子**：石墙读作细浅线，崖边读作宽米灰带。只是从一种描边变成了四种描边。
- 门控硬条件（逐岛说出区别）：英式勉强能过，法式 isle11 / isle13 过不了，见 P0-1。

## 4. 全图重复模式（`upper_v4_r4.jpg`、8K 局部）

1. **同一构图模板**
   - 法式：楼 + 花坛 + 水渠，一个模板。
   - 英式：楼居中偏一点 + 菜园 + 2–3 个小圆池 + 一条弧路。
   - 全图 2000 px 下，除 6 座地标、伊甸、银冠堡外，其余岛都是「绿色饼 + 均匀暗绿点 + 中间一个灰块」。
2. **正圆台地圈**
   - 共 8 座：isle7、9、11、12、13、16、18、32。
   - 地标会所 isle9 也有同一个正圆圈 + 浅晕。
   - 这是本轮新引入的「统一描边圈」，而且是全图最显眼的重复几何。
3. **岛缘**
   - 每种岛缘都沿整条岸线等宽、等距。
   - hedge 是树按 `linspace` 均匀排一圈；roots 是等距黑点念珠；cliff 的白色碎石也是等距小点。
   - 没有一座岛的岸线是「这一段崖、那一段林、中间断开」。
4. **相同树团**
   - 全图只有几种球状树，大小范围很窄，8K 下每座岛的「绿豆」质感一模一样。
   - 法式补树是均匀随机撒点，像撒胡椒，4 座法式大岛的空地质感完全相同。
5. **相同主楼**
   - 法式 U 形楼的比例固定（`L`、`L*.2`、`L*.16`），只随岛缩放。
   - 英式四种平面在 2000 px 下都读作「灰色长条组合」。
6. **菜园**：英式 6 / 6 是同一个 4 × 4 方格，颜色、比例都一样，从全图就能看出这是同一个贴片。
7. **云**
   - 六角网格 + 抖动的积云团，鼓包半径很均匀，全图读作一张「气泡膜」。
   - 大尺度上没有长条云街、平的层云区，也没有疏密对比。伊甸周围的亮云环例外。
   - 这点和「岛一个样」同属重复感。

## 5. 接缝与怪影

1. **水渠伸出岛缘悬在云上**
   - 看到的有：isle31（西北，很长）、isle13（东）、isle4（横渠顶到岸线）、isle11（西，贴岸）。
   - 岛上的水渠一头扎进虚空，是本轮最刺眼的接缝。
2. **瀑布水花是一块硬边白色矩形**，横在岸线上：isle10 东南、苏州 8K 两张的出水口都能看到。俯视读作贴图错位。
3. **云面上有近黑的小洞**
   - r4 全图 2000 px 坐标约 (1590, 500)、(1500, 890)、(1110, 780) 伊甸停靠平台正下方、(205, 330)。
   - 形状是深蓝近黑的椭圆 / 水滴，像云被戳穿、露出底层。
   - 伊甸平台下那一个最显眼，默认视野就能看到。
   - 推测是 `_puffs` 把岛投影范围内的云顶压下去以后，个别位置压穿了。另一种可能是飞艇或塔的投影，需要核实。
4. **isle12 的白石前庭跨出台地圆圈**：挡土墙从花坛和树中间穿过去，台地和园林不是一个整体。
5. **岛与云的接缝**
   - 岛像一张贴在云上的平面：岛底岩体俯视几乎看不到，只有个别岛在一侧露出一小条灰边（isle23 西端、伊甸东北）。
   - 露边的方向每座岛不一样，不像统一光向下的厚度。
   - 岛影柔边，方向基本统一，这点合格。
   - 岛周围的云因为被压低，形成一圈椭圆「洼地」，小岛周围尤其明显（isle22、isle18）。
6. **8K 贴图重复**
   - 没看到平铺贴图的重复纹，因为草面基本是纯色。
   - 问题反过来是**太平**：伊甸 670 m 的草面是一个颜色，没有割草纹、没有明暗块。
   - 东西两块加建草坪也几乎镜像相同，只有西块一角有条纹。

## 6. 问题与修改

### P0（不改不过门控）

**P0-1 法式岛共用一个模板；isle11 / isle13 分不出来。** 改云端 `blender/tc_estates.py` 的 `est_chateau`。

- 拆成至少 4 个布局族。按同风格岛的 id 排序后轮流分配，不纯随机，保证并排的 6 座里族不重复：
  - A 现状：U 形 + 中轴花坛 + 水渠。
  - B 护城河城堡（douves）：方形水环包住一座方形或四角塔主楼，花坛放在侧面，没有长水渠。
  - C 水花坛（miroir d'eau）+ 鹅掌放射林荫道（patte d'oie）：3 条林荫道从前庭放射到岸。
  - D 横向大运河 T 形 + 下沉阶梯花坛。
  - E 狩猎小楼：楼贴岸线，岛面大部分是星形林中路（étoile）切出来的丛林块。
- 主楼平面也要至少 3 种：U、单体长方 + 中央穹顶楼阁、L + 独立圆塔。
- 补树不要全岛均匀撒点：法式空地要么是规整的丛林方块（bosquet），要么是林荫道行树。

**P0-2 同风格同三元组 4 对。** 改云端 `blender/data/tc_islands.json`，把每座岛的 `shape / rim / terrain` 显式写进去；现在 `tc_islands.json` 里一个 `shape` 字段都没有，全靠种子。

- 同风格内不许重复三元组，建议：
  - isle18 改 `twin / roots / lake`。
  - isle13 改 `long / wall / meadow`，或 `cape / hedge / crag`。
  - isle24、isle31 其中一座改 `twin / cliff / terrace`。
- 同时在 `blender/tiancheng_upper.py` 导出前加断言：同 `estate_style` 的普通岛，`(shape, rim, terrain, 布局族, 主楼平面)` 五元组必须两两不同，冲突就换种子。

**P0-3 正圆台地圈是新的统一描边圈（8 座岛）。** 改 `tc_estates.py` 的 `build_body` 里的 plateau 段。

- 台地轮廓不要用正圆 `np.linspace(0, 2π, 40)`：用一个缩小的 `self.r(θ)` 加独立谐波，或者直接用矩形 / 半月形。
- 挡土墙**只砌在朝岸或朝景的一侧**，是一段开口的弧或直线，另一侧顺坡。英式台地参照克里夫登（Cliveden）那种单侧长栏杆台地；法式参照前面带台阶的方形平台。
- 台地内外的米白 / 浅绿晕要一起去掉：台地坡面不自动露岩，或把晕的颜色压到和草同色。
- 同一座台地不许把花坛或前庭切成两半：先放台地，再把 `est_chateau` 的前庭、花坛限制在台地多边形内（`claim` 之后做 `inside` 检查）。

### P1（这一轮应该改）

**P1-1 岛缘沿岸线分段混用、断开、宽度变化。** 改 `tc_estates.py` 的 `build_rim`。

- 把 `linspace` 均匀一圈改成按角度分 3–6 段，每段各取一种岛缘：
  - 例如 60 % 主岛缘 + 25 % 次岛缘 + 15 % 什么都没有，草直接到崖口。
- 石墙只砌在园林那一侧（前庭、花坛朝向的 90–150°），其余用隐垣（ha-ha）或林带。
- 崖边的米灰带宽度用低频噪声调到 0–3 倍。
- 碎石、树、垂根都改成成团分布（泊松团），不要等角度排队。
- roots 要有长短，并且在岸线外下垂出可见的深色须，不要一粒粒黑点。

**P1-2 英式标志物去同质化。** 改 `est_english`。

- 菜园出现率改为约 40 %，形状在方、D 形、圆形里取。
- 其余岛从这些里挑 1–2 个：
  - 鹿苑围篱
  - 隐垣（ha-ha）
  - 林荫大道（avenue）
  - 观景塔 / 方尖碑小品（folly）
  - 板球 / 网球草地
  - 果园网格
  - 湖边船屋
  - 岛缘观景台
- 小圆池串改成真正的蛇形湖：一条连续的弯曲水面，不要 3 个互不相连的椭圆。

**P1-3 水渠、溪流不许出岛。** 改 `est_chateau` 与 `build_body`（瀑布）。

- 水渠长度按终点 `inside(q, .85)` 截断；横渠半长取 `min(cl*.3, 到岸距离*.8)`。
- 瀑布口的 `foam` 矩形 box 改成沿岸线的细长弧片，材质边缘 alpha 渐隐。或者俯视时干脆不渲这块，只留侧面白练。

**P1-4 云面黑洞。** 改 `blender/tc_clouds.py` 的 `_puffs` 压低段。

- 被压低的团不要只改 z，要在 `lim` 处补一个同半径的扁团填底；或者给压低量设一个下限。
