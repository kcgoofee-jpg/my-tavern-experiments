# 天城地图悬浮窗 · UI 审计（E4 汇总）

- 来源：五个人设的实测报告（2026-09-27，Playwright，Chromium + WebKit）。报告、截图、脚本都在会话的 scratchpad `ui/` 下，没有进仓库：
  - **手** = 手机首用玩家（`phone.md`，6 / 10）
  - **剧** = 桌面重度剧情玩家（`rp.md`，7 / 10）
  - **设** = 视觉设计师（`design.md`，5.5 / 10）
  - **障** = 无障碍专家（`a11y.md`，4.5 / 10）
  - **弱** = 弱网低端机玩家（`weak.md`，5 / 10）
- 汇总人：架构师（本机）。五份报告合并去重后分成两组：
  - **A 组「现在修」**：功能错误、性能、流量、内存、无障碍阻断，以及会困住用户的问题。本轮（E4）修，E4b 复测。
  - **B 组「E5 统一重构」**：视觉一致性、组件规格。按第三部分的规范 v1 一次性重做。
- 归属：
  - **查看器**：`map/viewer.html`、`map/events.js`、`map/i18n/*`，本机负责
  - **卡内脚本**：`map/tavern/*`、`tools/add_script_to_card.py`，本机负责
  - **庄园页**：`map/estate/**`，云端负责；需要改的写进 `NOTES_FROM_LOCAL.md`
- 严重度：**P0** 阻断或困住用户 · **P1** 严重 · **P2** 一般 · **P3** 轻微。
- 状态：☑ 本轮已修（见第四部分的验证）· ☐ 未修 · → 云端（已写进 NOTES）。

## 三、统一设计规范 v1（定稿）

由设计师的草案 v0.1 整理而来，并吸收了无障碍、手机两份报告的要求。原则：**一套骨架，三层换皮。**
- 结构全站只有一套：尺寸、圆角、间距、字号、动效。
- 颜色分三级：基础中性色 → 主题（深 / 浅）→ 层强调色（上 / 中 / 下 / 庄园）。
- 组件只引用语义令牌，不写色值。

#### 间距、圆角、描边、阴影、动效

- 间距刻度（4 基）：`--sp-1 2` · `--sp-2 4` · `--sp-3 6` · `--sp-4 8` · `--sp-5 12` · `--sp-6 16` · `--sp-7 24`
  - 控件内边距 `6px 12px`（紧凑 `4px 8px`）
  - 面板内边距 `12px 14px`（手机抽屉 `14px 16px` 加安全区）
  - 组件间距 8；纵向导航按钮间距 4（触屏 8）
  - 屏幕边距：桌面 12，手机 8
- 圆角：`--r-s 4px`（tag、小色块）· `--r-m 8px`（按钮、分段、输入框、导航组）· `--r-l 12px`（卡片、弹层、横条、抽屉顶角）· `--r-pill 999px`（地图标签、角标、筛选片）。组内按钮的圆角 = 外框圆角 − 内边距。
- 描边：
  - 面板一律 1 px `--line`；选中 1 px `--accent`；悬停 `--line-strong`
  - 焦点 2 px `--focus`，offset 2
  - 保留的特色：选中导航项左侧 3 px `--accent` 内阴影；重点行左侧 3 px 线
- 阴影：`--sh-1 0 1px 3px rgba(0,0,0,.25)`（标签、针脚）· `--sh-2 0 6px 20px rgba(0,0,0,.30)`（卡片、横条、导航组）· `--sh-3 0 12px 32px rgba(0,0,0,.38)`（弹层、抽屉）；浅色主题下透明度减半。
- 动效：
  - 时长：`--dur-1 120ms`（悬停、按下）· `--dur-2 200ms`（面板进出、切层淡入）· `--dur-3 320ms`（主题、遮罩、抽屉）
  - 曲线：`--ease-out cubic-bezier(.2,.8,.2,1)` · `--ease-in cubic-bezier(.4,0,1,1)`
  - 按下反馈统一为 `scale(.97)`
  - 所有循环动画（脉冲、雷达、花屏）在 `prefers-reduced-motion: reduce` 或「关闭花屏特效」下停掉，只保留静态文字提示

### 3.2 组件规格

- **触控下限**（所有组件通用）：触屏上热区 ≥ 44 × 44 px。视觉尺寸可以更小，用透明伪元素扩展热区，相邻热区不重叠。
- **面板（Panel）**：`--surface-glass`，1 px `--line`，`--r-l`，`--sh-2`，内边距 `12px 14px`。所有浮层都从它派生：地点卡、设置、事态横条、加载提示、庄园房间卡、楼层条、缩放组。
- **工具栏（Toolbar）**：桌面高 48，手机高 44；`--surface` 92%，底边 1 px `--line`，没有阴影。
  - 左：面包屑（`--fs-body`，链接 `--accent`，当前层 700，分隔符 `›` 用 `--muted`）
  - 中：清晰度分段控件 + 状态
  - 右：「图层 ▾」下拉（国界、航线、地名、标记、事态）、语言分段、主题图标按钮、设置图标按钮
  - 手机：只留面包屑、状态和「⋯」，其余都进「⋯」菜单（本轮 N27 已先做成弹层，E5 改成底部抽屉）；**禁止横向滚动的工具栏**
- **按钮（Button）**：高 32（手机 36），`6px 12px`，`--r-m`，1 px `--line`，透明底，`flex: none; white-space: nowrap`。
  - 悬停：`--surface-2` 底 + `--line-strong`
  - 按下：`scale(.97)`
  - 选中 / 展开：`--accent` 描边和文字
  - 禁用：opacity .45
  - 焦点：`--focus` 环
  - 纯图标按钮 32 × 32，SVG 16 px、1.5 px 描线
- **分段控件（Segmented）**：外框 1 px `--line`、`--r-m`、内边距 2；内项 `--r-s`、高 28。选中 = `--accent` 实底 + `--on-accent` 字 + 700（中层再加 `--glow`），并带 `aria-pressed`。清晰度、语言、庄园「外观 / 全部」都用这一个组件。
- **纵向分段（层切换器 = 庄园楼层条）**：一个 Panel 容器（内边距 4、间距 2），项高 36（触屏热区 44），左内边距 10。
  - 文字 `--fs-control`；small 用 `--fs-micro` 和 `--muted`
  - 选中：`--accent-weak` 底 + 左侧 3 px `--accent` 线 + 字色 `--accent` + `aria-current`
  - 庄园嵌入时，层切换器和楼层条上下拼成**一根**柱子，中间用 1 px `--line` 分隔，加小标题「楼层」
  - 标记：当前地点 = 6 px `--alert` 圆点；未解除事态数 = `--r-pill` 角标（`--alert` 底，11 px 700），数字前有视觉隐藏的「未解除事态」
- **开关（Toggle）**：34 × 20 胶囊，轨道 `--surface-2` + 1 px `--line`，拇指 14 px `--ink`；打开时轨道 `--accent`、拇指 `--on-accent`；整行 label 是热区。
- **卡片（Card：地点卡、事态卡、庄园房间卡）**：Panel 规格，宽 320（庄园 280），`role="dialog"`，`aria-labelledby` 指向标题。结构从上到下：
  1. 顶行：tag + 关闭图标按钮（28 × 28，触屏 44，`aria-label="关闭"`）
  2. 标题：`--fs-title`、`--font-ui`
  3. 副标题：`--fs-small`、`--muted`
  4. 字段区：两列网格 `5.5em 1fr`
  5. 重点行：最多一行，`--accent-weak` 底 + 左侧 3 px 线
  6. 链接行：`--accent`，SVG 箭头，每条是一个 ≥ 44 高的行按钮

  手机上卡片是底部抽屉：**实底** `--surface`，顶角 `--r-l`，顶部有 4 × 36 的抓手。打开时自动收起事态列表；关闭后焦点回到打开它的元素。
- **标签（Tag）**：只有两种。
  - 实心：`--accent-weak` 底 + `--accent` 字（「设定」「推断」「事态」都用这种，靠文字区分）
  - 数据色：底色 = 大类色，字 `#111`，只出现在事态卡
- **抽屉（Drawer，手机）**：从底部弹出，最大高 60%，`--sh-3`，遮罩 `rgba(0,0,0,.35)`；进 `--dur-3 --ease-out`，出 `--dur-2 --ease-in`。承载地点卡、事态列表、「⋯」菜单。
- **提示条（Toast / 事态横条收起态）**：Panel 规格，高 36（触屏 44），底部居中，距底 12。
  - 左侧是最新事态的大类形状点；「N 条新」用 `--accent` 700；展开图标用 SVG chevron；按钮带 `aria-expanded`
  - 例外：花屏提示 `#glitchNote` 保留青色描边和色散（它就是故障本身），字号 12、`--r-s`
- **加载进度**：
  - 顶部细条 3 px，轨道 `--line`，进度 `--accent`
  - 首屏：`--bg` 底，世界图先铺缩略图；中间放一个实底提示条，文字「加载 天城 · 上层」+ 右侧等宽百分比
  - 没有任何瓦片完成之前不显示 100%；失败显示失败样式和出路（重试 / 换线路 / 看平面图），不画满
  - 完成：「✓ 已加载」在遮罩消失后显示 1.5 秒，然后淡成 `--muted`
- **地图叠加物**：
  - 地点标签：`--r-pill`、`--map-label-*`、`--fs-small`；按优先级避让，不整体隐藏
  - 针脚：默认 `--accent`，当前地点 `--alert` 加脉冲（遵守减少动效）
  - 事态点：大类色 + 大类形状，触屏热区 44；光晕只在中层有
  - 缩放组：纵向 3 个 32 × 32 图标按钮（+、−、复位），Panel 规格，放在右下角小地图上方，替代 OSD 的默认按钮
  - 小地图：`--r-m`，1 px `--line`，视口框 1.5 px `--accent`
  - 版权、版本号、状态合成一条页脚：`--fs-micro`，放在 `--surface-glass` 底上

### 3.3 深浅主题规则

1. 主题只换语义令牌的值。组件 CSS 里不出现 `html.light` 选择器；现在的 `html.light #status`、中层去发光这两处，改成令牌。
2. 浅色 = 规范的纸色系；每层的强调色取深一档，保证强调色做文字时 ≥ 4.5:1。
3. 地图标签在两种主题下都是深色胶囊（`--map-label-*`），写进规范，不算不一致。
4. 浮在地图上的面板都跟主题走，包括事态横条、缩放组、小地图框。
5. 庄园 iframe 的主题通过 `estate:theme` 下发；两边的令牌名一致，共用一份 `tokens.css`。

### 6.2 做了什么

- **令牌**：`map/ui/tokens.css`。
  - 全站只有一种金 #e6c36a（用户定，草案里的 #d9a441 不用），浅色取深一档 #7a5d22。
  - 只有一种红 `--alert`（`--on-alert` 保证 11 px 角标的对比度）。
  - 字号下限 11，圆角 / 间距 / 动效 / 焦点环统一，深浅 × 上 / 中 / 下层。
  - 浅色下层的强调色取 #336619。
  - 查看器把它逐字内联在 `<style id="tokens">` 里，省一个会阻塞首帧的请求；`tools/sync_tokens.py` 负责同步，`tools/smoke.sh` 检查两边一致。
- **工具栏**：桌面 48 px、手机 44 px，只有一行。
  - 次要开关收进「图层 ▾」。
  - SVG 描线图标，分段控件和开关（`role=switch`）。
  - 放不下时（窄窗口、EN、放大 200%）和手机一样收进菜单。
- **地图叠加物**：
  - 自绘缩放组替掉 OSD 的拟物按钮，小地图重描。
  - 层切换器做成一个 Panel：选中项用弱底 + 左侧 3 px 线；当前地点红点和事态角标都用唯一的红。
  - 标签避让把事态点、国名、小国名都算进来（R14）。
  - `#osd` 自成层叠上下文，地图元素不再盖住固定 UI。
- **卡片**：结构是 tag / 标题 / 副标题 / 字段网格 / 链接行按钮。
  - 事态卡 tag 用大类数据色，不再重复分类行（L6）；地点卡 tag 改叫「档案 / 传闻」。
  - 手机上是实底底部抽屉，打开时层切换器让开。
- **手机「⋯」**：底部抽屉，真实遮罩，点遮罩关闭且不穿透到地图，最高 60 dvh。
- **事态横条**：Panel 规格，去掉橙色描边，左侧是最新事态的大类形状，SVG chevron。
  - 列表项改为 `li > button`（R08）。
  - 图例去掉 `all:unset`，触屏高 44（R05）。
- **键盘 / 读屏**：
  - 飞行、进层、翻页键换层后，焦点落到卡片标题或当前层按钮（R06）。
  - 事件点有焦点环（R07）。
  - 播报合并成一句（R09）；瓦片失败只播一次。
  - 弹层打开时焦点进去，Tab 在弹层内循环，Esc 回到按钮。
- **加载**：
  - 「✓ 已加载」在遮罩消失后才出现（V13）。
  - 瓦片全部失败时显示「重试」，不再报已加载；重试按原视野重开。
  - 庄园页自己超时算「较慢」，脚本失败才算「失败」。
  - 嵌入时先等当前地点 ≤ 0.6 s 再开首图（R10：世界瓦片 0 张）。
- **宿主面板**（`map/tavern/eden-map.js`）：
  - 跟随地图的主题和中 / EN。
  - 面板 grid `minmax(0,1fr)`，375 宽也关得掉（r2 P0）。
  - 面板开着时新事件不再拉走地图，只在打开那一次飞过去（RP-1）。
  - 重复注入保持幂等；宿主输入框里按 Esc 不关地图。
  - 解析事件前剥掉 EJS `<% %>`。

### 6.3 TT 实测带来的改动（WebKit / WKWebView，本机用 Playwright iPhone 预设复测）
