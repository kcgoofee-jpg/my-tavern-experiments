## 仓库推断

- **定位与气质**：外环是圣都的败者聚居带——竞赛落败者、佣兵与破产者的棚户区，铁皮、油污与锈迹是它的主色。整体低矮（绝大部分单体不超过 6 m），与核心区、中环的宏大尺度形成落差——仓库推断。
- **片区模型口径**：本模型做的是外环棚屋城区的一段代表性街区（低矮棚屋群 + 巷道杂物 + 一座锈蚀水塔）；清算转运站、独立骑士营地、临光家族外城驻所三处卡里写明的设施**各有独立标记、单独建模**（`clearing_depot` / `free_knight_camp` / `linguang_post`），不在这套里——仓库推断，口径同 `contest_corridor`（外环另有标记不在这套里）。
- **棚屋**：单层为主的坡顶 / 单坡铁皮棚屋，波纹铁皮墙板与屋面，色块斑驳（锈橙、灰镀锌、褪色蓝、褪色绿），少数砖砌墙基与木门板、小窗；约三成棚屋上面再摞一层更小的阁楼层——仓库推断（卡只写「低矮棚屋」）。
- **水塔**：街区内一座锈蚀铁皮水塔（四腿钢架 + 圆柱罐体 + 锥顶），棚户区唯一的高点——仓库推断。
- **巷道杂物**：木条箱、油桶、板材堆、斜搭的防水布棚檐、几盏简易灯杆——仓库推断。
- **周边（bg，不导出）**：北侧温带阔叶林带与一条河（呼应「城外是温带阔叶林，北侧有一条河」），其余方向铁皮棚屋剪影挡地平线——仓库推断。
