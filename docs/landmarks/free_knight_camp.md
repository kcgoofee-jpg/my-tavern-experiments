## 仓库推断

- **定位与气质**：不愿挂靠骑士团 / 议会的「独立骑士」在外环扎营，营地里同时是黑市——帐篷与货摊混排，没有围墙、只有车辙与踩实的泥地；散漫但警惕——仓库推断。
- **大帐**：营地中央一顶长方形大帐（双层坡顶帆布，门厅带两根柱与三角山花），是黑市开市的地方；帐前插两根无字纹样旗杆——仓库推断（旗帜只用几何纹样，`docs/rejected.md` #5；参照 `contest_corridor` 旗帜处理）。
- **宿营帐篷**：四周散布 8–10 顶小帐篷，A 形帆布帐与圆锥帐两种，门朝中央，帐前有器械箱与铺盖卷——仓库推断。
- **黑市货摊**：三面摊位——木架撑起的斜面帆布棚，摊台上摆条箱 / 油桶 / 板材 / 陶罐形道具（无字），一角有一座两层瞭望木塔——仓库推断。
- **生活痕迹**：篝火圈（石圈 + 炭黑）、拴马桩列、水桶架、木条箱坐凳——仓库推断。
- **周边（bg，不导出）**：北缘阔叶树带（外环贴着城外林带），远处棚屋剪影——仓库推断。
- **中立性**：无人物、无文字 / 标志、无武器类细节；黑市气质只靠货摊与杂乱度表达（`docs/rejected.md` #5、#6）。
