# 佣兵公会（2026-09-28）

## 设定（卡内事实带 `docs/card-digest.md` 行号）

- L83：「佣兵公会 | 中层 | 雇佣兵接单的地方 | 军事与治安」——层已写明（中层），功能明确：雇佣兵在这里接任务委托。
- L156：「下层帮派、雇佣兵与赏金猎人 | 灰色势力 | 下层；佣兵公会在中层」——佣兵公会本身在中层，是相对下层帮派更「正规」的灰色机构，介于军事与治安体系边缘。
- L323（12 处未落点核对表）：佣兵公会具体位置未写，登记为「层写了、位置未写」一类，仓库据此只定院内布局与具体坐标，不改层。

卡里只给了层与一句功能描述，没有外观、规模、组织细节，其余在此设定。

- **定位与气质**：中层一处独立的低矮堡垒式院落，工业风格粗野混凝土 + 钢板，刻意区别于政务区的规整石材与法师塔的精致魔法感——体现「灰色地带机构」的气质。
- **主厅（接单大厅）**：一栋两层钢筋混凝土主楼，正立面是大面积可升降钢卷帘门（象征进出频繁），侧面附一座矮瞭望塔。
- **委托板墙**：主厅侧墙外挂一整面背光委托板（灯格阵列，纯几何无文字，象征贴满的委托单），呼应「接单」功能，2088 年科技化处理成电子公示屏而非纸质告示板。
- **起降坪**：院内一块铺装坪，停靠几辆无标识装甲悬浮车（佣兵代步载具），与卡内「悬浮轨道」「悬浮车」等已确立的世界观元素一致。
- **训练场**：压实土地面的简易训练场，木质训练桩、沙包架、绳网——不放任何武器道具，避免涉及武器建模（对齐 `docs/rejected.md` 里其它机构类地标「无武器」的一贯处理）。
- **补给库**：一排锁死的钢卷帘仓库门 + 露天堆叠的运输箱垛（纯素面集装箱式箱体，无标识文字）。
- **围墙与大门**：混凝土围墙 + 钢制滑动大门，门口哨岗。
- **中立性**：无人物、无文字/徽记/标志、无武器/囚禁/束缚类细节，符合 `docs/rejected.md` #7、#5、#6。
