# 原域城区（设定稿，2026-09-30）

`yuanyu_city`，层 yuanyu_city。本稿按场景写：东门、穹顶区、朝圣广场、尖塔区四个标记并进同一个三维场景，各成一个热点。卡里写到的事实带行号。

## 设定

- L90（`docs/card-digest.md:90`）：「原域 · 诸神殿（悬浮圣山）｜第三帝国｜国都与最高议事地」——原域是第三帝国的国都。
- L163：第三帝国的体制是神权（诸神殿、神明代理人、红祭司），国都原域。
- 卡 E44 L5912–L5914（见 `docs/world-setting.md` §1.1）：原域风貌是西式古典神圣美学与神秘色彩；高耸入云的哥特式尖塔、繁复华丽的巴洛克穹顶与黑白石材雕琢的巨型神像回廊交错分布；街道常年笼罩淡淡的以太薄雾与圣香烟气；煤气灯风格的魔导路灯照亮铺满青石的幽深街巷。
- **东门与城墙**：城区东侧一道白石城墙，正中是双塔门楼（方塔 + 尖顶 + 四角小尖塔），门洞朝东（朝天城方向），一条宽阔的东门大道通向广场。
- **朝圣广场**：悬浮圣山正下方的圆形广场，半径约 70 m，同心铺石环；外圈 24 尊黑、白石材交替的巨型长袍立像（无面容、无持物），中心一座低石盘与金色圆球；立像外是一圈路灯。
- **尖塔区**：广场以北的密集街区，白石高屋配陡峭的深蓝板岩坡顶，屋顶中央一根细长的尖塔，四角各有小尖顶；窗有暗有亮。
- **穹顶区**：广场以南的街区，鼓座上的巴洛克穹顶（铜绿与白石相间），顶上金色灯亭与圆球，四角小穹顶。
- **街巷与灯**：青石铺满的街巷，街口与大道两侧是煤气灯式的魔导路灯（暖金色）。
- **远景**：悬浮圣山的倒锥轮廓悬在广场上空（只在成图里，不导出）；远处是环绕的山影。
- **中立性**：无人物、无文字 / 标志、无宗教符号、无武器类细节（`docs/rejected.md` #5、#6）；立像无面容、无持物。
