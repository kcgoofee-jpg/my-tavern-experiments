- **片区气质**：三处机构性质相近（公共福利 / 信仰安宁），仓库把它们放进同一片「关怀带」院落群，视觉上区别于政务区的宏大与佣兵公会的粗野——采用暖色调、较低楼层、更多绿化的「民生」气质。
- **中层公立医院**：一栋 8 层板式医院主楼（白色面砖 + 蓝绿色遮阳板），门诊裙房（一层，弧形雨篷 + 救护车下客位），屋顶悬浮救护飞行器停机坪（呼应卡内「悬浮车」「悬浮轨道」的既有世界观元素）。
- **中层养老院**：一栋 4 层的低层住宅式建筑（暖黄色面砖、外挑阳台、无障碍坡道），附花园（步道、凉亭、菜圃），突出「安养」气质。
- **中层修道院**：小礼拜堂 + 回廊 + 素面钟塔（比圣铁摇篮矮小、无战斗训练设施），呼应 maps.json 里「5 座普通修道院代表」的定位——外观朴素，无宗教符号/文字/人物，符合 `docs/rejected.md` #5。
- **共用院落**：三栋建筑共享一条步行街与绿化带，街边设无标识悬浮救护车停靠点、公交/接驳站台造型（无文字），体现「关怀带」整体感。
- **中立性**：无人物、无文字/徽记/宗教符号，符合 `docs/rejected.md` #5、#6、#7。
