# 第一席封地（设定稿，2026-09-30）

`fief1`，层 site_fief1。本稿按场景写：城堡、骑士团驻地、领地城镇、领地农田标记并进同一个三维场景，各成一个热点。卡里写到的事实带 `docs/card-digest.md` 行号。

## 设定

- L91（`docs/card-digest.md:91`）：「临光家族领地、圆桌骑士封地（五席）｜光辉联邦｜封地」——圆桌骑士共五席，各自有封地。
- L162：光辉联邦的势力包括圆桌骑士（5 席）与骑士团守备卫队；每席圆桌骑士享有独立封地与专属骑士团的调动权（封地位置设定未给）。
- **地貌（湖山）**：一片缓丘环抱的湖：城堡坐在西北的丘顶，缓丘上是牧草与成片阔叶林，湖在东南，湖岸边有一座小木码头与一条无帆小船；城镇沿湖岸南侧铺开，屋顶多为深蓝板岩。
- **城堡**：石砌方形外墙 + 四座圆角塔（锥顶）+ 南墙正中的门楼 + 院内方形主塔楼（四角小塔、四坡尖顶、素色三角旗）+ 内院大厅；无纹章、无文字。
- **骑士团驻地**：长方形低院墙围起的营地——两排长营房、一座长马厩（只有马厩门，不画马）、沙土校场（木栏围边）、一座瞭望塔与素色旗；不画兵器架与武器。
- **领地城镇**：山墙木石民居沿街排开，中心一座带钟塔的大厅（无标志），旁有水井与四座集市摊棚（帆布顶）。
- **领地农田**：随地形铺开的条垄作物田（绿 / 金 / 褐几种作物与休耕），田边有草垛。
- **道路**：城堡门前、城镇、骑士团驻地之间有踩实的土路相连。
- **中立性**：无人物、无动物、无文字 / 标志、无武器类细节（`docs/rejected.md` #5、#6）。

## 规模与镜头

- 场景约 660 m × 520 m：城堡、城镇、骑士团驻地各占一片平整地，农田与树林填满其余的地貌。
- 镜头：c1 主视角（自东南高处俯瞰全域）/ c2 侧视（自城镇一侧看城堡）/ under 当第二侧视（看骑士团驻地）。
- 热点：`castle`（标记 `fief1_castle`）、`order`（`fief1_order`）、`village`（`fief1_village`）、`fields`（`fief1_fields`）。
