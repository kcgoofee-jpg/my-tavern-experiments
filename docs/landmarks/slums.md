## 仓库推断

- **定位与气质**：下层棚户带里最拥挤的一片——比普通铁皮棚户区更密、更高、更乱：棚屋一层压一层往上摞，靠木板桥、爬梯和斜拉的电线互相连着；没有规划，只有一条弯曲的主巷、几条挤出来的窄弄和一处公用水点——仓库推断。
- **棚屋群**：几十座单元棚屋按网格胡乱排布，两到四层错位叠放（下大上小、悬挑），墙面是波纹铁皮、胶合板、褪色蓝防水布拼贴，屋顶单坡铁皮压着废轮胎，窗只是一个方洞或一块暖光——仓库推断。
- **管线**：外墙贴着乱接的水管与电线，屋檐间拉着下垂的线缆，屋顶有歪斜的炉管——仓库推断。
- **交通**：外挂木 / 钢阶梯、悬空木板桥、竖梯；主巷是踩实的泥地 + 碎石——仓库推断。
- **公用水点**：巷心一处立管水龙头 + 一圈水桶与积水；场地一角一座立在高脚架上的水箱——仓库推断。
- **杂物**：木托盘、油桶、成摞旧轮胎、废料堆、一排晾晒用的横杆（无衣物、无人物）——仓库推断。
- **周边（bg，不导出）**：更远处的棚屋剪影与零星灯杆——仓库推断。
- **中立性**：无人物、无文字 / 标志、无武器类细节（`docs/rejected.md` #5、#6）。
