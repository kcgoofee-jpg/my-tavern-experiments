- **烟囱**：厂房侧后立一根熏黑的砖砌高烟囱（约 28 m），顶部略收口。
- **拳笼圆场**：厂房西侧接一座半地下圆形场馆（直径约 22 m）：低矮砖鼓座 + 铁条网格穹笼罩顶，笼顶四支泛光灯；只看外观，不做内部。

- **院场与杂物**：碎石 / 沥青混铺的后院，木托盘、油桶、成摞旧轮胎、废弃货箱，铁丝网围栏（有缺口），地面有积水反光。
