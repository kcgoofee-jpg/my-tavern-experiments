# 默认决定摘要（DIGEST-1）

你不在的时候，五张审阅表（P 物品与人物、U 界面、L 图层、T 交通、Z 零配置，共 97 条）都按推荐项默认定了；P 表你 10-01 整批确认过，其余四张你还没看过。
下面挑出 12 条最影响你自己玩、或者以后最难改回来的，按对游玩的影响从大到小排；每条写清定了什么、在哪看到、为什么、另一种选法和改回来要多大工夫。
请在最后一列写「保留」或「改」（改就写想要哪种）；空着 = 保留。本文件不改任何代码或决定。语言：中文为正本（D18），无英文版。
