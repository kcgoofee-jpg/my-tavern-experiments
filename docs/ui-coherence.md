# UI 一致性标准（UI-COH-1，D46）

> 状态：2026-10-02 起生效。本文是整套界面唯一的容器 / 图标 / 徽标标准：`docs/ui-refactor.md` §2 与
> `map/ui/tokens.css` 引用本文，sweep 技能 §5b 的「视觉一致性」检查以本文为准。深浅两主题同样适用。
> 决定号：D46（提示词里写的 D45 已被 WB-2 占用，顺延）。

## 1. 容器语言（一条规则）

1. **控制组 = 一条连续的玻璃条**：缩放组 `#zoom`、层切换条 `#layers`、手机控制列 `#dock`（≤ 640 px 时整列一条）、
   桌面收起的抽屉栏（`.uis.rail` 收起态）各自是一条玻璃条（g1 / g2），**条内的图标按钮不再有自己的边框盒、
   底色盒**；悬停 = `--surface-2` 圆角底，选中 = 弱强调底 + 左缘 3 px 强调线 + 加粗（§4）。
2. **顶栏是例外**：顶栏（`header`）是工具栏，文字按钮（图层 ▾、设置）保留 `.btn` 的 1 px 描边样式；
   图标按钮（状态点）无边框。
3. **读表面板内的控件无边框**：抽屉（`.uis`，g2）头部的页签、展开按钮、层名胶囊去掉各自的边框盒——
   抽屉面板本身就是容器；悬停 `--surface-2`，选中按 §4。
4. **独立按钮保留描边**：不在任何条 / 面板里的单个按钮（卡片里的行动行、对话框按钮）保留 `.btn` 描边样式。
5. 圆角嵌套：容器 `--r-glass`（14 px），条内按钮 `--r-m`（8 px）；玻璃条内边距 `--pad-glass`（8 px），
   条内按钮间距 `--sp-1`（2 px）；条与条之间 `--sp-4`（8 px）。
6. 玻璃：浮动控制条用 g1（80 % 玻璃 + 12 px 模糊，触屏 / 低内存 / 3D 时自动改实底）；读表面板用 g2（实底）。
   3D 道具查看器（`ui/chrome3d.js`、`props/viewer3d.html`）的列条与分段条用同一套值，圆角统一 `--r-glass`。

## 2. 图标词汇表（一个图标只有一个含义）

唯一图标集：`map/ui/icons.js`（24 格网格、1.75 描线、圆头圆角、currentColor）；界面图标一律 20 px
（抽屉收起栏、顶栏、控制列、3D 列条同一尺寸；面包屑里的下拉箭头是文字内的尖角符号，14 px，不算图标）。
按钮的含义写在 `aria-label` 与 tooltip，不写在按钮里。

| 地点 / 地点介绍 | `room`（建筑） | 抽屉「地点」页；地图针只画在地图上（`.mk .pin`），不做界面图标 |

| 3D 查看（视图模式） | `cube` | 手机控制列里唯一入口 |
| 提醒 AI | `nudge`（气泡） | |

## 3. 徽标（一种数字徽标 + 红色只留给警报）

1. **计数徽标只有一类**：抽屉收起栏的 `.bdg`（小中性胶囊：`--surface-2` 底、`--line-strong` 边、10 px 数字）。
2. **红色只用于警报**：有新内容 `.bdg.new`（红底）与面包屑菜单里未解除事态数（`.n`，红底）——两者都是
   「需要看的事」，语义相同，共用红色；其余计数一律中性。
3. 不再做第二套角标（无圆点徽标、无描边徽标）。

## 4. 选中态、描边、字重

1. **选中语法**（与 `docs/ui-refactor.md` §2.5 一致）：选中 = 左缘 3 px 强调线 + 弱强调底 + 加粗，
   不是强调色实底胶囊。分段控件（清晰度 / 语言 / 视图模式 / 3D 分段）与列表选中（层切换、抽屉页签、
   设置分组、面包屑菜单当前项）一律如此。
2. 开关类图标按钮（标注 Aa、提醒 AI 无状态）：开 = 弱强调底 + 强调色图标，关 = `--muted` 图标
   （aria-pressed 承载状态）。
3. 描边一律 1 px `--line`，悬停 `--line-strong`；强调色只用于选中、主按钮、开关轨道（§2.5）。

## 5. 审计表（2026-10-02，UI-COH-1 逐项）

逐组对照桌面 / 手机、2D / 3D 的现状；「处理」列 = 已修复或明确保留（附理由）。

| 组 | 现状问题 | 处理 |
| --- | --- | --- |
| 桌面收起抽屉栏 | 每个图标各自 1 px 边框盒，碎块感（用户 2026-10-02 点名） | 修复：去边框盒，栏 = 一条玻璃条，悬停 / 选中按 §1 / §4 |
| 抽屉「地点」页图标 | 用地图针 `pin`，与「我的位置」含义冲突（用户点名） | 修复：换 `room` 建筑图形（`core/drawer-tabs.mjs`，测试同步） |
| 抽屉页签（手机底部 / 右栏展开） | 页签带 1 px 边框盒，与读表面板内无边框规则不符 | 修复：去边框，悬停 / 选中态保留 |
| 手机抽屉 | 拖柄 + 「展开」文字按钮重复同一动作（HEADER-1 后遗留） | 修复：文字按钮改纯图标箭头（44 px 热区、aria-label 保留，等价操作不丢） |
| 手机 3D 控制列 | ⋯、立方体、缩放条三个独立盒子（HEADER-1 后遗留） | 修复：≤ 640 px 整列一条玻璃条，条内按钮裸排 |
| 提醒 AI 按钮 | 自成一个玻璃盒，悬在控制列里像第四个组 | 修复：并入缩放条（条内第一枚），不再自带盒子 |
| 桌面顶栏状态 | 绿点 + 「✓ 已加载」文字两种呈现，✓ 是文字字形（协调者点名） | 修复：加载完成只亮绿点（文字进 tooltip / aria），i18n 去掉 ✓ 字形；加载中的百分比文字保留（进度不是状态重复） |
| 手机顶栏面包屑 | 大片空位时提前截断成「伊甸…」（协调者点名） | 修复：最后一个面包屑占满剩余宽度再省略 |
| 面包屑菜单 | 单层 + 多个 3D 页时不画分组线；17 条一列铺开（协调者点名） | 修复：两组都非空即画分隔线；可见高度已封顶（100vh − 顶栏），> 25 条才考虑筛选框（现为 0 个包达到） |
| 3D 道具查看器（chrome3d / viewer3d） | 容器圆角 12 px（--r-l）与玻璃条 14 px 混用；选中 = 强调色实底；列条底色用不透明 --surface；.btn 自带描边底色 | 修复：圆角统一 --r-glass / 条内 --r-m；选中按 §4 语法；列条与分段条改 g1 值；aria-pressed 图标钮改弱强调底 |
| 3D 主场景视图分段（estate-shell #v3seg） | 选中 = 强调色实底 + 反色字，与 2D 分段控件不同 | 修复：统一 §4 选中语法 |
| 卡片行动行（#card .extra） | 1 px 边框 + 弱底 + 强调色字，与设置分组行（无边框）不同 | 保留：卡片行动行是浮在阅读面板上的主操作，描边把它与静文本区分开；设置分组行是纯导航，两级语义本就不同 |
| 物品图标 vs 3D 立方体 | 字形相近 | 保留（见词汇表备注）：不同界面、tooltip 区分 |
| 图标尺寸 | 顶栏 18 px / 抽屉栏 22 px / 控制列 20 px 混用 | 修复：界面图标统一 20 px（文字内尖角 14 px 除外） |
| 徽标 | 已只有 .bdg 一类 | 保留：规则成文（§3） |
