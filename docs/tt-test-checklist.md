# TT 实测清单 · 截至 v0.9.5

第 0–7 节是 v0.9.1 基线的步骤（版本号改成当前版本即可），第 8b / 8c / 8d 节分别是 v0.9.2 / v0.9.3 / v0.9.5 的新增项。

手机（iPhone / 安卓 TT）和桌面（电脑浏览器或 macOS TT）各走一遍。每项后面是「应该看到什么」；不一样就按最后一节截图。
测正式版之前，可以先用跟随分支的预览脚本（`【地图】预览-跟随-cloud-tc-mid-low`）走一遍，步骤相同。

## 0. 准备
1. 酒馆助手 → 脚本 → 导入 `~/Downloads/酒馆/脚本/【地图】伊甸地图 v<当前版本>.json`（v0.9.5 起文件里带版本号），确认启用。
   - 同时只留一个地图脚本：停用预览脚本，以及旧卡「母畜庄园·地图版 v0.6.1」自带的「【地图】世界地图」。
2. 世界书 → 导入 `~/Downloads/酒馆/世界书/伊甸地图·世界书附加条目 v<当前版本>.json`，挂到角色（或设为全局）。
   - 应该有 3 个常驻条目：地图联动规范 v3、地图事件类型 v2、地图当前地点；v0.9.3 起还有人物位置 1 条，方位 3 条（上层 / 中层 / 下层）在 v0.9.5 起改为聊天里出现该层层名或地标名时才触发。
3. 用原卡（母畜庄园）开一个新聊天。角色卡不用改。

## 1. 首次打开
| # | 做什么 | 应该看到 |
|---|---|---|
| 1.1 | 进聊天，什么都不点，等 10–20 秒 | 悬浮按钮上有一圈预加载进度环，走满后短暂变绿；失败是红色虚线环（点开会让你重试）。省流设备（内存 ≤ 4 GB、省流模式、2G / 3G，很多安卓机）只预取程序和数据：环走到约 80% 就消失、不变绿，这是正常的 |
| 1.2 | 看标题栏「线路」 | 预加载时已自动选了最快的一条；点「线路」弹出「选择加载线路」，每条有延迟，快的标「推荐」。只有所有线路都连不上时，第一次点按钮才会直接弹出它 |
| 1.3 | 预加载完成后点按钮 | 秒开（1 秒内出图）；省流设备首开要加载首屏图块，慢一些 |
| 1.4 | 关掉面板，3 分钟内再开 | 还是秒开；超过 3 分钟再开会重新加载，进度 0→100% |
| 1.5 | 加载中 | 进度只增不减；8 秒提示网络慢，20 秒提示卡住并给「重试 / 换线路」 |

## 2. 没梯子
1. 关掉 VPN，标题栏「线路」选「没梯子」（国内镜像 jsdmirror），刷新酒馆。
2. 应该看到：地图正常出图（首屏可以慢一点，但不卡死）；切层、放大能加载新图块。
3. 进伊甸庄园（3D）：网络连不上 3D 库时，出现「重试 / 看平面图」，不会困在空白页（应在约 1 秒内出现；已知问题：目前要等约 12 秒，修复中）。
4. 版本编码（桌面在地图左下角，手机在「⋯」里；庄园页里不显示）：尾号应该对应你的客户端（I = iPhone / iPad、A = 安卓、M = Mac、W = Windows、S = 其他）。

## 3. 手机单手
- 面板全屏；顶栏一行不折行（「没梯子」不断成两行），多余按钮收在「⋯」里。
- 单指拖动、双指缩放顺手；所有按钮单手够得着、点得中（不误触旁边的按钮）。
- 悬浮按钮可以拖到拇指边，位置会记住。
- 竖屏看一层能看全；地点卡从底部抽屉弹出，能关掉。
- 记下哪些按钮单手够不到（下个版本做左右手设置）。

## 4. 当前地点跟随（MVU）
1. 聊到角色进庄园某个房间（或在 MVU 面板把「世界.当前地点」改成 `伊甸庄园·书房`）。
2. 打开地图：直接进伊甸庄园，落到书房所在楼层并高亮。
3. 改成 `天城·下层·7号井黑市` → 落到下层、聚焦 7 号井；改成 `中层` → 中层默认视野；写一个认不出的地名 → 地图不动。
4. 标题栏的「当前地点」随变量更新；地图总是先开世界图，点工具栏「当前位置」才跳到当前地点。

## 5. 事件标签 → 地图
1. 让剧情里出现一条快讯或通报（比如执法局通报下层火灾）。模型应该在载体末尾写隐藏标签，正文里看不到标签。
2. 应该看到：悬浮按钮出现新事件角标；打开面板飞到该事件，底部「N 起事态」横条，事件点按大类配色、按类型配图标字。
3. 让事件解除（「火已扑灭」）：事件点变灰，横条计数减少。
4. 重 roll / 删掉那一楼：事件跟着消失。
5. 网络攻击事件：所在层（或全城）的地图间歇花屏，配「⚠ 数据链路受扰」；⚙ 设置里「关闭花屏特效」能关。
6. 如果模型从来不写标签，或者照抄世界书里的示范原文：截模型那一楼的原文（长按「编辑」看源码）。

## 6. 天城上层与云海
- 上层默认是云海；打开「显示下方城市」换成带城市的底图，状态会记住。
- 切换时不出现长时间黑屏（面板收起时后台已经在预取）。
- 注：云海还要重做，这一项只看开关好不好用，不评价云的样子。

## 7. 伊甸庄园
- 上层点伊甸庄园 →「进入伊甸庄园」：3D 剖切模型打开，楼层条能切楼层。
- 缩放、旋转顺手；手机上画面不糊、不明显卡顿（记一下大概流畅不流畅）。
- 返回上层不丢视野。

## 8. 英文 / 浅色
- ⚙ 设置 → 界面语言选 English、界面主题选浅色：地图、层切换器、事态条、地点卡、庄园页都换过去。
- 看有没有文字溢出、被截断、浅色下看不清的文字。

## 8b. v0.9.2 新增（界面去重、单手、人物栏）
1. 桌面打开下层：标题栏左边只有「新历 2088」，层名只在面包屑；右边一个地点胶囊（MVU 写了两处时显示「第一处 +1」，点一下 / 悬停看全文），不和别的挤在一起。
2. 开一条落在地标上的事态：地图上只剩事态图标 + 事态标题（地标针脚和地名让位）；卡片顶上一个大类色块，副标题只写类型，地点不重复层名；层按钮只有红数字。
3. 手机：设置里「单手」选左手 / 右手，菜单、缩放、楼层条到拇指一侧；双击后按住上下拖 = 单指缩放；卡片抽屉往下拖能关。
4. 人物栏：让模型写一次 `⌖人物 名字 @ 下层·7号井`（或 MVU 有在场人物表）→ 横条出现「人物 N」页签；列表有名字、地点、楼层；点一人飞过去；地图上是圆形头像框（和事态方块不同），同处多人叠成一组；总开关、逐人开关换聊天各自记住。
5. 控制台：`EdenMap.setAvatar('名字', 'data:image/png;base64,…')` → 头像框换成图；`EdenMap.removeAvatar('名字')` 恢复首字。
6. 卡片的 × 与右边缘：如果别的扩展（例如狐狸精灵）盖住了 ×，截图反馈。

## 8d. v0.9.5 自定义面板
1. 新聊天：设置 →「同步到世界书」默认勾着，世界书列表里还没有「伊甸地图·自定义·xxxxxx」。
2. 设置 →「名称与用途」→ 添加：搜「书房」，选中，起名「星图室」写一句用途 → 保存；卡片显示「书房 → 星图室」「手动」；此时世界书才出现并绑定到聊天。
3. 卡片上点「在地图上看」：进庄园并聚焦书房（庄园加载失败过的会话：落到上层伊甸，地点卡写「要看的房间」）。搜一个中层地标点定位图标：切到中层并开卡。
4. 「重置」点一下变「确认重置」，再点才删。Esc：编辑页 → 列表 → 关闭，焦点回到入口按钮。
5. 切浅色 / 深色（☀ 按钮）：对话框、搜索框、宿主标题栏、自检提示一起换，文字都看得清。
6. 手机 375 宽：对话框全屏，按钮不小于手指。

## 8c. v0.9.3 MVU 联动
先导入新版「伊甸地图·世界书附加条目 v0.9.3」（多了「地图人物位置」和三条「地图方位」）；要装「提示词模板」扩展，没装时自检会提示关掉方位条目。
1. 标题栏「新历 2088」旁边出现剧情内时刻（如「01.12 23:30」），悬停看全文；推进到就寝时段，打开上层 / 中层：地图变暗一点；下层、庄园不变；设置 →「夜间给上层、中层加一层夜色」关掉即恢复。
2. 当前地点写到某个天城地标：点该地标的卡片，多一行「着装：…」（主角着装初始化之后）；控制台 `await EdenMap.getOutfit()` 有值。
3. 让一个在场人物去别处：模型应写 `⌖人物 名字 @ 层·地点`；人物页签里这人标「标签」，没写的在场人物标「推断」。
4. 设置 →「名称与用途」→ 添加：选「书房」起名「星图室」写一句用途 → 地图标签 / 卡片换名；下一轮发送后，模型提示词里有「[地图自定义…] 书房→星图室」；换聊天再回来还在（存在聊天变量）。
5. 让剧情里改一次名（模型写 `⌖改名 客房 → 画室`）：地图上方提示一次「客房 改名为「画室」」，自定义列表多一项；再发一楼不重复提示。
6. 打开「同步到世界书」：世界书列表出现「伊甸地图·自定义·xxxxxx」（每个聊天一本），本聊天绑定了它（聊天原本有世界书时不绑定，设置里有提示）。关掉后条目停用，世界书不删。
5b. 重 roll 带 `⌖改名` 的那一楼、换成没有标签的回复：改名撤回；再 roll 回原来那条，改名重新生效。
7. 当前地点写「天城·中层·天城执法局总局」：用提示词查看器看，出现一行「[地图方位·仅背景] 天城执法局总局：…；附近：…」，其他层的方位条目为空。
8. 自检一栏：「MVU 在场人物 / 世界时间 / 着装可读」「自定义名称存在聊天变量」都是 ✓。

## 9. 出问题时截什么
每个问题一组，发给我：
1. **整屏截图**（带标题栏和悬浮按钮）；手机横竖屏哪种。
2. **版本编码**：点版本编码（`S1-…`，桌面在左下角，手机在「⋯」里），会复制一段诊断信息，直接粘贴过来。
3. **第几步、做了什么**：比如「5.2，删楼后事件没消失」。
4. 网络：有没有梯子、选的哪条线路。
5. 事件或当前地点不对：那一楼的原文（含隐藏标签），以及 MVU「世界.当前地点」当时的值。
6. 卡住 / 白屏：等 20 秒后的截图（有没有出现「重试 / 换线路」）。
7. 桌面可以再附浏览器控制台里带「[地图]」的几行（F12 → Console）。
