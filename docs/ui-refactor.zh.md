## 2. 视觉系统

### 2.1 原则

1. **地图就是内容。** 外壳以玻璃浮在上面，只遮必须遮的；阅读面不透明。主题只换外壳，绝不给底图加滤镜、蒙层或提亮；地图的
   明暗只由时段色调（K-R39）负责（R0：P5-4）。
2. **一条公式，多套皮。** 组件只引用语义令牌；包和主题改令牌值，不改组件 CSS（`tokens.css` L3 现有规则，保留）。**外壳只有一套**
   （U-04 B′）：外壳令牌在包的每个视图、二维和三维里都相同；包与视图的个性放在地图空间令牌 `--map-*` 里。
3. **默认安静。** 动效短（≤ `--dur-3`）、有目的；减少动态、文档隐藏、地图面板隐藏时停；外壳文字不用发光 / 霓虹效果。
4. **每种状态都看得见。** 开 / 关 / 此处不适用 / 未生效 / 等待各有不只靠颜色的区分（形状、图标或文字）。
5. **紧凑的按钮列与导轨只用图标**（UI-3D-1）。缩放列、控制列、抽屉导轨和手机控制列只放图标，文字写在 `aria-label` 和提示里；可见的文字只出现在卡片、菜单和抽屉里（菜单项可以是文字）。楼层 / 层级条只显示短码（F3、B1），全名放进 `aria-label` 和 `title`。需要文字才看得懂的按钮，放进菜单，不放进按钮列。
6. **一条信息、一个动作，每屏只出现一次**（HEADER-1，D37）。一条事实（当前位置、事态数、加载状态、地图的素材来源）和一个动作（定位到我、返回上一级、切层、关闭、给名字挂到地图上）在一屏里都只有一个看得见的位置，放在最适合它的地方：切层在面包屑最后一节，定位在缩放列的图标，关闭是宿主的 ×，数字写在它自己的页签上。加控件之前先在这一屏里找有没有同一条事实或动作；有，就挪过去，不要再复制一份。

### 2.2 颜色与玻璃令牌（暗霜玻璃）

## 6. 无障碍

- 对比度：正文 ≥ 4.5:1，大字（≥ 18.66 px 粗体 / 24 px）与图标 ≥ 3:1。每种玻璃面叠在**三种**背景上测——纯黑、纯白、当前地图亮度
  第 95 百分位的瓦片——覆盖 `--ink`、`--ink-2`、`--muted`（只在 glass-2）、强调色、焦点环、开关边框，两种主题、每个包视图都测
  （R0：P4-1、P5-2）。glass-1 上 13 px / 600 **不算**大字。
- 触控区：44 px（§5 第 1 条）。焦点：每个控件（包括玻璃胶囊）用双层焦点环（§2.2）。
- 减少动态：`html.rm` 与 `prefers-reduced-motion` 停掉所有 CSS 动效（保留）、所有图层 rAF（§4），并传进 3D 帧（状态消息带 `rm`：
  不空闲自转、相机直接跳、小牌不做动画；主题瞬切）（R0：P4-8）。
- 减少透明：`prefers-reduced-transparency` 与 `html.noblur` / `html.lowmem` → 不透明，查看器、宿主页令牌块和 3D 帧都一样（P4-15）。
- 读屏：灰掉的图层行是带名字的组，原因走 `aria-describedby`，不加 `aria-disabled`（§3.3）；功能卡健康用形状图标（✓ 正常、! 未生效、
  ◷ 等待、– 关）加 `aria-label`；一个共用的 `aria-live="polite"` 区域只播报状态**变化**的那张卡，最多 5 秒一次（R0：P4-4、P4-6）；
  时钟胶囊有带完整日期与时段的 `aria-label`；状态从不只靠颜色。
- 名称：每个按钮、开关、标签页都有非空的无障碍名称（设置滑杆图标、+ / − / 定位到我 / Aa / ⋯、提醒铃、侧栏图标、带
  `aria-haspopup`、`aria-expanded` 和方向键焦点的 `编辑 ⋯`）；由无障碍树探针 `a11y_tree` 在二维和三维外壳里检查（R0：P4-9）。
- 键盘：弹层和设置保留焦点陷阱（`settings.mjs` L128–131）。跨文档的 Tab 顺序：宿主栏 → 查看器页头 → 图层 → 层级条 → 工具列 →
  抽屉；3D iframe `tabindex=-1`，在里面按 Esc 会发给上层（U-25）。Esc 依次关闭：卡片 → 弹层 → 抽屉（半开 → peek）（R0：P2-8、
  P4-10）。开了单字母快捷键（`edenMapKeys`）时：已有的 `L` 图层、`M`、`/`、`?`，再加 `,` 设置、3D 里 `1` / `2` / `3` 切视图。

## 9. 风险

- `backdrop-filter` 的开销 → 模糊预算（§2.2）：glass-2 不透明，glass-1 只用在四个小元素上，触屏和 3D 里不模糊；`pan_frame` 与
  `html.noblur` 比，差值超过 2 ms 时 glass-1 降为不透明。
- `color-mix` 支持：所有支持的浏览器（Chromium ≥ 111、Safari ≥ 16.2）都有；令牌在每个 `color-mix` 声明前留一行普通值兜底。
- 探针用到的设置 id：页 id 保留，`display` 设别名；行搬家时控件 id 保留；懒构建的页在探针读之前先构建（`SettingsApi.open(page)`
  会构建该页）。
