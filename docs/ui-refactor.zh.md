## 2. 视觉系统

### 2.1 原则

1. **地图就是内容。** 外壳以玻璃浮在上面，只遮必须遮的；阅读面接近不透明。
2. **一条公式，多套皮。** 组件只引用语义令牌；包和主题改令牌值，不改组件 CSS（`tokens.css` L3 现有规则，保留）。
3. **默认安静。** 动效短（≤ `--dur-3`）、有目的，减少动态效果和文档隐藏时停。
4. **每种状态都看得见。** 开 / 关 / 此处不适用 / 未生效各有不只靠颜色的区分。

## 4. 图层适用性与动画暂停

## 6. 无障碍

- 对比度：正文 ≥ 4.5:1，大字与图标 ≥ 3:1，以玻璃色分别叠在纯黑和纯白背景上测（取最差）；现有探针 `contrast_v2` 为两种主题下的

- 减少透明：`prefers-reduced-transparency` 与 `html.noblur` / `html.lowmem` → 不透明。

## 9. 风险

- 低端手机上 `backdrop-filter` 的开销 → 粗指针默认不透明（§5 第 6 条）；由性能角色决定。

- 探针用到的设置 id：页 id 保留，`display` 设别名；行搬家时控件 id 保留。
- 并行工作：S8-4（交通，`docs/transit-schema.md`）负责路由器、`routes` 字段和绘制；S7-1 等 S8-4b，只加操作和 `routeOp` 调用。
