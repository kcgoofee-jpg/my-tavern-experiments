## 2. 每座岛都不一样

### 轮廓
按岛 id 的 md5 定种子，同一座岛每次都一样。极坐标半径 = 椭圆 ×（1 + 4 个低频谐波 + 1 个细碎岸线谐波），形成海岬与内湾。

| 轮廓 | 比例 | 做法 |
|---|---|---|
| `round` | 40 % | 标准谐波 |
| `cape` | 35 % | 谐波更强 |
| `long` | 15 % | 拉成长条（1.25 : 0.72） |
| `twin` | 10 % | 上下收腰的葫芦形（双峰） |

伊甸、银冠堡的谐波减半，轮廓更稳重。

### 地形
岛心（园子）平缓，外圈起伏；另按风格随机加一种地形：

| 地形 | 做法 |
|---|---|
| `terrace` 台地 | 主楼坐在台地上，台地边是陡坎 |
| `lake` 湖 | 凹地 + 水面；湖靠岸时有一道溪流流到岛缘，出水口是白色水花，侧面有一条瀑布 |
| `crag` 裸岩峰 | 外圈凸起的岩峰 + 散石 |
| `meadow` 草甸 | 只有起伏 |

岛面材质按法线自动露岩，台地边与崖边一眼能看出。

### 岛缘
不再是统一的浅色描边圈：

| 岛缘 | 做法 |
|---|---|
| `cliff` 崖边 | 外圈下塌露岩 + 碎石 |
| `wall` 石墙 | 墙带墩柱 |
| `hedge` 林带 | 岸线内一圈密树 |
| `roots` 垂根 | 岸线外挂一圈深色藤根 |

### 草色
按风格：英式深绿草场、法式修剪浅绿、苏州偏黄绿、岭南浓荫深绿、伊甸明绿。每座岛再随机偏一点明度与色相（Object Info · Random）。

### 布局
主楼位置在台地中心，或在岛心附近随机取点，不都放正中；朝向随机。平面也随机：
- 英式：L / H / E / 回字。
- 法式：U 形 + 角楼，中轴朝四个方向之一。

附属建筑随岛而变，0–3 座：温室、马厩院、仆役楼、亭、机库 + 停机坪（私人飞艇）。

### 园林（占岛面多数）

| 风格 | 园林 |
|---|---|
| 英式 | 弯曲砾石车道、蛇形湖 + 湖边小神庙、红砖围墙菜园（菜畦网格 + 靠墙温室）、草甸割草步道、成团的树 |
| 法式 | 砾石前庭、刺绣花坛（2–3 × 2–3 格，三种绿篱图案）、中轴圆池、大水渠（部分有横渠）、两侧丛林块与林荫道、橘园 |
| 苏州 | 不规则白墙围合（5–8 边）+ 黛瓦墙顶、分院墙、拼合的不规则池、假山石、九曲桥、厅与亭、沿墙的廊；园外竹林团与顺着岛弧的茶垄 |
| 岭南 | 青砖灰瓦院落群（2–3 × 1–2 组，带天井）、方池 + 水榭、大榕树、荔枝林（网格） |

其余空地按风格补树：英式、岭南成团，法式在规整园外，苏州以竹为主。

### 导出
`map/data/tc_upper.json` 的每座岛新增：
- `outline`：36 个点的归一化多边形，左上原点，与 `nx/ny` 同一坐标系。
- `shape`、`rim`、`terrain`。
- `role`：地标府邸才有。

## 4. 伊甸本岛（按 `docs/eden-estate.md` 的室外布局）
- **府邸**：`eden_manor.build_eden_manor`（1:100），坐岛心偏前，正面朝 -y。
- **前庭**：砾石广场、中央大喷泉、左右各 3 × 2 格刺绣花坛。
- **中轴大道**：从前庭直通岛缘的访客停靠平台（伸出岛缘的圆台 + 候机亭 + 两艘飞艇）。两侧林荫与雕像台座，中间是条纹草坪（tapis vert）。
- **后庭**：不规则人工湖、湖心圆亭、船屋、湖边台阶平台。
- **加建用地**：东西两侧各一块约 105 × 95 m 的设计草坪，绿篱框、十字砾石路、中心小池、四角雕像、条纹割草；以后加建直接替换。
- **东北**：红砖围墙花园 + 玻璃暖房。
- **西北**：马厩 / 机库、仆役楼。
- **外圈**：整圈白石栏杆（带墩柱）+ 林带；园中孤植大树、成团的树与林间草地。
- **云**：伊甸外圈的亮云环跟着 `rx / ry` 放大（`tc_clouds.py` 读岛的尺寸）。

## 5. 航线（任务 5 · 3）
`tc_upper.json` 新增 `routes`，都是归一化折线：
- `lane`：各停靠平台 ↔ 伊甸 / 银冠堡，略带弧度。
- `patrol`：银冠堡巡逻环，约 250 × 180 m。
- `patrol_city`：骑士团巡空大环线，银冠堡 → 将军官邸 → 首相府 → 财团庄园 → 伊甸 → 联盟会所 → 银冠堡。

本机在查看器里画成可开关的叠加层。
