## 2. 每座岛都不一样

### 风格分配（B2 第 2 轮）
- 英式 11 / 法式 8 / 苏州 6 / 岭南 6（另有伊甸新古典、银冠堡要塞）。按**边缘间距**取每座岛最近的 2 个邻岛，没有同风格（导出前断言）。
- 苏州样板岛 isle22（rx .78）、岭南样板岛 isle12（rx .80）。
- 每座岛在 `tc_islands.json` 里显式写 `shape / rim / terrain`；同风格普通岛的 `(shape, rim, terrain, 布局族, 主楼平面)` 两两不同（导出前断言）。
- 布局族与主楼平面（`layout / plan`）：同风格普通岛按 id 排序后轮流分配（`tc_estates.assign_families`），并排的 6 座不重复；地标岛另起一轮；数据里写了就用数据。

### 轮廓
按岛 id 的 md5 定种子，同一座岛每次都一样。极坐标半径 = 椭圆 ×（1 + 4 个低频谐波 + 1 个细碎岸线谐波），形成海岬与内湾。

| 轮廓 | 做法 |
|---|---|
| `round` | 标准谐波 |
| `cape` | 谐波更强 |
| `long` | 拉成长条（1.25 : 0.72） |
| `twin` | 上下收腰的葫芦形；腰宽 `.42 + .6·|cos|^.7`，≤ 两头的 55 % |

伊甸、银冠堡的谐波减半，轮廓更稳重。

### 地形
岛心（园子）平缓，外圈起伏。法式、苏州、岭南、伊甸的园林核心压平（椭圆内地形噪声为 0），花坛、条纹草坪、池面不再被地形吞掉。

| 地形 | 做法 |
|---|---|
| `terrace` 台地 | 不规则多边形（圆角方台或谐波台），缓坡 `.14·F`；挡土墙**只砌朝岸一侧的开口弧**（本版 133–200°，断言 ≤ 220°），中间留台阶口，另一侧顺坡。法式前庭不许跨出台地 |
| `lake` 湖 | 凹地 + 水面；靠岸时有一道溪流流到岛缘，出水口是沿岸线的细长水花弧片，侧面有一条瀑布。苏州岛的湖就是园池（不下凹，画在压平的园心） |
| `crag` 裸岩峰 | 外圈凸起的岩峰 + 散石 |
| `meadow` 草甸 | 只有起伏 |

岛面材质只在真正陡的地方露岩（法线 z < .80–.88），台地缓坡不再出米白 / 浅绿晕；另加低频明度斑块（±8 %）。岛底岩体第 1 层缩到 .86，抖动后也不超出岸线。

### 岛缘
不再是统一的一圈：按角度分 **3–6 段混用**，每岛的 `rim` 是主岛缘（约 60 %），另有次岛缘，至少一段什么都没有（草直接到崖口）。

| 岛缘 | 做法 |
|---|---|
| `cliff` 崖边 | 外圈下塌露岩 + 成团碎石（只在崖边段下塌） |
| `wall` 石墙 | 墙带墩柱 |
| `hedge` 林带 | 岸线内成团的大树（冠幅半径 .04–.07） |
| `roots` 垂根 | 岸线外挂成团的深色藤根，长短不一 |

### 树
- 冠幅半径 `.045–.09`（冠径 9–18 m，真实尺度），树数约为旧版的 1/5，面数反而少（本版 0.81 × r4）。
- 树冠不伸出岸线；修剪紫杉 / 黄杨球（`topiary`）是唯一的小冠白名单。
- 英式：外圈偏置（60 %）+ 3–6 个 15–25 株的大树团 + 草坡上少量孤植。法式：园内只有规则种植的方块丛林（每 4 行 / 列留一条直园路），随机树只在岛缘。苏州 / 岭南：园外才补树，树冠不进园子与建筑包络。

### 园林（占岛面多数；导出前断言每座普通岛和地标岛的园林覆盖 ≥ 50 %）

| 风格 | 布局族（轮流分配） | 园林 |
|---|---|---|
| 英式 | 菜园 ×3 / 眺望塔 / 林荫道 / 果园 / 船屋（/ 鹿苑） | 主楼（L / H / E / 回字）前的回车圆 + 从岛缘绕进来的车道；**连续蛇形湖**（沿正弦曲线的一条带状水面，一头收成小溪，放在主楼正前方）；湖端 8 柱圆形小神庙；隐垣（ha-ha）；菜园出现率约 40 %（方 / D 形 / 圆） |
| 法式 | 中轴水渠 / 护城河 / 水镜 + 鹅掌路 / T 形运河 + 下沉花坛 / 狩猎小楼 + 星形林路；主楼平面 U 形 / 方楼 / 长楼 | 正面（-v）是砾石荣誉庭院；**花坛在园林立面（+v）**，宽 `L·1.6`，含卷草纹 broderie；水渠宽 `.07F + .02`，每 .02 采样 `inside(.85)` 截断，横渠两端也截在岸内；其余园地是方块丛林 |
| 苏州 | 水湾 / 池中岛 / 双池 | 园墙贴岸（`.84·r(θ)`，园占岛约 70 %）；白墙露边（墙 .008、瓦带 .004）；**池占园 37 %**，带伸向墙角的水口；厅在池南（面阔约 15 m，屋脊浅灰脊线）、假山在池北（厅—池—山）；三面以上连续的廊；2–3 道带洞门缺口的分院墙；九曲桥（石色，每段转 ±45°，约池宽 60 %）+ 平板石桥；花街铺地 + 灌丛种植池，粉花 ≤ 2 株 |
| 岭南 | 前池 / 侧池 / 院中池；院落 3 × 3 / 3 × 2 / 2 × 3 | 按岛找最大的矩形园区，青砖墙围合；**前方池占园 25 %** + 半伸进池的水榭 + 直廊桥；梳式院落（三间主屋两端**镬耳山墙**、天井、两廊、窄巷）；一角三层方阁；1–2 株大榕树放在园外入口；园外荔枝林成网格；青砖 `(.33,.36,.38)`、黛瓦更暗 |

## 4. 伊甸本岛（按 `docs/eden-estate.md` 的室外布局）
- **府邸**：`eden_manor.build_eden_manor`（1:100），坐岛心偏前，正面朝 -y。
- **前半（法式）**：
  - 前庭砾石 1.9 × 0.65，中央大喷泉，左右各 3 × 2 格花坛（每格约 24 × 26 m，一半是卷草纹）。
  - 中轴：tapis vert 条纹草坪 + 两侧砾石园路 + **双排林荫** + 雕像台座，直通停靠平台。
  - 两侧**方块丛林**（每侧 4 列 × 3 排，块间直园路）；玫瑰园、迷园在前庭花坛外侧。
- **分界**：y ≈ 0.82 一道**隐垣（ha-ha）**东西横贯。
- **后半（英式）**：花园厅台阶下来的连续白石台地、不规则人工湖 + 湖心圆亭 + 水榭；布朗式 6–8 个大树团 + 草坡孤植大树。
- **加建用地**：两块**不同的下沉草坪（boulingrin）**——西：方形，花境 + 坡面 + 中央水池（半径 8 m）+ 四角小丛林；东：椭圆，草坪里切出砾石卷草纹（gazon coupé）+ 中心雕像 + 四角树团。十字路是砾石色，草色与岛面明度差 ≤ 8 %（图像自检）。
- **东北**：红砖围墙花园 + 石柱橘园；**西北**：仆役楼、马车房、工坊、机坪 + 机库；**东北角**：果园。
- **观景台**：后轴 `0.97·r(π/2)` 一座半圆台 + 小圆亭；东西各一座小圆亭。
- **结界锚碑 ×4**：按 `0.82·r(t)` 取点（t ≈ ±0.45、π ± 0.45，与别的部件冲突时沿轮廓挪开）。
- **访客停靠平台**：直径 52 m，白石 + 金环 + 候机亭，两艘浅色长飞艇（3 : 1）。
- **外圈**：整圈白石栏杆（带墩柱）+ 林带（前轴与平台前留空）。
- **云**：伊甸外圈的亮云环沿真实轮廓 × 1.25–1.5 排约 30 团（`tc_clouds.py`）。

## 5. 航线（任务 5 · 3；B2 第 2 轮重做）
`tc_upper.json` 的 `routes` 都是归一化折线：
- `lane`：有岸外停靠平台的地标岛（首相府、联盟会所、财团庄园）↔ 伊甸 / 银冠堡。**端点是岸外平台中心**；在所有岛轮廓外扩 40 m 的障碍外做 A*（放不下时逐步收到 30 / 22 / 15 m），再拉直 + Chaikin 平滑，拐点都在岛外。
- `patrol`：银冠堡巡逻环，约 250 × 180 m。
- `patrol_city`：骑士团巡空大环线，银冠堡 → 将军官邸 → 首相府 → 财团庄园 → 伊甸 → 联盟会所 → 银冠堡；航点在各地标岛平台（或岸）外 70 m，段间同样在岛外寻路。
- 导出前断言：每段加密 25 倍的采样点不落入任何岛轮廓（lane 端点平台 30 m 内除外）。

本机在查看器里画成可开关的叠加层。
