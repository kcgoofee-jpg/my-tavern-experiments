# 天城事态看板：前端载体 → 地图联动（设计草案 v0）

> 目标：地图不只是地图，而是天城的「城市态势看板」。剧情里生成的前端载体（新闻快讯、执法局通缉、火警、黑市情报……）自动在地图上落点；地图的态势又反过来喂给模型，让之后的前端和叙事跟着变（网络攻击 → 地图花屏 → 屏幕类载体出马赛克）。先小后大，但格局按「城市级实时事件系统」设计。

## 0. 现状与硬约束
- 前端载体由模型按世界书《天城视觉规范》生成：只用内联样式，**不能有脚本**，包在 `<htm1fenge>` 里，常带一个 `display:none` 的说明 span。
- 地图：查看器 `map/viewer.html`（OpenSeadragon，非地理坐标，平面归一化坐标）在 iframe 里；卡内脚本 `map/tavern/eden-map.js` 跑在酒馆助手（JS-Slash-Runner）环境，能用 `eventOn / getChatMessages / injectPrompts` 等接口，与查看器之间用 postMessage（`eden-map:*`）。
- 地点：`map/data/maps.json` 里每张图的 markers（名字 + alias）；天城三层有城区划分（中层核心 / 商业 / 外围，下层工业 / 贫民 / 高密旧楼）。
- 内容边界：事件只做城市治安、灾害、网络、公共事务类；不做性相关或束缚类标记。

## 1. 数据流：聊天记录是唯一真相
```
模型输出（前端载体 + 一行隐藏事件标记）
  → eden-map.js 监听 消息收到 / 编辑 / 滑动(swipe) / 删除 / 切换聊天
  → 从最近 N 楼的原始文本（chat[i].mes）解析事件（纯函数，可重算）
  → postMessage('eden-map:events', 列表) → 查看器画事件层 + 事态列表
  → 活跃事件摘要 → injectPrompts（≤150 字）→ 模型下一轮知道「城里正在发生什么」
```
- 从原始文本解析而不是从 DOM：不受酒馆 HTML 净化、渲染时机、折叠影响。
- 纯函数重算：swipe、删楼、回滚后地图自动一致，不需要持久化状态，也不会和 MVU 变量漂移。

## 2. 事件标记（写进世界书，模型照写）
在载体末尾（`</htm1fenge>` 之前）加一行隐藏文本，一楼最多 3 条：
```html
<span style="display:none">⌖火灾｜中层·霓虹街C区｜2｜霓街17号仓库起火，三人被困</span>
```
字段：`⌖类别｜地点｜等级 1–3｜一句话`。可选第 5 段 `来源`（天城一台 / 执法局 / 黑市终端…），缺省按载体推断。
- 类别（首批）：火灾、盗窃、凶案、通缉、抗议、事故、网络攻击、停电、管控、直播（仪式 / 大型活动）。
- 为什么用纯文本 + 全角分隔：模型最不容易写错，净化器不会删，正则一行就能解析，玩家看不见。

## 3. 地点解析（地名表）
1. 精确匹配 markers 名字 / alias（执法局总局、7 号井、辉光大教堂……）。
2. 匹配城区关键词（中层·商业区、C区、外围、下层工业带、7 号井一带……）→ 城区中心 + 按事件标题哈希的确定性偏移（同一事件每次落在同一点）。
3. 只认出层（「中层某处」）→ 该层内确定性散点，画成虚线圈「大致位置」。
4. 天城以外（圣都、原域……）→ 世界图上的国家 / 城市标记。

## 4. 查看器表现
- 事件点：按类别配色的脉冲环（颜色取各层色板：执法警示橙 #f08a24、直播红 #e0182d、全息青 #3de0ff…），等级决定大小与脉冲；新事件第一次出现有「落点」动画。
- 老化：按楼层数衰减（例如 20 楼后淡出、40 楼后只在列表里），体现「这是几天前的事」。
- 事态列表（右侧抽屉 / 手机底部）：时间（第几楼）、类别、地点、来源、一句话；点一条飞到地图位置。
- 聚合：缩小时同城区事件合成一个计数圈；世界图上天城显示汇总角标。
- 悬浮按钮角标：面板收起时有新事件 → 按钮出红点 + 数字（「看板」感）。
- 网络攻击：该层地图出现花屏（RGB 错位、扫描线抖动、局部块状马赛克），事态列表写「数据链路受扰」；持续到事件老化。

## 5. 反向：地图态势 → 模型
- 每轮把「活跃事件」压成一句注入（深度 4 左右）：`[天城事态] 中层C区：网络攻击进行中（屏幕类载体会花屏、马赛克）；霓虹街仓库火灾余波，执法局封锁两个街区。`
- 世界书加一条规则：有网络攻击时，屏幕类载体用马赛克 / 花屏配方（给出内联 CSS 配方）；有火灾时新闻快讯滚动相关消息。

## 6. 以后（格局）
- 热力模式（类似犯罪热点图 / KDE）：看哪一片最乱；按层、按类别筛。
- 「天城广播」：没剧情输入时，按时间种子本地生成背景事件（离线模拟），让城市自己在动；也可以接外部 API 或模型批量生成。
- 事件与 MVU、角色位置联动：角色所在城区有事件 → 叙事里自然出现。
- 事件驱动地图变化：火灾后该街区变暗、管控时检查点亮红灯。

## 7. 首个可交付（MVP）
1. 解析器 + 地名表（node 单测，覆盖写错格式、未知地点）。
2. eden-map.js：监听消息事件、重算、发给查看器；角标。
3. viewer：事件层 + 事态列表 + 网络攻击花屏。
4. 世界书新增条目「地图事态标记」+ 在「新闻直播」「执法局告示」「黑市终端」样例里各加一行示范标记；马赛克配方。
5. 视觉规范 artifact 加「地图」一节：地图界面色板、事件图例、标记写法。
