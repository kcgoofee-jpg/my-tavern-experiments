## 局限性

- 分类基于子代理任务描述/首行提示的关键词匹配，存在误分类（例如"未分类"15 个 agent、以及跨类关键词重叠）。
- "返工"计数只匹配提示文本里的 `v<数字>` 模式，不代表真实重做次数上限，也不做同资产去重。
- 成本权重是相对倍数示意，不等于实际账单金额。
- 优化前后对比缺乏严格的同任务 A/B 切片，多数标注为估算，仅供趋势参考。
