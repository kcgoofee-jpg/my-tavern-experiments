# 玩家上手指南（REL-DOCS，B3）

状态：2026-10-06。这份是给玩家看的那一份（D18：仓库拆分之前中文为准）；`docs/player-guide.md` 是同结构的英文版，
两份的标题层级由 `tools/check_zh_mirror.py` 守住。

## 这是什么

- 一个跑在你聊天里的地图层：点悬浮按钮打开世界图、城市图与三维页面。
- 交付只有两样：**导入脚本** + **世界书附加条目**。它不生成角色卡、不修改角色卡，也不写卡自己的变量。
- 图上的一切都由聊天正文重算出来。文里没人动身，地图就不会替谁挪位置。

## 安装

1. 在酒馆助手里新建脚本，内容就这一行：
   `import 'https://cdn.jsdelivr.net/gh/kcgoofee-jpg/my-tavern-experiments@map-v0.9.8/map/tavern/eden-map.js'`
2. 这个地址钉在正式标签上，不会自己变。刷新酒馆，打开一张带地图的卡就能用。
3. 想跟随开发分支，就导入 `python3 tools/build_preview_script.py --follow preview` 生成的脚本：它每次打开都按最新提交号取。
4. 两种只装一种，别同时开着：两份脚本会抢同一个悬浮按钮。

## 第一次打开

- 点悬浮按钮出面板，第一帧就是剧情此刻所在的地方。
- 标题栏上有：层与视图切换、⇄ 线路按钮、语言、设置，以及「反馈」。
- 顶部面包屑：世界 → 城市 → 街区 → 建筑。双击有标记的地点飞过去；带三维页的地点会给「进入」。
- 第一次打开会把底图下载一遍，之后靠浏览器缓存与地图自己的预加载，基本秒开。

## 地图读什么，怎么纠正它

- 它读聊天正文：地点标签、人物位置、事件、物品，以及卡自带的 MVU 变量（有的话）。
- 宿主不支持酒馆助手时地图照样画，但不注入提示、状态行不工作——自检里会写明，不会闷着。
- 地图认错了，就在下一条消息里写一句，它会重读：
  `（OOC 地图：现在在 某处）`、`（OOC 地图：某人 在 某处）`。
- 设置 → AI 关联页有「提醒 AI」区块，四条模板（地点、人物、事件、物品）。点一下只填进输入框，绝不替你发送。

## 卡住、变慢、白屏时

- 三条交付线路自动测速，最快答话的那条胜出并在本机留 24 小时；换的只是 host，内容是同一份。
- 一条线路 10 秒不响应就跳下一条。查看器页面起来 15 秒还没消息，启动看门狗会先按原地址重挂一次，再走最多三条备选线路，并写明走了哪条。
- 瓦片全挂时地图自己换一次线（每 2 分钟窗口一次）。
- 想固定走某条，用 ⇄ 手动选。手动选过就一直用，直到你清掉这个选择；这期间地图不再自动测速。
- 低配机器与系统省流模式会自己降到更轻的画质档；设置里也能手动指定。

## 隐私与安全

- AI 参谋的密钥保存在这台浏览器的本地设置里，同一页面运行的脚本都能读到它。只有你接受这一点才把密钥填进去；提示就写在输入框旁边。
- 反馈报告里只有：地图版本、自检结果、当前位置与地图自己的日志。**不含聊天正文、不含卡文**。
- 地图只写自己的存储（设定包对应的聊天变量，以及标了归属的那几条世界书条目）。你自己写的世界书条目一条都不动。

## 内容分级

- 伊甸设定包是 18+。分级由设定包自己声明，显示在设置与 credits 里；引擎不认识任何卡的内容边界，不过滤、不审查，剧情怎么写就怎么摆。
- 原始角色卡作者是 **Yehehua**，设定包的 credits 会署名，发布时这份署名保持可见。
- 代码是 MIT，设定包内容权利保留：见 `LICENSE` 与 `docs/licensing.md`。

## 反馈

- 面板里的「反馈」按钮会先给你看报告全文，可复制、可下载，也能直接打开一条填好标题与正文的 GitHub issue。
- 仓库里备了两个 issue 表单：Bug report 与 Feature request。请带上宿主与版本（ST 1.19.0 / 酒馆助手 4.11.2 / TauriTavern 2.3.0）、当时走的线路、以及卡在哪一步。
- 还没实测过的范围列在 `docs/compatibility.md` §8，手机 TauriTavern 就在里面。你在真机上的一次反馈比这里的猜测有用。

## 不做的部分

- 不产出、不修改角色卡；交付物只有脚本与世界书附加条目。
- 不做手机专门适配，也不对手机宿主做任何承诺。
- 不发 npm 包：地图从仓库地址交付，代码里的 npm 线路是封存兜底，永不发布。
