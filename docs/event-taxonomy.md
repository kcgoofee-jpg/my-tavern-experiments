# 天城事件体系（2026-09-27，子代理发散 + 本机定稿）

原则：**事件要少，种类要多**。每一种都要一看就是天城才有的。地图图例只有 9 种颜色（大类，v2 加了「人物」），具体类型靠图标字区分。
代码里的定义在 `map/tavern/events.mjs`（`GROUPS`、`CATS`、`ALIAS_CAT`）；世界书「地图联动规范」给模型的清单与此一致。
灵感来源：赛博朋克 2077（NCPD 犯罪报告、城市广播）、《长安十二时辰》（时辰、宵禁、望楼传讯、靖安司）、现实中的 Citizen / 犯罪地图 / 山火地图。

## 0. 设定主轴（2026-09-27 按用户要求强化）
- **双轨并行**：以太魔法与高科技并行，同一座城里两套系统互相依赖又互相掣肘——结界与防空炮、祷告与监控、以太配给与电网、魔导装甲与义体。每个大类都至少有一种「以太」事件和一种「科技」事件，一看就知道是天城。
- **人物是城市的焦点**：{{user}} 是天城顶级贵族、伊甸庄园的绝对主人；城里从贫民到首相、将军、财阀千金、战斗修女、大主教，人人都有权力、地位、财富或战力，也人人都有一道**裂缝**（丑闻、债务、失势、继承之争、信仰动摇、军法审查……）。
  - 地图记录的是**城市公开知道的事**：她们的公开行程（在哪里、什么时候出现），以及裂缝被曝光的那一刻（丑闻、违约、罢免）。
  - 这给剧情提供「在哪里能遇到谁、谁此刻最脆弱」的线索；接近、谈判、收服都在剧情里发生，不上地图。
- **示范与世界书的写法边界**：我们自己出的示范原文和世界书文本不写私人场所内部的事。解析端不做关键词过滤（6dd392e 起去掉了 `BLOCK`）：用户聊天里的标签原样解析、原样落点，见 `docs/content-compat.md`。

## 2. 城市节律（以后做：定时 / 周期事件，地图上是「城市在呼吸」，不是事件点）
**时间来源**：卡里本来就有 MVU 的 `世界.当前时刻`（HH:MM）和 `世界.当日时段`（晨起 / 晨间报到 / 日间 / 晚间值守时段 / 就寝，原枚举值照原文匹配），`世界.当前日期` 给日期。不需要另设时间锚点。

**卡里写到的节律**（只用这些）：
- 辉光大教堂的晨祷（开局八）；主教座堂**每周六晚祷**（视觉样例告示）。
- 跨层通行许可写明有效时段（样例 18:00–24:00）。
- 中层低区夜间部分街区不安全（卡原文，不是宵禁）。
- 节日：建城纪念日（悬浮轨道免费）、制度纪念日（中层放假）、丰收节；春秋拍卖季、冬季私人拍卖、秋季猎季。**卡没有给任何节日的具体日期**。
- 品鉴宴样例：2088-01-12 20:00，罗斯柴尔德庄园 R-02。

**非设定（旧稿自拟，已撤下，不得写进世界书）**：气候塔 05:30 / 21:30 调光、中下层宵禁 23:00–05:00、骑士团整点报点、哨所整点换防。

表现：低调的周期性微光或环形进度。
