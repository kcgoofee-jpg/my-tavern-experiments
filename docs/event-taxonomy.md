# 天城事件体系（2026-09-27，子代理发散 + 本机定稿）

原则：**事件要少，种类要多**。每一种都要一看就是天城才有的。地图图例只有 8 种颜色（大类），具体类型靠图标字区分。
代码里的定义在 `map/tavern/events.mjs`（`GROUPS`、`CATS`、`ALIAS_CAT`）；世界书「地图联动规范」给模型的清单与此一致。
灵感来源：赛博朋克 2077（NCPD 犯罪报告、城市广播）、《长安十二时辰》（时辰、宵禁、望楼传讯、靖安司）、现实中的 Citizen / 犯罪地图 / 山火地图。

## 2. 城市节律（以后做：定时 / 周期事件，地图上是「城市在呼吸」，不是事件点）
人工晨昏（气候塔 05:30 / 21:30 调光）、中下层宵禁 23:00–05:00（检查点收紧）、跨层通勤高峰、骑士团整点报点、教会晨祷 / 晚祷钟声、施粥开放时段、黑市开市 / 收市、天城一台整点快讯、哨所整点换防。
表现：低调的周期性微光或环形进度，呼应《长安十二时辰》的时辰感；需要一个故事时间来源（MVU 变量或世界书时间锚点），届时再定。

## 3. 跨层连锁（编号沿用同一前缀，事件卡写「由 … 引发」，以后画虚线因果连线）
1. 气候塔故障 → 中层酸雨 → 下层积水停电 → 黑市发电机涨价 → 灰票兑价波动
2. 通行税修正案 → C 区检查点管控升级 → 下层货运受阻 → 轨道故障 → 施粥站告急
3. 网络攻击（天城一台）→ 广告劫持 → 舆情发酵 → 联盟内讧传闻 → 骑士团巡空加强
4. 黑市查抄 → 灰票造假流出 → 黑市终端警示 → 血肉磨坊骚乱 → 分局增援管控
5. 结界过载 → 空域临检 → 品鉴宴加警 → 联盟请柬安保收紧 → 议会质询空防预算

## 4. 地图表现
- 传说级（人工极光、联盟内讧公开化）：对应层短暂整层色调偏移；世界图「天城」角标加特效边框。
- 全城级（政策、气候塔大故障）：顶部横幅广播条（复用「数据链路受扰」提示的样式）。
- **不上地图**：私人场所内部的事、硬边界内容（由 `BLOCK` 过滤）、未公开的机构内部八卦（除非已成为「舆情」）、没有地点的纯情绪对话、单件物品展示。
