# 成人向内容的兼容架构（只做架构，不做内容）

用户 2026-09-27：「可以不做但是要考虑兼容和用户实际情况，兼容 nsfw 在地图的显示，至于发生什么没权限也没有义务知道，做好技术架构就行。」

原则：地图**不画、不写、不还原**任何性相关或束缚类内容（硬约束不变）；但聊天里出现这类情节时，地图要**稳定、不出错、不泄露文字**，只给出中性的位置信息。发生了什么，地图不需要知道。

## 现状（v0.9.1）
| 环节 | 现在的行为 | 位置 |
|---|---|---|
| 事件标签 | 行里命中屏蔽词的整行丢弃，不落点、不进横条、不注入 | `map/tavern/events.mjs` 的 `BLOCK` |
| 未知类型 | 归「其他」，灰色方块、只显示地点 | `events.mjs` 的 `catOf` |
| 当前地点 | 房间名不在表里：逐级回落到楼层 / 庄园 / 大区 / 层；都认不出就不动地图 | `map/here.mjs` |
| 庄园房间 | 设定没写清用途的私密房间一律中性命名（「私人房间 A」「附属用房」），只放普通家具 | `docs/eden-estate.md`、`maps.json` 的 `rooms` |
| 注入给模型的态势 | 只有地图认得的事件（已过屏蔽），一句话，`should_scan: false` | `map/tavern/eden-map.js` |

## 目标架构（下个版本起，按需实现）
1. **中性占位代替丢弃**：命中屏蔽词的事件不再整行丢弃，而是变成 `kind: 'private'` 的占位事件——只保留地点和时间，类型固定为「私人」，没有标题、正文和原文片段；图标是中性灰色圆点，不闪烁、不进「新事态」播报、不注入给模型。
2. **显示开关**（设置里，默认「只显示位置」）：`隐藏`（完全不显示）/ `只显示位置`（中性圆点）。开关只影响显示，不改变解析。
3. **地点兼容**：`maps.json` 的房间可加 `private: true`。当前地点落在这类房间时，地图照常定位、高亮，但卡片只显示中性名称，不显示用途与陈设。
4. **不留痕**：地图不把聊天原文存进 localStorage 或日志；已读标记只存楼层号。截图 / 分享时有「隐私模式」一键隐藏所有事件标签文字。
5. **扩展点，不提供内容**：卡作者或用户若想自己加更细的图层，走本地插件接口（`window.EdenMap.registerOverlay(fn)`，只在用户本机生效），仓库与公开 CDN 不包含任何此类数据。
6. **测试**：`tests/events.test.mjs` 增加用例，断言屏蔽行只产生 `private` 占位、不含原文任何片段；`here.mjs` 对未知 / 私密房间的回落逐级有用例。
