## ① 辉光大教堂（圣光教会总部，中层高区，开局八起点）

卡里能用的：圣光教会总部；位于中层高区；大主教深夜在大教堂回廊散步（所以要有**回廊庭院**）；
视觉样例里的「天城主教座堂」按用户决定视为同一处。现有中层底图里的简模（`blender/tiancheng_mid.py` 约 542 行）是
拉丁十字 + 飞扶壁 + 交叉处穹顶 + 西立面双塔，这次的 3D 版保留这个平面，只把细节做成真的。

| C2 | 米兰大教堂 | 哥特（白色大理石） | 浅色石材在灯光下「发亮」——对应「辉光」；屋顶平台可走人 | https://en.wikipedia.org/wiki/Milan_Cathedral |

**推荐组合**
- **A 哥特主体 + 巴洛克穹顶（推荐）**：C1 的双塔立面 + C2 的浅色石材 + C3/C4 的交叉处穹顶与镀金采光亭，南侧接 C6 式回廊庭院。和现有简模完全同一平面，中层底图不用改位置。
- **B 纯哥特**：C1 + C5，交叉处换成尖塔（不做穹顶）；「辉光」改成玫瑰窗透光。需要同步改中层底图的简模。

夜景用光：石材被地面投光照亮 + 玫瑰窗与采光亭透暖光；不做霓虹、不做灯串。

**推荐组合**
- **A 唐宁街街面（推荐）**：P1 + P2 的街面（三层 + 阁楼、深色砖、黑门、铸铁灯笼、街口铁门与岗亭），背面按 P3 做白色柱廊朝向花园。
- **B 广场联排**：P4/P5 式围合一个小广场，首相府是中间一栋；更像街区，信息量大但不如 A 好认。

材质：手工砖（深色、略有烟熏与风化）、波特兰石窗套、黑漆铸铁、白漆木窗；不写任何真实机构的标志或文字。
