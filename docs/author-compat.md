您好，感谢您的卡和变量结构，地图一直是只读它来工作的。

有一处小建议，完全可选：在「在场人物」的对象里加一个位置字段，例如

```js
位置: z.string().prefault(''),   // 「层·地点」，如「下层·7号井」「伊甸庄园·书房」；和玩家同处可以留空
```

为什么提：现在的结构是 `z.object`，未列出的键会在每次变量更新时被丢掉，所以外挂的规则没法让模型把人物位置写进变量，只能写聊天里的隐藏标签。

加了这一行以后，地图会：
- 人物栏优先用这个字段（列表里标「MVU」），标签只作补充，和玩家同处的人不用再写标签；
- 其余行为不变：不写别的变量，字段为空时照旧按标签或「和玩家同处」显示。

不加也完全没问题，地图照现在的方式工作。
