# 伊甸庄园 · 结构草案（three.js 结构示例与 Blender 剖切渲染共用）

用途：弄清楚楼层 / 房间 / 家具的骨架，不追求美术，正式版仍由 Blender 剖切等轴渲染（见 ROADMAP P2）。

## 出处说明

- 「世界书」：`map/data/maps.json` 里 `eden` 标记的 `src` 字段——
  「庄园布局：位于天城上层悬浮区，独占一座悬浮岛屿；新古典主义白色石材建筑；前庭喷泉、后庭人工湖、访客停靠平台；全域结界」，
  以及它的 `alias` 房间名列表：书房、主卧、大厅、餐厅、会客厅、客房、寝、浴室、后庭、前庭、花园、停靠平台。
- 世界书正文（`worldbook/母畜庄园世界书_地图联动版.合并.json`）里没有专门的「庄园楼层/房间尺寸对照表」条目；能找到的相关内容只有：常驻写法规则提到「哪一层、庄园哪个区域」（entry 0）、庄园规定告示样例提到「大厅墙上」的告示与「女仆长」（entry 5）、内网档案样例提到「EDEN·HR 内网」（entry 2）、排表样例提到「女仆长」排班（entry 3）、铭牌/请柬/登记证样例只给了庄园名与配色，没有房间信息。因此**楼层数、房间划分、面积、门窗位置全部是本次推断**，仅房间名称尽量对齐上面的 `alias` 列表。
- 悬浮岛尺寸：`blender/data/tc_islands.json` 里 `eden` 条目 `rx=1.656, ry=1.242`（1 单位=100 m，约 331×248 m）。用户本次要求放大到约 `rx=3.35, ry=2.5`（约 670×500 m），本示例按新尺寸画岛，庄园建筑本体仍按较小的推断体量摆在岛心偏前区，岛上其余大部分留白为花园，供以后加建。
- 楼层数「5 层 + 悬浮岛」、剖切等轴视角、权限/主人通道/监控/隔音结界叠加层的构想，来自 `ROADMAP.md` P2·伊甸庄园（用户的规划条目，不是世界书原文，故单独标「ROADMAP」而非「推断」）。

## 硬约束处理说明

设定没有写清用途的私密房间一律用中性名（「私人房间 A」「附属用房」），只放中性家具（床、衣柜、沙发、书桌、灯），不复述、不还原世界书的相关描写。

以下楼层表里，出处一栏：`世界书` = maps.json 的 eden src/alias；`ROADMAP` = 路线图规划；`推断` = 本次为了搭出可用demo 自行假定，无设定依据。

## 垂直交通

- **主楼梯**：公共楼梯，贯穿 1F–5F，示例中橙色竖井标出，位于建筑后部中轴附近。推断位置。
- **电梯井**：贯穿 1F–5F，示例中青色竖井标出，紧邻主楼梯。推断位置。
- **主人通道**：贯穿 1F/3F/5F 的私密竖井，示例中紫色标出，直接连接停靠平台 → 3F 主卧套间 → 5F 私人电梯厅，不经过 2F/4F 公共/服务层。来源：ROADMAP P2「主人通道」叠加层构想；具体走线为本次推断。
- 三条竖井在 demo 里始终贯穿全部楼层显示（半透明），不随楼层切换隐藏，用来体现「贯穿」关系。

## 室外

- **前庭**：喷泉广场，位于建筑正面（面向访客停靠方向）。世界书出处（前庭）。
- **后庭**：人工湖庭院，位于建筑背面。世界书出处（后庭）。
- **访客停靠平台**：位于岛缘，供飞行载具停靠。世界书出处（停靠平台）。
- **花园**：覆盖岛顶除建筑本体与两处庭院外的大部分区域，为庄园以后加建预留空间。世界书出处（花园）+ 布局细节推断。
- **岛缘 / 岩基**：岛体为倒锥形岩基向下收窄，顶面为花园覆土层；结构类比其余天城悬浮岛的通用做法（`blender/tiancheng_*.py` / `tc_islands.json` 的岛屿构造），非伊甸专属设定，标「推断」。
- 结界（全域）：世界书出处，demo 中未单独可视化，留给以后的「隔音结界」矢量叠加层（ROADMAP）一并做。

## 未落实到 demo 里的部分（留给以后）

- 权限分区、监控范围、隔音结界的可开关矢量叠加层：ROADMAP 明确写的是「以后做成可开关的矢量层」，本次 demo 只用不同颜色标出三条垂直交通竖井，没有做完整的叠加层开关 UI。
- 「地下层/岛内空间」：世界书和 ROADMAP 都没有提到伊甸庄园有地下层或岛体内部可进入空间（悬浮岛机构本身是否可进入未设定），demo 的楼层切换按钮只做「全部 / 1F–5F」，没有加「地下或岛内」按钮。
