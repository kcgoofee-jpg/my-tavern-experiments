# 风格 / 面板指引（用户填）

这个目录放**用户自己**要贯彻的做图与写卡规则，skill 本身不夹带任何内容立场——模板都是空的，只有标题和几句提示，填不填、填什么由用户决定。

- `建筑指引.md` —— 建筑 / 场景美术方向（体量、材质、光影、参考）。
- `面板UI指引.md` —— 地图内 UI / 面板的交互与视觉规则。
- `风格指引.md` —— 整体美术基调、调色、禁忌手法。
- `NSFW指引.md` —— 成人向内容的边界与处理方式（要不要做、怎么做、怎么不做）；不填就当没有特殊规则。

## 怎么用

1. 打开对应文件，按标题下的提示填内容；不需要的标题可以留空或删掉。
2. 改完之后，`SKILL.md` 会在动手前提醒读这几份文件——**只读已经填了内容的部分**，空文件当作没有指引，走 skill 默认流程。
3. 这些文件不参与任何自动过滤或审查逻辑；guides 只是给执行者（Claude）看的参考，不是代码。
